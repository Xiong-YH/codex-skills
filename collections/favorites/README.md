# 原子设计收藏夹

`catalog.json` 保存用户主动收藏的设计说明、七大模块配置、认可范围和来源引用，不保存视频、图片、音频、逐帧缓存或 base64。

- 相同模块、设计说明与配置按内容哈希去重；一项最多保留 8 个来源引用。
- 最多 500 项；单项最多 8 KiB；完整 JSON 最大 2 MiB。达到上限时拒绝新增，不自动删除旧收藏。
- `current-render` 表示用户收藏当前原片中这一原子的设计；`proposed-config` 表示用户偏好尚未渲染的建议配置。均不表示整片或未来生成结果获认可。
- 来源为项目 ID、原片 SHA256、片段/镜头/事件与时间，不复制源素材。引用失效不影响设计配置保存；不能据此声称仍可预览素材。
- 工作台通过本机 `docs/prototypes/segment-review/server.py` 原子写入。按钮显示“已收藏”前，必须收到落盘成功响应。浏览器的评论草稿仍单独保存在 localStorage。

运行：`python docs/prototypes/segment-review/server.py --port 5337`，然后访问终端显示的本机地址。仅监听 `127.0.0.1`。原型尚未接入正式渲染器；引用收藏会产生配置建议，不直接重制视频。

具体原子收藏另保存 capabilityId、对象 ID、最多 8 个用途标签（每个最多 32 字）与最多 300 字的适用条件。同类收藏可作为当前对象的建议配置引用，建议 JSON 保留 favoriteId。去重以模块、能力类别及配置为准，不因设计说明换一种措辞重复占用空间。
