# 角色表演与场景接镜试验

本次依据 2026-11-13 用户转来的三张复盘截图和仓库里的角色素材。此前的《奖状之后》信息演绎获得认可，同组现代精细像素人物用定格换位演跳跃被否定，超粗像素训练场保留为动作试样。截图提到的另一台电脑工程仍需从原机交接。当前素材来源和两种人物的画法见 [sources.json](../media/sources.json)。

| 表现任务 | 本片做法 | 审片关注 |
| --- | --- | --- |
| 现代精细像素人物表达疑问 | 小棕在读取端用动作库完整待机和疑惑姿态，两脚按原图锚定。A 请求碰到空槽，空槽维持状态。 | 人物站得稳，初次未命中的原因和下一步跟得上。 |
| 超粗像素游戏精灵演出接触和受力 | 以库里获认可的静态精灵为造型基准。站姿用透明提取版，跑、蓄力、起跳、腾空、落地用按原图生成的整幅姿态。原地蓄力后连续位移，跳跃用两幅整姿态和连续轨迹。 | 查看腾空前后帧，足底与踏板同帧接触，压板随后下沉。 |
| 物件保持身份 | A 请求带出源站，卡夹打开后资料返回读端并进入缓存，第二次请求从缓存得到一份 A。缓存的同一张副本进入浅底对照图。 | 看三次换场能否持续跟住 A，以及结果里的长短路线和去回方向。 |
| 粒子指示发生了什么 | 踩板时在触点喷出像素屑，能量沿线路移动，末端开夹并扫光。短促的局部强调落稳后清场。 | 能沿触点追到反馈，同时读清主句和设备名。 |

配乐暂用现有《步进》一分钟版 26–40 秒，覆盖加密、留白与鼓组回归。关键动作和音效取同一事件，起跳在两拍之间，落板、开夹、入缓存和本地返回在拍位上。时长、拍速、人物姿态数量及具体粒子参数都是这份试样的选择。

当前独立 Canvas 的人物修订已获认可。配乐和粒子的审美反馈各在对应讨论继续。正式工程接入和共享动作收录按各自的验证和确认记录。

### 人物修订

用户指着站在踏板上的第一版精灵问「这个小人咋长这样了」。该版由代码手绘，发型剪影偏窄，身体与鞋的轮廓挤在一起。当前版使用 [原图与生成提示词](../media/azong-sprite-poses.json) 中的七幅完整姿态。统一头部尺度和足底坐标，接触时的光效位于人物后方。2026-11-13 用户回复「这个可以」，对应这版源站精灵的造型及跑跳踩板试样。另一台电脑的动作图集仍待交接。

本机 Edge 检查覆盖独立入口和对话内预览，验证拖动、逐帧、半速、静音、重播及音频尚未开始时的画面推进。对话内预览 1× 带声播完 14 秒。抽帧检查了起步、换脚、蓄力、腾空、359 帧离地、360 帧接触及踏板下沉后的站姿，七个图集单元都对齐足底行。另核对三次换场、能量传到卡夹及两条完整路线。
