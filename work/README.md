# 视频项目

`work/<项目>/` 是一个可以独立交接的工程。从本页找到项目的当前入口、复现方法及审片状态。

| 项目 | 当前入口 | 状态 |
| --- | --- | --- |
| 缓存两次读取 | [Canvas 小样](cache-route-canvas/index.html) · [项目记录](cache-route-canvas/README.md) | 源站人物修订已认可 |

纳入版本管理时，在根 `.gitignore` 开放对应项目目录并登记本页。先用新目录试跑，确认依赖可以通过相对路径或项目说明复现。已有本机目录按需要逐个迁入，迁移前核对其源文件、入口和素材引用。

| 路径 | 内容 |
| --- | --- |
| `README.md`、当前入口 | 主题、启动方式、版本及确认状态 |
| `src/` | 脚本、镜头源和可编辑工程 |
| `media/` | 当前工程实际依赖的素材、来源、裁切与锚点 |
| `review/` | 审片记录和必要证据，注明版本和认可范围 |
| `.tmp/`、`build/`、`frames/`、`exports/` | 本机生成物、测试缓存、逐帧文件和成片，按忽略规则保存 |

小型预览可以随源文件直接打开。需要构建的工程提供构建入口和依赖说明。成片需要交接时，保留配对工程 JSON 并在项目记录中标注对应版本。体积较大的素材按项目约定的存放位置交接，并记下来源和哈希。
