# 拆解模仿流程

## 1. 确定承接的 Skill

先读目标项目和相关核心 Skill。查清现有做法、可复用的能力和应沿用的约定，再定本次要改善的效果。

## 2. 对照参考选手法

定位参考片段，按起态、变化、结果拆出手法。对照现行做法，选一项能补足缺口或把已有能力串起来的做法，写清接进哪个环节。看不到的实现标为推测。

## 3. 用核心 Skill 做样本

沿目标工作流复用现有素材、组件和执行器，把所学手法变成本项目的一段。用实际产物检查目标效果和原有要求。只拆解或缺制作条件时，给出接入点和最小试样方案。

## 4. 复盘试样

带着样本的核验结果进入 [复盘沉淀](retrospective.md)。记录所学做法的适用范围，或下一次要补的证据。

## 示例

1. 已有纸签重排和数量对照，目标是让观众看见数量由哪些样本组成。
2. 参考先给出样本再亮出结论，把这种顺序接进现有分镜的结果揭示。
3. 用原有纸质组件把同一批纸签排成组，等数量可读才亮出优先项。
4. 核对纸签归属、读数和强调顺序。结论按试样验证的范围记录。
