# 视频脚本

使用时填入项目决定并删除本行及提示语；维度含义和交付前审查见 [脚本表格规范](../../references/script-format.md)。此模板供写作时复制，不由 init/check/handoff 自动加载。

项目基调：主题、受众、核心观点、视觉语言、角色职责、画幅、时间依据及当前约束。

## 片段总览

| 片段 / 镜号 | 时间依据 | 理解目标与推进 | 片段类别 / 画面呈现 | 核心可见变化 / 组件选择 | 实现状态与缺口 |
| --- | --- | --- | --- | --- | --- |
| P01 / 对应镜号 | 建议区间或工程事件 | 本段新增理解 | 类别；呈现 | 主体变化；组件方案 | 实际状态；缺口 |

## P01 · 片段标题

| 维度 | 本段设计 |
| --- | --- |
| 片段与时间 | 填片段 ID、镜号及时间依据 |
| 理解目标 | 填问题、新增理解和后续承接 |
| 类别与呈现 | 分开填类别和画面形式 |
| 旁白与讲解文案 | 填实际文案及说话者，或说明无人声 |
| 画面与构图 | 填环境、景别、焦点、光影和留白 |
| 人物与物体 | 填身份、职责、数量、位置和关系 |
| 组件选择 | 填名称/ID、作用、复用或定制理由 |
| 组件风格与样式 | 逐组件填风格、组织样式、堆叠开关及理由，或引用共用外观约定并写差异 |
| 组件形态与空间 | 填轮廓、视角、比例、材质、颜色职责、光影、像素尺度、文字区和背景适配 |
| 状态与动作 | 填初态、触发、动作、触点、末态和连续关系 |
| 节奏与保持 | 填事件依据、动作收束和阅读条件 |
| 运镜与图层 | 分别填相机、背景、主体、UI 的运动及遮挡 |
| 字幕与场景文字 | 填实际文字、形式、位置、重点、出现和收束 |
| 声音 | 分别填旁白、配乐、环境声和音效的安排 |
| 入场、接镜与收束 | 填接住、边界过程、交出和落稳条件 |
| 素材、能力与验收 | 填实际资源、能力范围、缺口、验收结果及未审项 |

### 组件明细（多个组件或独立变化时填写）

| 组件 ID / 名称 | 解释任务 / 复用判断 | 初态与输入 | 触发 → 动作 → 末态 | 保留、归属与空间关系 | 外观约定引用 | 实现依据 / 缺口 |
| --- | --- | --- | --- | --- | --- | --- |

后续片段沿用同一详情格式；无组件时删除明细空表，在详情说明原因。复杂五维引用附件，不复制第二条事件时间表。

### 组件外观约定（复杂或多个组件时填写；简单单组件可写进片段详情）

外观约定 ID / 适用组件 ID：填写明确对应关系；共用外观写继承来源及差异。

| 维度 | 本组件决定 |
| --- | --- |
| 身份与依据 | 填基础 kind 或自定义身份、真实能力/参考源 |
| 风格 | 填选定风格或无风格及理由 |
| 组织样式 | 填信息与主体的组织方式；基础按合法选项，自定义按对象设计 |
| 堆叠与层次 | 填开关、厚度、错位、容纳与遮挡；无则明确关闭 |
| 外形与比例 | 填轮廓、视角、比例及场景内尺度 |
| 材质、颜色与光影 | 填材质、受光与常态/重点/警告/失效颜色职责 |
| 文字与阅读 | 填标题、数值、单位、标签区域及层级 |
| 运动的外观机制 | 填风格如何通过实际运动成立，各状态外观变化和保留 |
| 背景适配与实现 | 填像素尺度、同框关系及参数/素材/代码的缺口 |
