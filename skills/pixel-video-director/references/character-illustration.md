# 本系列：人物动态与情境插画

适用于 [计算机知识口播的上层要求](computing-voiceover.md)。口播采用该系列当前的固定姿势局部开闭嘴规则，情境插画按文案设计行为与反应。拆头/躯干双样例因人头分离、比例失衡被否定，已退出运行；完整场景关键姿态试样仍保留独立的审美验收状态。

## 插图的职责

插图为具体内容提供图像解释、叙事或情绪表达；像素是画风，插图是用途。情境插图让人物、物体、行为与关系共同表达本镜内容，可以有人或无人、静态或动态。背景主要交代场所与气氛，口播人物层承担讲述，组件主要解释结构与数据；它们可以组合，图解在广义上也属于插图。验收看画面实际表达了什么，不能只凭生成了一张背景、加了小人或换了标签就算落实情境演绎。

本例用设备通知、人物疲惫和抱头等状态表达分心压力，原图见 [场景母图](../examples/whole-illustration/media/01-tired.png) 与 [抱头状态](../examples/whole-illustration/media/03-overwhelmed.png)，[生成提示词](../examples/whole-illustration/generation-prompts.json) 随创作源保留。新主题学习这种文案与画面的对应关系，重新选择处境和载体。

## 参考用法与人物出镜

**这组插图是风格与演绎方法的参考，不是每片必用的素材包或结构模板。** 可学习像素质感、完整人物与场景的统一，以及动作如何回应文案中的处境。新片的故事结构、镜头顺序、构图布局、动作组合、片长及插画数量由本片脚本重新决定，不默认复用书桌、通知、抱头、趴下，也不默认安排“插画开场 → 组件总结”。同一段连续姿态需保持空间连续，这不要求其他视频沿用该段构图。

逐镜先确定解释任务，再选择表达形式和人物职责：

| 镜头职责 | 是否需要人物 | 制作要求 |
| --- | --- | --- |
| 主角口播 | 脚本需要人物直接讲述时出镜，不要求全程出现 | 按系列当前规则保持身体、头部、手臂和站位，只做局部开闭嘴，停顿闭嘴；旁白播放、单次眨眼或静态微笑不能单独证明口型成立 |
| 情境插画 | 按情节选主角、配角，或采用无人物情境 | 谁在经历、操作、提问或核对，就按人物职责选角；不因样例用了阿棕就全部改用主角，保留各自身份与使用范围 |
| 概念、流程、数据、物体或场所展示 | 可以没有人物 | 用组件、道具或场景直接解释，不为统一形式给每个画面硬塞小人 |

角色“说话”与角色“在情境中行动”分别设计和验收。脚本涉及口播时，现有静态基准或本组情境姿态不足以完成口型，应补齐同一底图的局部开闭嘴素材与适配；不能借实现暂缺取消口播职责，也不宣称已有真实音素对齐。

## 从参考缓存学到什么

本次使用用户提供的 `ade295eb1fe78125a62187b3d177e07a.mp4` 的既有截图缓存，未重新解码视频。观察范围为截图序列，不能据此确认帧间动作质量、具体制作工具或音画同步。

| 参考片约数时间 | 缓存里可见的变化 | 可迁移方法 |
| --- | --- | --- |
| 7–10 秒 | 小人物坐在电脑前，数量换算和结果逐步进入画面 | 情境先给出人物处境，数据组件承担解释与归纳 |
| 12–13 秒 | 餐罩被掀开，内部显露沙漏 | 用道具状态变化把抽象观点具象化；保留动作来源和揭示结果 |
| 15–18 秒 | 人物躺床看手机，旁边沙漏与反馈图形建立时间关系 | 文案提到生活行为时，以具体场所、姿态和道具建立可识别情境 |
| 25–28 秒 | 桌上设备通知累积，人物从疲惫变为抱头、趴桌 | 同一场景内呈现“触发 → 升级 → 反应 → 结果”，表情随处境变化 |
| 33–41 秒 | 不同时期的桌面情境收成对比画面，配合时间数值 | 演绎画面可以进入对比组件，保持真实场景来源，再回收成结论 |
| 43–49 秒 | 桌、灯、书和多台设备被逐项指认，设备增多后人物反应变化 | 先让对象在场，再用标注与数量解释；角色和道具共同推进论点 |

学习画面与观点的连接方法，保留本系列的角色、画风与场所要求；参考片的真实人物、城市背景、书封与剧情不自动迁移。本地缓存和研究产物放忽略目录，不作为安装依赖。

## 两种表演职责

| 职责 | 预期表现 | 验收重点 |
| --- | --- | --- |
| 主角口播人物 | 同一姿势，只在实际说话时局部开闭嘴，静音闭嘴 | 对照旁白和停顿检查开合；身体其余区域保持一致，不用全身姿态轮换、眨眼或漂浮代替嘴型 |
| 情境中的人物 | 按文案进入操作、查找、比较、受阻或验证等场景，让动作回应可见事件 | 身份稳定，人物与道具接触可信；看掉字幕仍能辨认行为和变化；动作之后给结果阅读时间 |

情境动作的组合、幅度和频率由本镜处境决定，不固定为全系列循环；较大的情绪动作需要内容触发。口播嘴型遵循上层系列约束，不从这些情境动作中选一套轮播。人物不必常驻，也不要求每句话切一段插画。

## 《AI 全栈路线怎么走》的可试用镜头

以下是对既有旁白的画面改编提案，不能当成已实现清单。旧电脑问答拼接试样已经撤回；新片在开头加入完整书桌插画的分心、抱头、趴下和恢复专注，再回到项目驱动的路线讲解。

| 原文解释任务 | 人物与场景提案 | 可见动作与结果 | 组件接住什么 |
| --- | --- | --- | --- |
| 做出能提问、能显示回答的页面 | 阿棕在同一完整插画中操作问答页 | 仍为后续提案；旧拼接试样已撤回，不能当作完成 | 回到前端结构，指出输入、状态与结果的职责 |
| 接口连上数据库 | 栗子在开发工坊排查一次失败请求 | 请求受阻、定位连接问题、再次提交后记录写入；表情随失败和恢复改变 | 页面 → 接口 → 数据库的流程说明 |
| 有私有资料，再加检索增强 | 阿棕在资料馆查找指定材料 | 从资料中选出相关片段并送入问答终端，回答显示来源 | 用简短流程归纳检索、上下文、生成与引用 |
| 评测、日志和部署 | 老麦在核对台检查回答与记录 | 对照问题和来源，标出错误，修复后再次验证 | 清单或数值组件展示已满足的条件与运行指标 |

这些插画承担解释任务，可用直接切镜、同一主体接续或既有图卡回收衔接。无需额外强转场，镜头数量和时长按实际旁白与阅读负担决定。

## 现有能力与制作缺口

按 [基础依赖](handoff.md) 定位 pixel-game-video，再读取对应模块：

| 内容 | 当前实际状态 | 继续制作所需工作 |
| --- | --- | --- |
| V3 五人人物、每人六张动作参考 | `modules/library/CHARACTERS.md` 与 `characters/action-guide.json` 可供选型；原基准与认可状态保留 | 新动画另外存放，按角色逐个适配，不能把一人的试样推广为五人均已支持 |
| 完整书桌情境关键姿态 | 基础层 `modules/scenes/whole-illustration.md` 含实渲染图与独立样例；新试样已接入32秒原片开头 | 有限关键姿态编排，无逐帧连续动画、全身骨骼或音素对齐；仍需审美反馈 |
| 其他人物、查阅/报错/核验情境与手势 | 未接入；原动作图是参考，不能当作连续帧 | 按镜头补素材、适配、合同、可播放样例与新证据 |
| 项目镜头图片/视频导入 | 已有 background/replacement，可保留字幕和旁白；见 [按镜头替换](media-replacement.md) | 动态片段制作并验收后按镜头接入；导入能力本身不生成角色动作 |
| 十二类组件及前镜快照 | 可组织结构、数值、比较和总结 | 与场景交替使用，避免用卡片数量代替情境变化 |

新插画应提供角色基准图及适用动作参考，明确场所、姿态、视线、道具接触点、光源和字幕留白。位图由实际图像生成工具制作；动画需要实际帧序列、分层表演或视频资产，整图推拉不能算人物表演已完成。

试样验收应查看连续播放及关键帧：眨眼是否自然，嘴与脸是否稳定，动作是否被道具遮挡，表情是否符合处境，前后镜头角色是否一致。只有静态姿态图或源代码不能证明这些要求已满足。

## 哪层维护什么

导演层保留参考拆解、选镜头原则与 [完整插画创作源](../examples/whole-illustration/storyboard.json)；基础层保留媒体接入合同、实渲染参考与独立片段快照。单片的新故事和插画放工程，核心入口只做路由。优先复用人物身份、画风与演绎方法，新片结构和构图另按脚本设计；不把身体零件拆分当作可维护性的前提。

从导演 skill 根目录执行 `python scripts/render-illustration.py examples/whole-illustration` 按镜头事件编排完整插画，随后运行 `python scripts/sync-illustration-example.py` 生成基础层独立快照；`--check` 验证来源与生成物。时间只在 storyboard，图像映射与生成提示词分别保存，不依赖原参考视频或截图缓存。


## 2026-10-20：完整插画试样

用户指出拆头方案“人头分离了，比例也不协调”，要求合并完整人物，并以其第三张参考图学习情境表演。新试样以完整书桌母图生成疲惫、抬手、抱头、俯身、趴下、专注和闭眼7张整幅画面，再按事件做有限关键姿态动画。它已放入《AI 全栈路线怎么走》的开头，旁白和32秒总时长保留，随后接回原路线讲解；其余讲解镜头本轮未重制人物动画。

检查完整人物的比例与接触关系，核对每个关键姿态在导出视频里的真实区间。试作中发现不同源图尺寸会使共享滤镜重置而丢失姿态，已改为每张独立归一画幅后拼接；编码测试也覆盖不同尺寸和多个切换点。新样片尚待用户审美反馈，不能因为技术通过就标为已认可。

随后用户明确：本集合参考的是风格和模式，不要求每次出现，也不应照搬结构；不是所有画面都要有小人，插画可按脚本选主角或配角。用户同时指出现片的主角缺少说话感觉；本组情境试样不能视作口播表演已经完成，口播动态仍是制作缺口。
