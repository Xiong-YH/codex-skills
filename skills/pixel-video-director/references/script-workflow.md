# 导演流程与旧五阶段入口

现行导演流程唯一维护在 [导演四阶段](director-workflow.md)：**拆全片大模块 → 大白话与构思草图 → 结构化设计与动态白模 → 正式制作与审片**。当前页面以这四步导航；以下标题保留旧链接和职责映射，不再要求按旧五步输出。

## 1 · 聚焦需求

由编剧负责，先讨论并确认帮谁、问题和价值。见 [编剧流程](../../pixel-video-writer/references/script-workflow.md#1--聚焦需求)；独立安装按 [协作定位](collaboration.md) 读取 WRITER。有效确认直接沿用。

## 2 · 确认全片叙事逻辑

由编剧整体确认开头、核心和收尾。导演继承已有路线与授权，不因拆模块另加叙事审批。

## 3 · 分阶段文案

编剧尽早交完整稿并做内容自查，文案可独立交付。稳定文案 ID 与事实依据随同一项目交给导演；文案不是分镜、音效和制作参数的容器。

## 4 · 视觉脚本

旧阶段四现在细分为导演阶段一至三。先拆模块，再用大白话与可弃用的线框草图讨论，最后才系统细化并播放白模。不对粗构思强制填六列/十列表，静态参考不自动变成采用的动态方案。

## 5 · Check 与修订

原阶段五的多维检查融入导演阶段三，与动态白模共用当前设计、片段 ID 和修订循环；细则见 [Check](segment-check.md)。原十列视图按需展开。正式视听审片仍归阶段四，样板不替代最终成片验收。

## 同一创作器继续协作

同一 HTML、项目 ID 和 revision 延续，兼容旧 activeStage 字段；新的导演实际进度由 stages.director.phase 表示。浏览不推进实际进度，改稿与意见先保存本地并交回聊天，再回源修订。数据与工具见 [创作器](script-creator.md)。
