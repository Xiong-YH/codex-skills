# 用画面推进讲解

从编剧已确认的开头、正文和收尾出发，用画面兑现其中的变化。需要调整内容路线时按 [协作合同](collaboration.md) 与编剧对齐。构图、材质和组件按 [视觉表达](visual-system.md)，镜头写回按 [分镜合同](visual-storyboard.md)。

## 先确定整段如何推进理解

按观众的理解拆段。先交代眼下的问题或参照，再让观众看到一个对照、操作、结果或依据，最后把所得结论或未解问题交给下一段。独立的定义和并列内容可以用稳定画面，注明共同维度。情境模拟延续编剧确定的条件与限制，依据仍随原论证。 [情境模拟](scenario-simulation.md)

把路线记进项目的基调约束，每镜说明本段职责。检查删去本段会丢掉什么理解，以及换序后原有因果是否还成立。结尾回到开头的提问、选择或参照，交代观众现在多知道了什么。

## 概念、动作与视觉母题

### 把讲述推进落实到画面

第一轮镜头说明写清“讲到哪里 → 此刻看见什么 → 因此理解什么”。文案讲准备时，画面演出资料怎样变成问题；讲结果时，先建立必要的条件，再改变结果。用同一角色、物件或参照连接有因果的镜头，保留下一步需要读到的状态。

- **操作**交代对象和变化。条件、动作、结果各有可辨认的一处。
- **对比**给双方统一的条件或零点，沿清楚的顺序显露差异。
- **转移或积累**保留来源、去向和剩余状态。分清原件和副本。
- **隐喻**用真实关系约束画面。数字、因果与引文分别给依据。
- **稳定阅读**用于定义、限定和总结。明确观众要读到的关系与结果。

选少量有连续用途的物件。意义改变时演出交换或转换。先查前镜留下的结果能否进入后镜，再用构图或接镜让观众认出它。 [R41 纸签跨镜](../../pixel-game-video/examples/asking-motion/index.html#paper-handoff)

### 关键转折的画面检查

用相同镜号核对分镜、白模和成片。

| 观察点 | 设计与播放核对 |
| --- | --- |
| 操作与结果 | 动作段可暂隐藏主句，保留对象标注，核对操作、先后和可见结果；再恢复主句复看对应。定义和限定按正常阅读场景查看。 |
| 跨段承接 | 连播相邻镜头，指出后镜在哪里接住对象、结果或问题。并列段核对共同参照。 |
| 开头、章节与收尾 | 先建立问题或比较，片名和章签承接这个问题。结尾回到参照物，显示新的结果或下一步行动。 |

焦点、运动、配乐落点和阅读窗口用 [动效合同](motion-direction.md) 对照。将实际审片结果记进 [Review](review.md)。
