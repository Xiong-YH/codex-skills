# 人物表演：先设计行为，再选姿态

当镜头需要人物经历、操作或互动时读取。按人物任务、实际触点和动作结果选择姿态。

## 关系模式审核稿

当前关系库是待用户审核的草案，不视为已确认的导演配方。上一轮先审核分类；本轮用户要求为各项补独立参考视频，使用代码人物结构排练，不把它们当正式角色成片。原12条具体动作链已归档为故事案例；新模式不绑定纸笔、手机、学长或固定秒数。

模式按三个可叠加层级浏览：**行为关系**（注意重定向、启动抑制、反馈闭环、耦合解耦）；**变化与节奏**（蓄势收束、累积阈值、重复变奏）；**段落衔接**（接续交接）。不是八选一，也不要求每镜用满三层。例如一次试探可采用“启动抑制”，再按需要用“蓄势收束”安排力度；具体伸手、走近或发言仍由本镜决定。

## 三层各有归属

- **动作形态**：人物要做的具体动词、支撑与接触、末态。基础层 `modules/scenes/character-performance/actions.json` 提供开放的候选词汇，不是已完成动画的名单。姿态原图、哈希和锚点归 library 或单片素材清单。
- **连贯关系模式**：基础层同目录 `sequences.json` 保存关系、变量、分支与必须保持的条件，全部标draft-review。具体动作链留给单片或历史案例。审核入口为同目录 `index.html`；旧试样只作为有明确范围的局部证据，不当成模式已完整实现。
- **本镜表演**：导演在既有 `visual.action/result/continuity` 与 `intent` 写清处境、选择、接触、反馈和理解；具体事件时间仍只在 storyboard / 当前白模 plan。独立试样可用 plan.json，不伪装成引擎字段。

## 怎样避免动作多了，仍然重复

先问“人物想完成什么，什么阻碍了他，这次尝试使什么改变”。按行为差异而非情绪名称设计：探索可以是靠近检查、翻找、比对、试探；受阻可以是落笔停住、操作失败、伸手撤回、寻找另一条路。歪头与抱头只是少数表情选择。

同一句“很迷茫”可表现为写下又划掉、对照资料却找不到依据、或求助前的犹豫。选择能给下一句留下结果的行动，不必全做。扩大动作范围不等于每秒换姿态；方向、重心、接触、结果都没变化时，增加表情图通常不能补叙事。

按本片既有长度检查相邻动作的**行为目的、轮廓、接触对象、节奏、结果**。几项都相同时，合并阅读保持，或因剧情补不同的真实行为，不通过加摇晃掩盖重复。允许有意义的重复：第一次伸手退回，第二次伸手完成拿起，重复的起势用来突出结果变化。

## 组合动作段，而非套六拍公式

查找、操作受阻、比较选择、犹豫撤回、接物协作、验证修正、放下交接需要不同的阶段；只保留本镜有用的部分。准备、操作、反馈可以重叠，旁观反应不强制接一次操作。禁止把所有场景都改写成“吃惊—抱头—摊手—成功”。

每段确定一个观众看得见的主动作，说明：

1. 起态和目标：人物朝向、支撑点、手原来在何处，物体由谁持有。
2. 转折与因果：什么使动作开始／中止，是否需要准备；触点发生后哪个对象反馈。
3. 过程素材：完整起姿、关键中间姿、触点姿、末姿；需要跨空间抓握时，人物、手中物和相关遮挡一起准备，不拿摊手图冒充握持。
4. 收束与接镜：保留哪次尝试的痕迹，末态物体归属，以及何时稳定供阅读。

从可执行样例中选技术，再按当前机位重做接触布局。镜像全身会改变发型、徽记、惯用手和空间方向，不能把一次试样的取巧推广为默认。

普通信息场景的小比例小棕可走到组件前、踩稳、伸手触发结果。先定地面与交互边缘，触点同时驱动手、组件和声音。执行由 FOUNDATION 的 `modules/motion/recipes/contact-feedback.md` 维护，可用 [无口播缓存示例](../examples/beat-driven-cache/README.md) 比对正式画面与白模。近景、持物和两人交换优先保留整幅素材、真实承托及中间姿态。

## 素材缺口如何处理

动作目录分别标 `existing-pose-reference`、`candidate-example`、`design-only`。前者只表示有原图，后两者不意味着 VideoSpec 可调用。需要新姿态就制作与检查，不能因为旧六姿态执行器只能选六项，就把所有剧情改成这六项。

新的一组完整姿态优先保证角色、机位、桌沿／脚底锚点、比例、光源一致。物体与人物互动在完整素材中成立；持机末姿桌上不能再有同一台手机。整幅同空间关键帧可作为姿态层；切图间不能靠叠化产生双手、双脸或两部手机。需要更连续时补接触和过渡帧，不把编码60fps称为连续肢体动画。

## 本轮参考与认可范围

用户对“两张图仍呆”的第一版不认可，认可任务选择第二版的流畅和事件编排；该认可只覆盖那一个试样。后来《提问的艺术》S02A 复用歪头、抱头、摊手，被指出“反复是这几个动作”。有效经验是按本镜行为重新构思并检查重复，而不是把第一版的动作顺序作为所有剧情的模板。

新增 S02A「落笔停住—划改—试探又收回—决定拿起」试样及动作目录均待本轮观看反馈。技术通过、动作数量或新素材生成均不代替审美认可。
