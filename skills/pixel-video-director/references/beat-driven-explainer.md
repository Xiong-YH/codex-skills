# 无口播信息动效与音乐卡点

画面组件演出过程与结果，屏幕主句交代观众需要读懂的判断。BGM 推进段落，事件音效强调少数需要听见的落位、碰撞或完成。

## 先确定组件怎样推进信息

1. 继承已确认的受众、问题与价值。按 `script.beats` 接入每段初态、变化、结果和承接，镜头用 `beatId` 对应。导演把它落实为 `visual.action`、`visual.result`、`visual.continuity` 中的画面行为。例如从岗位卡抽出共性技能，再让同名同色的技能参与下一段操作。
2. 先安排结果怎样进入下一段，再选运镜或转场。跨段保留可认的身份、方向或相对位置。上一段的结果成为下一段的输入时，给观众看见它怎样被聚拢、移交、插入或转换。
3. 一段主句承载一个完整判断，对象标签补足含义或依据。采用现代像素风时，组件使用清楚的硬边轮廓，文字按输出尺寸独立绘制。给落稳的主句和结果留足阅读时间，在小屏核对先后和避让。

当用户明确指定参考片和动作库形象，先做一帧同框检查。看清参考的背景信息密度、组件的厚度与状态色、标题在小屏的大小，并用动作库原姿态核对人物身份和触点。技术试样里的替代画风和占位人物不自动进入正式预览。

## 让接镜演出交接

需要换场时，先摆好前镜交出的对象、后镜的接收方和承托面。用可辨的同一物件承接视线，让新环境在对象落稳前逐步进入。便签从笔记递到双人咨询台时，保留真实的小尺寸，从桌面过渡到人物手边。核对中间帧里人脸、手和纸的可见顺序，避免便签遮住整场交接。既有可用接镜按当前题材保留。

普通镜头需要人物主动操作时，先排走近、踩稳、触碰和反馈。让角色手到达对象边缘的帧带动状态、少量光效和事件音效。到 [人物表演](character-performance.md) 选实现，再从 FOUNDATION 的 `modules/motion/TRANSITIONS.md` 查可用的接镜机制。

## 把关键动作对到实际配乐

1. 先按片子的推进与阅读需要选曲。可从 FOUNDATION 的 `modules/audio/bgm-system/` 取可复用底乐和节拍表，也可选已有配乐。按 FOUNDATION 的 `modules/audio/GARDEN.md` 核对实际拟用区间的首拍、重拍和乐句边界。BGM 和事件音效保留独立轨。
2. 先指定观众看见接触、结果显现或新画面揭开的那一帧，再倒排起动和转场。用配乐在工程中的实际入点、裁入和播放速度换算每个选定拍点，按当前帧率量化到最近整数帧，再折算到镜内 `events`。按 [创作合同](authoring.md) 让动作、画面强调和相应音效引用同一事件。无旁白的有声工程用 `sfx-only`，按 FOUNDATION 的 `modules/audio/MUSIC.md` 用 `--source` 导入所选配乐。
3. 主重拍留给段落转折和重要结果，细分拍可以承担成组入位、高亮和计数。组件短促加速，在接触时给出压缩、回弹或状态确认，随后迅速回稳。镜头冲击用在确需强调的节点，结果阅读时保持主句和对象稳定。具体动作与停留预算沿 FOUNDATION 的 `modules/motion/TIMING.md`。

先用包含一次组件交接、一次关键落位和主句阅读的有声试样检查手感。Canvas 用同一次 `build` 产出的 `whitebox.html` 和 `film.html` 核对事件与阅读；进入正式交付后再用同次工作台 JSON 与 MP4 核对。审片记录配乐重音、预期工程帧、实际揭示或接触帧及偏差。整体错位时检查配乐入点和裁入，局部错位时调整揭示时机，再复测受影响触点。工作台改过速度或片段位置后按当前工程复核。以正常速度带声检查接缝、冲击强度和阅读，记录当前证据的观察范围。

## 16 秒求职样片

用户于 2026-11-12 提供此无口播成片作为效果参考。其上游参考是「5 个就业信息差」的录屏。约 0:44–1:01 用课程表、10 张招聘需求卡、技能频次条形图和招聘页展示如何从岗位需求找共性。样片接着把共性技能用进一个项目，最后把准备时间挪到学期轴的前段。

| 成片时间 | 可见推进 |
| --- | --- |
| 0–2 秒 | 大四日历与「开始准备」标记立在学期轴末端，建立「别等大四」的问题。 |
| 2–6 秒 | 岗位卡快速入位，第一张在 2.50 秒带动计数更新。10 张齐后，SQL、Excel 和可视化的高亮提示后面的统计依据。 |
| 6–10 秒 | 岗位卡聚成一叠，三项技能沿用标识进入频次图，条形依次填入。约 7.7 秒结果落稳，随后留出阅读时间再交接。 |
| 10–14 秒 | 同名同色的技能标签依次嵌入项目面板，面板生成表格和图表，约 12.5 秒勾选确认。完成的面板缩小后挂到学期轴的大三位置。 |
| 14–16 秒 | 切换浅底，主句收回「准备，往前挪」。标记从大四移到大二，约 14.5 秒稳定，留约 1.5 秒读结论。 |

经验记录中的 120 BPM 和 60 fps 是样片制作参数。收到的 MP4 为 1280×720、30 fps、16 秒。逐帧核对可见段落在 2、6、10、14 秒变化，同一份混音的瞬态检测在这些节点后约 0.03–0.04 秒得到峰值。该记录依据成片帧与混音，具体声部和听感用配乐原轨、事件音效及带声试样复核。后续按本片曲目、语义变化和阅读负担决定时长与用拍。
