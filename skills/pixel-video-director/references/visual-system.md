# 脚本阶段的视觉表达

循 [文画对应](visual-storytelling.md#把讲述推进落实到画面) 定下本段关系，再选画面载体和第一眼焦点。具体镜头决定写入 [分镜合同](visual-storyboard.md#写回现有工程)。

## 组件家族与场景

先定观众要看懂的关系，按需组合实物、图像、文字、标注或界面。在涉及人物行为或因果的镜头，场景交代谁做了什么，组件显露条件、变化与结果。案例与图解可以用同一件物品、操作状态或画面快照相连。

按所解释的关系查 FOUNDATION 的 [组件目录](../../pixel-game-video/modules/components/INFORMATION-COMPONENTS.md)。轮廓、层次与触点按 [R41 组件美术](../../pixel-game-video/modules/style/COMPONENT-ART.md) 确定，新结构按 [组件设计](../../pixel-game-video/modules/components/DESIGN.md) 定制。同镜组合先定主对象和辅助标注，按事件错开显露。复杂解释可拆镜。

## 视觉语言统一，场景开放

在 `brief.constraints` 记录本片的颗粒分工、色彩职责和人物身份。场所、视角和留白逐镜按内容设计。环境与道具有共同光源和承托面，组件按其信息职责独立用色。 [分层美术合同](../../pixel-game-video/modules/style/ART-DIRECTION-CONTRACT.md)

## 构图、光影与尺度的设计决定

| 决定 | 写到可制作的程度 |
| --- | --- |
| 焦点 | 标清第一注视对象，并用大小、亮度、细节或留白将次要内容退开。 |
| 光线与空间 | 写主光方向、冷暖、前中后景、承载面和遮挡。近处道具要有明确透视与接触阴影。 |
| 尺度 | 准备匹配实际景别的素材。近景看表情、触点或细节，拉远交代数量、来源或空间关系。 |
| 文字 | 分清主句、对象标签和强调字。安排适合阅读的位置，避开人物动作和转场路径。 |

聊天段可以让左侧人物与右侧消息共处一镜。头像对上说话者，第二人称讲述字幕独立于消息。其他镜头按自己的焦点布局。用灰度和小屏预览检查信息主次。 [R41 消息与反应](../../pixel-game-video/examples/asking-motion/index.html#chat-reaction)

## 按镜头准备素材

根据本镜动作确定背景、人物整体姿态、可动道具和遮挡层。对照触点准备同机位的起止状态。生成图片时按当前图像工具说明执行，实际素材和来源随工程保存，按 [素材替换](media-replacement.md) 绑定到镜头。

## 人物自然感

当前系列按 [人物表演](character-performance.md) 组织超粗像素角色的身份、重心、视线和事件反应。维持用户已选角色与职责，站立、坐姿或特写由情境需求决定。用 [角色设计](../../pixel-game-video/modules/library/CHARACTER-DESIGN.md) 选用其他物种时，写出隐喻关系与限制。

## 插图、表演与顶部导航的执行边界

插图需要实际素材与镜头接入。人物事件姿态和顶部进度目前走 Canvas，具体字段按 [插画](illustration-motion.md)、[创作合同](authoring.md) 与当前后端能力核对。
