# 六列视觉脚本示例

这是阶段 4 的纯设计示例：无实际音轨、素材或运行验证。叙事结构假定已确认，不能用示例代替真实用户确认。旧逐段十六维表由本例取代。

前序摘要：给普通观众解释“过去平安不能保证下一次”；采用认知纠偏结构：常见看法→反例/矛盾→更准确解释→结论与限定。以下仅展开前两段，其余阶段正式脚本需覆盖。

文案分组：常见看法 / P01 / c1：“一千次平安，慢慢积累了安心。”；反例 / P02 / c2：“但过去的平安，不能保证下一次。”

共同基调 A01：朴素像素城市，同一人物剪影与正面仪表；仪表平涂载板、暖色文字、左上受光，常态绿、警告红；自定义布局，无机械/能量风格，堆叠关闭。安心条为视觉隐喻，不是概率测量。
