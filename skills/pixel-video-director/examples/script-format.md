# 表格脚本完整填写示例

主题：长期平安不保证下一次安全。受众：一般观众。画面采用朴素像素城市和同一块仪表，少装饰、无主持人，数字与条块是视觉隐喻；安心值不是统计概率。下述两个片段是纯设计示例，无实际音轨，时间为建议，不构成可运行工程或默认系列模板。

## 片段总览

| 片段 / 镜号 | 时间依据 | 理解目标与推进 | 片段类别 / 画面呈现 | 核心可见变化 / 组件选择 | 实现状态与缺口 |
| --- | --- | --- | --- | --- | --- |
| P01 / S01 | 建议 0–5 秒 | 建立持续平安带来安心的预期 | 普通讲解；城市背景＋仪表 | 天数递增，示意条填满；复用状态仪表试样 | 独立试样存在；工程适配与旁白待补 |
| P02 / S02 | 建议 5–8 秒 | 区分过去记录与下一次结果 | 普通讲解；同场景连续展示 | 原条块变红、散落；天数保持 | 同一组件可示范；跨镜状态承接与工程适配待补 |

## P01 · 预期逐日累积

| 维度 | 本段设计 |
| --- | --- |
| 片段与时间 | P01 / S01，建议 0–5 秒；grow、full 是本设计事件称呼，实际帧位待建工程确定 |
| 理解目标 | 让观众看到：连续经历平安，可能形成更强的安心感；为下一段打断预期做准备 |
| 类别与呈现 | 普通讲解片段；像素城市与无框人物剪影，人物上方连接一块仪表，无侧边主持人 |
| 旁白与讲解文案 | 建议旁白：“一千次平安，慢慢积累了安心。”沿用项目确认的讲述者；尚无录音，不声称音画已对齐 |
| 画面与构图 | 固定中远景，人物在中央偏下，仪表在上方中部，顶部留文字区；城市低对比，仪表文字为主焦点，暖色人物与冷暗背景区分 |
| 人物与物体 | 一个人物剪影代表经历者，一块仪表通过连接线归属于他；背景城市不参与计量 |
| 组件选择 | C01 状态仪表：复用基础技能独立试样 object.state-meter-break.v1 的增长段；需要数字与条块联动且下一段保留同一主体，故不拆成互不关联的卡片 |
| 组件风格与样式 | C01 采用外观约定 A01：无机械/能量风格的朴素像素仪表；自定义数字区、状态区、分段条共用扁平载板；堆叠关闭。不对应基础 styleVariant，也不向试样传未实现的 features |
| 组件形态与空间 | 继承 A01 的正面轮廓、比例、平涂材质、暖色文字、绿色常态条和左上受光；仪表内阅读区独立，上方字幕另留白；不增加侧壁挤出或玻璃辉光 |
| 状态与动作 | 天数从 0 增至 1000；同一组 24 个示意条块逐格激活；full 后保留满格与终值。数量为本例视觉选择，不是事实样本规模 |
| 节奏与保持 | grow 到 full 持续积累；full 后停稳供阅读，再进入 P02；建议本段末尾预留约一秒保持，实际按录音和阅读核对 |
| 运镜与图层 | 相机、背景、人物、连接线均固定，只有仪表内部值变化；城市在后、人物在前、仪表为上方独立单元，不盖人物 |
| 字幕与场景文字 | 顶部屏幕固定、无底板，完整显示“一千次平安，慢慢积累了安心。”，强调“平安”“安心”；文案稳定覆盖增长及满格阅读，P02 新句出现时整句替换；仪表内另有“天数”“安心值（示意）”及动态数值，标签需通过已有输入配置 |
| 声音 | 旁白待录；无配乐、无环境声、无音效，为阅读留白，不给每格激活发声 |
| 入场、接镜与收束 | 首镜直接呈现城市与空仪表，随后增长；P01→P02 同镜继续，交出同一满格仪表、终值、人物及连接线，不让数值归零或重入场 |
| 素材、能力与验收 | 仪表有独立 Canvas 源码；人物和城市需本项目素材或场景实现。验收看数字与条块对应、满格稳定、标签无遮挡；跨镜与工作台尚未实现，连续视听未审 |

## P02 · 预期被一次事件打断

| 维度 | 本段设计 |
| --- | --- |
| 片段与时间 | P02 / S02，建议 5–8 秒；risk、break、settled 为设计事件称呼，沿同一主体继续求值，建工程后绑定唯一时间源 |
| 理解目标 | 过去的平安记录仍在，但不能保证下一次结果；安心条失效是预期被打断的示意，不是风险概率变化的测量 |
| 类别与呈现 | 普通讲解片段；保留上一段城市、人物与仪表，无侧边主持人或独立插画切换 |
| 旁白与讲解文案 | 建议旁白：“但过去的平安，不能保证下一次。”同一讲述者，声音待录 |
| 画面与构图 | 延续 P01 的构图、材质和受光，仪表仍是焦点；条块落向人物两侧地面，地面和仪表同一局部坐标关系需适配 |
| 人物与物体 | 同一个人物、同一块仪表、同一批 24 条块；不额外生成爆炸粒子，不复制一批假碎块 |
| 组件选择 | 沿用 C01 的警告和失效段，不重复创建组件。独立试样支持当前变化；正式项目需 scenes 适配器并处理 S01→S02 的状态承接 |
| 组件风格与样式 | C01 继续继承 A01，保持自定义布局和关闭堆叠；本段唯一外观差异是原条块与状态文字进入红色警告/失效态，原材质、壳体和字体不变 |
| 组件形态与空间 | 原载板和数值区留在原位，条块保持原轮廓、厚度和颜色职责，旋转下落；落点映射到同一地面，不因离开载板变成另一种材质或新增发光碎屑 |
| 状态与动作 | 满格→risk 时条块变红并显示警告→break 后条块脱离并下落→settled 后地面保留条块，安心值归零；天数始终保持 1000，外壳完整 |
| 节奏与保持 | 警告后才碎裂，让触发可读；碎裂到落稳采用本例短促动作起点，建议约 0.5 秒；随后保持结果直到结尾，具体帧数及旁白对齐待工程确认 |
| 运镜与图层 | 相机、城市、人物和外壳固定；仅原条块在同一变换下脱离、旋转和落地，不能在旧位置留下副本；不额外闪屏或推镜 |
| 字幕与场景文字 | 顶部整句替换为“但过去的平安，不能保证下一次。”，强调“不能保证”；从警告前稳定出现至末态阅读结束，无底板；仪表显示警告/失效和数值变化，文字区不随碎块掉落 |
| 声音 | 同一旁白，待录；无配乐、环境声和音效，本例先靠状态变化表达反转 |
| 入场、接镜与收束 | 接住 P01 的满格末态，无切镜闪变；settled 后保持外壳、天数与地面碎块，字幕完整读完后硬切结束，不循环复位 |
| 素材、能力与验收 | 复用 C01 源码和 P01 环境；工作台适配、跨镜连续状态和地面映射待补。验收检查原条块身份、无重复、天数保持、落点一致、结果可读；技术与视觉均需对当前工程复核，成片未审 |

以上没有查询或宣称新增原生后端支持。正式执行时按实际能力合同补实现，文案与时间分别回写 script 和 storyboard；本表不驱动渲染。

## A01 · C01 共用外观约定

| 维度 | 本组件决定 |
| --- | --- |
| 身份与依据 | C01 是自定义状态仪表，依据基础技能独立试样 object.state-meter-break.v1；不是基础 kind，当前无工作台适配器 |
| 风格 | 无机械或能量风格，采用朴素硬边像素表达，让状态与数值成为焦点；“朴素”是本自定义造型决定，不是给试样传 visualStyle 参数 |
| 组织样式 | 一块扁平载板：左侧天数、右侧状态、下方分段条与百分比；布局不对应基础 styleVariant，不给它填写 open/inset/relay |
| 堆叠与层次 | 关闭堆叠，无轮体侧壁、层片厚度或错位复制；条块只在画面平面内脱离和落地，场景有前后关系不等于组件启用 stack |
| 外形与比例 | 正面横向矩形载板，像素角点与简单边缘；沿现有试样局部设计比例等比映射，条块落地区域一并变换，不把含落点的完整区域裁成仅有载板 |
| 材质、颜色与光影 | 深色平涂载板、暖浅色读数和角点，不加金属/玻璃贴图；常态绿色只编码安心值，风险后同一条块与状态提示变红；背景采用弱左上光，强立体光照若要补充需新绘制实现 |
| 文字与阅读 | 左区显示“天数”和动态数值，右区显示状态，下方显示“安心值（示意）”及百分比；标题与单位独立，不压条块；外部解释字幕固定在顶部，不烘焙进仪表 |
| 运动的外观机制 | 无齿轮、活塞、充流或辉光；常态直接逐格激活，警告变红，失效后原条块沿短路径旋转下落；外壳、文字区、主材质保持 |
| 背景适配与实现 | 城市低对比避免争焦，连接线归属人物，落点与地面一致；现有试样可配置标签与颜色并等比缩放，跨镜状态、场景地面映射、额外材质效果和工作台接入仍需适配与核验 |

A01 仅适用于本例 C01，不能推广成所有视频的默认风格。实际标签长度、位数和背景同框须在当前布局核验。
