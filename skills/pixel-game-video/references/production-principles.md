# 制作总则

创作、制作、续作或复盘先读本页。优先级：本次明确要求 → 本片已确认方案 → 本系列现行规范 → 参考案例。已有有效确认直接继承；只在受众、问题或价值改变时重新确认相关方向。

## 当前制作入口

本系列的新片按 [当前风格](current-style.md) 制作：超粗像素人物与完整姿态表演、粗像素环境、实体组件、短促动效、同物接镜和落稳阅读。具体拆解与可播放证据都在技能包内，不需要读取历史 work 工程。其他风格仅在本次需要时明确选择。

编剧负责选题、叙事和上屏文案；导演负责视听设计、事件与接镜；制作负责实际实现、剪辑与技术核验。跨角色沿用同一项目与已确认内容，不重复询问。

## 文件与依赖

从工作区根目录为每个项目使用 `work/<项目>/`。文案、导演源、素材、预览、工作台工程、导出与审片证据随项目保存，续作沿用当前入口。可重建缓存、逐帧产物与浏览器资料放项目内忽略目录。

技能只维护规则、共享执行器与必要的独立样例。工具显式接收项目路径；不从具体旧 work／outputs 工程、绝对机器路径或遗留构建读取素材和参数。新片从空模板开始；重建已有项目先保存当前剪辑，不能用旧源覆盖工作台修改。

## 制作与放行

1. **按内容发生变化。** 逐段确定初态、可见动作、结果与承接。人物动作回应事件，组件承担操作和状态；结尾让观众看到行动或结论成立。静态定义保留必要阅读，不强迫每句换景。
2. **身份与接触可信。** 超粗精灵核对剪影、色块、朝向、支撑与对象归属，不强行恢复精细头身比例。其他造型按其结构检查肢体、连接和比例。抓握、承托、容纳涉及的中间态与遮挡必须成立。
3. **动作与阅读分开。** 触发、接触／揭示、收束、稳定阅读各有窗口。关键落点对齐实际音源，少量音效强调有效触点；先删多余触发再调音量。按 [动作预算](../modules/motion/TIMING.md) 和 [内容收镜](production-workflow.md#按内容收镜不填满预估时长) 核对。
4. **先试关键机制。** 新动作先做起态、过程、末态齐全的可播放试样。已有本片授权即可制作；收入共享库另按用户的入库意图处理。失败先修复或回退，不能把相近效果冒充指定过程。见 [试样与回退](production-workflow.md#新动作失败时先回退不带缺口扩片)。
5. **如实区分设计与能力。** 查 [能力目录](capability-catalog.md)，新造型、原片快照、独立试样不等于可调用 recipe。技术检查、实际观看和用户认可分别记录；未审为 `not_reviewed`，未兑现为 `failed`。
6. **交付可继续编辑。** 实际用到的镜头、文字、转场、音效、BGM 独立成轨；从 [工作台](workbench.md) 导出 MP4 与同次 JSON，保存重开后验证。最终正速连续观看、核字并听音，抽帧只用于定位问题。

## 经验维护

反馈先记录在本片：版本、区间、现象、预期、修复与复核。明确的新要求立即生效；新解法只沉淀实际验证且获得认可的范围。通用方法合并回所属模块，单片限制留在项目；不要继续叠加重复案例与过时默认值。

[基线与撤回边界](iteration-history.md) 仅在追溯时读取。动作细则归 motion，人物素材归 library，接触和表演归 scenes，组件美术归 style，导演的描述与审片归其 `references/motion-direction.md`。每条规则保留一个维护位置。
