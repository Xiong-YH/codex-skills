# 现行基线与撤回边界

本页仅在追溯认可范围或维护兼容能力时读取；新片先读 [当前风格](current-style.md)。详细旧过程由 Git 历史保存，安装包不继续携带旧片的逐轮制作报告。

## 2026.11.17 · 以 R38 重构制作入口

用户要求按《提问的艺术》最新版翻新 skill，重点是人物动作结合超粗像素、动感动效与组件风格，并清理旧 work 工程影响。采用 R38《步进》V5，88 秒、60 fps；这些参数只属于参考片。

完整 Canvas、原混音、八段选段、逐镜动作和来源哈希收进基础制作技能的 [独立参考](asking-motion-reference.md)。默认方法归 current-style，人物表演、组件美术与动态合同各维护一处。旧口播案例报告退出安装包，八类画风和旧执行器仅按具体需求查询。

新片模板改为中性占位，旧三镜演示仅留测试夹具；创作器构建需显式项目路径。此次为技能重构，不表示重新制作或验收参考片，不扩大后端、动画或工作台能力。

## 保留的认可与能力范围

| 主题 | 仍有效的边界与维护位置 |
| --- | --- |
| 超粗精灵 | 静态造型已认可；单片跑跳试样曾获局部认可，不等于全库连续动画。素材与边界归 [人物库](../modules/library/CHARACTERS.md)。 |
| 实体组件 | 纸卡、托盘、消息与同物交接按当前参考；基础执行器的机械／能量／纸质／朴素出口保留，使用按题材选择。见 [组件](../modules/components/GUIDE.md)。 |
| 旧组件合集 | 六套机械／能量结构及后续合集的美术曾获认可，原八组件材质对照也获认可；认可不覆盖任意新内容或新镜位。见 [组件美术](../modules/style/COMPONENT-ART.md)。 |
| 短促动作与运镜 | 已确认要按动态规范设计并兑现实际效果；参数与后端范围归 [motion](../modules/motion/GUIDE.md)，不把 HTML 设计自动注册为 recipe。 |
| 文字 | 柔边字幕静态样张与五项优化方向获认可；不自动覆盖任意长句、动态或新成片。见 [文字模块](../modules/text/GUIDE.md)。 |
| 音效 | 九种常用原子按音频 manifest 保留；声音源的认可不等于新片密度、混音和同步通过。见 [声音](../modules/audio/GUIDE.md)。 |
| 旧竞赛场景 | V6 视觉／V8 音画是该例基线，32 秒、筹码和试练天数不作默认。见 [专用场景](../modules/scenes/competition-routes.md)。 |

## 不恢复的失败路线

- 拆头拼身与扭曲透视实验已撤回；人物用整体姿态，物体保持比例与可信接触。
- 旧竞赛 spatial 模式被否定；阵列拉远／俯看试作已撤回，不自动恢复推荐。其他有解释任务的拉远按本片判断。
- 扩展蓄力、持续网络音等试听未获认可，不进入常用声音源；《步进》V6 尾段试听撤回，R38 采用 V5。
- 结构失败的旧坐姿图集不再作为正式素材；修正候选仍须单独审查。人物与家具支撑归 [完整插画](../modules/scenes/whole-illustration.md)。
- 曾把切图近似连续运镜、只看联系图就交付，现按 [试样与失败回退](production-workflow.md#新动作失败时先回退不带缺口扩片) 执行。已知失败不因导出成功而放行。
