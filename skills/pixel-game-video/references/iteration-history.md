# 已确认基线与历史实验

这里集中记录认可范围与撤回原因。上层阅读和记录规则见 [制作总则与经验入口](production-principles.md)。当前参数和执行入口仍以各模块指南为准；用户反馈不改变实际视听 review 的检查状态。

| 版本 / 实验 | 结果与保留范围 |
| --- | --- |
| 缓存人物表演 | 曾试用跑动、取物、抱持；旧角色切片在 V3 人物沉淀时删除。场景路径保留，当前人物为整图布局预览，肢体动作需另行制作。 |
| V3 人物，2026-10-19 | 用户确认无围巾主角、三位差异化配角、半身专题配角，以及五人人设与30张动作参考，要求删除旧人物资料。当前库只保留本版；认可不表示像素清稿、逐帧动画或嘴型已实现。 |
| 同背景口播、局部背景转场 | 局部背景裁片破坏空间连续性；修成整幅后，反复在同一房间推拉仍显单调。两个 `motion.stage-*` ID 已撤回。 |
| 18 秒跨空间叙事，`b837203` | 书页进入档案馆、书架跨到工坊、场景收成路线卡。用户反馈“这样好多了”；认可概念、物体与空间共同推进讲解的方法，未覆盖所有审片类别。 |
| 竞赛 V3 spatial | 用户否定为动作局限右侧、位移呆板；该模式已退出当前合同，源代码归档，旧工程用原独立快照复现。 |
| 竞赛 V4 透视实验 | 用户否定为扭曲；卡片纵横比变化，平面背景倾斜绕行，翻折与运镜争抢注意力。旧投影辅助及测试已归档。 |
| 竞赛 V5 cinematic | 正面统一镜头、卡片固定比例，获得“好很多”的反馈；是本例实现，尚非通用转场 recipe。 |
| 竞赛 V6 gameplay，2026-10-18 | 在 V5 上增加选中、触点回弹、资源转移、确认、进度与结算。用户反馈“符合预期，这个细节沉淀好”。 |
| 六种街机＋鼓点声音，2026-10-18 | 用户认可选择、拾取、落位、展开、受阻、奖励六个原子。保留原 PCM 母版和电子/鼓点/回弹分层；原子认可不等于成片音量、密度、同步已验收。 |
| 竞赛 V8，2026-10-18 | 沿用 V6 视觉并应用六种声音，用户反馈“整体好很多了”。后续扩展、持续蓄力和网络样音未获认可，用户要求停止探索、整理交付。实验不进入正式运行或交付。 |
| 文档脱敏高亮口播，2026-10-19 | 用户指出书页铺屏“这个转场还是太奇怪了删掉吧”。本片两处同类效果移除，改为直接切镜；后续修改本片不得自动恢复。此反馈限定于本片，不覆盖此前跨空间影片的认可范围。 |
| 组件指南缺少图片，2026-10-19 | 用户指出“咋没图片参考，这个组件指南做的不合格啊”。经验：视觉组件选型需要看到实际效果，指南应配图片、用途与边界，关键动态状态给对照，并可追溯到运行源。已补十二类大图、四组状态对照、两种组合和独立示例，完成当前引擎逐帧运行、图片链接及独立副本核验；补图后的审美认可尚未收到。适用于本视频体系的视觉选型文档，不要求非视觉模块也用图片替代其验收方式。见 [组件指南](../modules/components/GUIDE.md)。 |
| 背景选择过窄，2026-10-19 | 用户指出背景“来来会会回回这几张”，限制整体想象力。现有素材接入能力本已开放，但 AI 全栈片仍直接复用既有房间，文档中的“可变”未落实为创作顺序。调整为先按内容设计空间、尺度和主体变化，再选取或制作素材；样板只参考质感，不作场所白名单，不新增背景数量或新图比例限制。创作空模板移除赛博夜城预选，采用中性排版底等待项目设计；旧工程与运行示例保留原设置。本次更新为流程、文档和模板修正，尚无新背景素材或重制成片的审美验收。见 [背景设计](../modules/style/ART-DIRECTION.md)。 |

当前竞赛基线为 V6 视觉 / V8 音画。32 秒、十二枚筹码和十四天试练属于本例内容，不推广为技能默认值。历史源与素材归仓库 `legacy/pixel-video-experiments/` 保存，不是安装依赖；安装包自身保留本记录即可说明选择边界。
