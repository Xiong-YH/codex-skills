# 改动影响、局部更新与检查

基础编译时间线仍为唯一初始执行源，工作台 JSON 为独立剪辑分支。本机制不写回导演创作源、不调用 TTS、不代表自动视听认可。

## 看源改动

`python scripts/video.py changes PROJECT` 只读比较当前输入与上次成功 build 的基线，输出变化镜号、原因、相邻复核范围、组件使用镜号和实现哈希。成功 build 才更新 `build/project-state.json`；`build/change-report.json` 保存该次构建的差异和时间预检。诊断不修改原始四份输入。director 输入仍须先 handoff，源哈希不符时沿原合同报错。

比较覆盖画面/事件、文字、声音、镜头位置、项目设置及既有运行依赖清单。时间变化会带出后续镜号，公共实现或素材变化会保守扩大范围。组件版本是实际依赖内容哈希，当前 components 共用执行器，公共文件变化可能影响多个 kind；不冒充逐组件独立发布版本。邻镜被列为复核范围不等于必须重画。

## 在工作台局部更新

“版本与检查”面板可以检查源变化、定位时间疑点、显示组件使用范围。源重建并加载新版清单后，“预览局部更新”显示可合并项与冲突；“应用无冲突更新”只接收未手改的源单元，可撤销。按稳定单元 ID 和首次导入默认值作三方比较；手改、拆分、隐藏或删除的单元保留，冲突须人工决定。画幅/帧率不同时拒绝局部合并。旧 JSON 没有基线时保留编辑，另导入新版对照，不猜测覆盖。

局部更新会一起处理清单里实际变化的镜头、文字和音轨，不保证所有关联都可合并；存在冲突时源版本保持待更新。用户自行增加的内容和轨道排列保留，重建不会自动写入浏览器存档。应用前保存当前 JSON，应用后复查所有相关镜头和边界。JSON 不包含旧版执行器，运行代码改变后，旧 JSON 不能独自恢复旧版画面；需另存原始工程和素材快照。

源变化提示以读取当前源为准；剪辑变化提示以当前 JSON 为准；MP4 对应导出时冻结的 JSON。面板将“可预览”“自动检查”“视听待审”“已导出/导出后又修改”分开，不能把技术完成当作用户满意。

## 自动检查与实际审片

编译器继续拒绝已支持合同中的越界、引用错误与动作窗口错误。新预检报告已知讲述/文字/动作区间结束后的停留；工作台另检查镜头空档和字幕/旁白区间后的尾停。这些是时间疑点，不自动裁镜。静态阅读、情绪或接镜可以有明确依据；无依据的长尾按 [按内容收镜](production-workflow.md#按内容收镜不填满预估时长) 修复。

开启分段复用的 MP4 导出会重新解码检查总帧数和画幅，再按 2 fps、160 像素宽灰度抽样，提示持续静止或近乎无边缘的平坦画面（排除底部字幕区）。抽样会漏掉短暂问题，平坦/静止也可能是有意设计；仅供定位，不作审美拦截。技术不符会报错，不提供完成下载；人工正常速度连续观看、核字和听音仍保留未审。本轮没有新增通用 Canvas/DOM 文字遮挡或小字视觉检测器，不把现有结构检查称作像素布局检测。

解码使用 `PIXEL_FFMPEG` / `PIXEL_FFPROBE` 指定的已有工具，缺省尝试 Remotion 自带版本。部分自带精简版不支持 rawvideo 输出，此时帧数、画幅、帧率及音轨长度检查仍执行，画面抽样明确标 unavailable，不能当作无问题；配置支持 rawvideo 的已有完整 FFmpeg 后重跑，不自动安装。

## 分段导出缓存

完整 MP4 导出可勾选“分段复用”；按六秒全局帧区间缓存静音 H.264，当前剪辑的完整声音每次重渲成 WAV，最终只编码一次音频。首次需要生成所有片段；再次导出可复用内容未变片段。修改一个区间时，转场引用镜头、相邻连续字幕等依赖也计入键；代码、素材、总长、帧率、画幅、浏览器文件版本等变化会保守失效。公共生成 payload 或运行代码变化可能使全片失效，不承诺每次都只重算一个镜头。

每次导出先生成一份固定编译 bundle，所有画面片段和完整音轨共用它；编译期间发现源代码/素材变化会中止并要求重试，不拼接新旧执行器。生成后的 bundle 和素材快照在任务结束时清理，成功片段缓存继续保留。

缓存放工作台忽略目录 `.segment-cache/`，校验内容哈希，未完成或损坏片段不复用，不随独立工程交付。关闭勾选走原整片渲染；剪映 ZIP 与独立轨道导出继续原路径。系统字体、驱动等外部环境变化未完整指纹化，疑似旧画面时关闭复用并重新导出。当前不自动清理缓存，需要时在停用导出后清理本工程缓存目录；不提供任意路径删除 API。

最终 MP4、同次 JSON、耗时/检查报告仍配套保存。缓存和指标不替代工作台保存重开、逐轨与实际成片核验。
