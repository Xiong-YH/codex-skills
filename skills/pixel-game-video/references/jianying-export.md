# 剪映草稿导出

在已支持的原生 Remotion 书桌工程中，把当前工作台剪辑导成独立剪映草稿。导出与本机安装是两步；导出包不读取设备标识或修改剪映草稿库。

| 内容 | 剪映中的形式 |
| --- | --- |
| 镜头及转场画面 | 去字幕、去音频的底片，按当前镜头边界切段；可重排、删减、变速 |
| 工作台字幕片段 | 原生文本轨，可改内容、字号、颜色和位置 |
| 事件音效 | 独立音频轨，保留起点、裁入、倍速、音量 |
| 镜头主标题、人物、任务纸、运镜与内部动画 | 烘焙在底片中；修改这些内容后从工作台重新导出 |

字幕重建保留文字与样式参数，字体、字距和渲染外观需要在剪映里复核，不承诺与浏览器逐像素一致。工作台片段时长或速度已体现在底片动作中；剪映分段再次变速属于新的编辑。

## 工作台入口

安装一次可选依赖，使用与工作台服务器同一套 Python，或在启动前设置 `PIXEL_JIANYING_PYTHON` 指向已安装这些依赖的解释器：

```bash
python -m pip install -r requirements-jianying.txt
python scripts/video.py workbench PROJECT --port 5208 --no-open
```

打开命令打印的本机地址，点击「导出剪映草稿」。工作台对提交时的项目 JSON 渲染干净底片，再生成草稿 ZIP；已有 MP4 导出按钮继续导出普通成片。导出后保存配对的工程 JSON，之后的界面修改不会改变已提交版本。

命令行也可使用已经核验的干净底片：

```bash
python scripts/video.py export-jianying PROJECT DESTINATION \
  --plate PLATE.mp4 --workbench-project EDIT.project.json
```

省略 `--workbench-project` 使用同源清单的原始时间线。`PLATE.mp4` 必须由同一项目 JSON 在 plate 模式渲染，关闭字幕和音频，画幅、帧率、总帧数与本次剪辑一致；普通已烧字幕 MP4 不能代替底片。目的目录必须不存在，避免覆盖旧交付。

当前导出范围与工作台桥接一致：focus-desk、支持的运镜转场、事件音效或静音。已知项目镜头、字幕、转场、叠加层与音频片段按合同处理；未知可见组件、无法保留的层级或样式应明确拒绝。当前自定义主题不导出，需切回默认主题以保留字幕样式。不要把旁白/BGM 或其他 Canvas 场景扩写为本实现已核验能力。原始 source revision 变化时，按当前连接组件渲染并记录版本差异；不能借用旧版 parity 为新版背书。

## 包内容与本机安装

包内包含 `draft_content.json`、`draft_meta_info.json`、相对引用的 `Resources/`、配对工作台 JSON、导出清单、`install.py` 与带许可的平台适配器。中立包可迁移；先解压，保留整个目录结构。

目标机器需要 Python 3.10+ 与 FFmpeg（平台适配器用于生成封面）。先检查前提：

```bash
python install.py --check --name "像素视频-新草稿名"
```

先保存正在编辑的内容，在 Mac 使用 Cmd+Q 完全退出剪映，再执行安装：

```bash
python install.py --name "像素视频-新草稿名"
```

安装器拒绝同名项目，保留原始导出包。Mac 适配会在临时副本中补全 `draft_info.json`、媒体登记和本机平台元数据，把素材放在草稿的 Resources 中，再备份并原子更新草稿索引；失败回滚。本机平台元数据不能重新放回下载包。

Mac 安装器自动检测本机应用版本。**精确版本 11.2.0** 已用本轮 15 秒 Demo 验证：即使已有草稿全部加密，也可使用仅含 `os=mac`、`app_version=11.2.0` 的平台信息安装，不需要读取或虚构设备标识。该路径默认可用；不要把它扩大为其他版本均已兼容。其他 Mac 版本仍需要本机可解析的明文草稿提供平台元数据，可通过 `--donor-draft` 指定；缺少可用明文草稿时停止，不解密旧草稿。

Mac 11.2.0 的实际应用名可能是 `VideoFusion-macOS.app`，进程检查同时覆盖该程序及普通辅助进程。Cmd+Q 后若只剩单独常驻的 `VideoFusion-macOSTrayHelper`，且未运行主程序或其他编辑辅助进程，可继续安装；不强制结束后台进程。本轮已通过重复检查确认该托盘进程未访问草稿目录。

Windows 适配器已提供，尚无本项目 Windows 真机验收；可以通过 `--draft-root` 指定剪映设置中的草稿位置。Linux 可生成中立包，但不负责本机安装或应用内验证。

剪映可能在保存后升级或加密草稿。这是单向交接，工作台 JSON 仍单独保存；不读取剪映保存后的加密工程来同步工作台或导演源。

## 验收与记录

1. 底片按当前项目总时长导出，无字幕、无音轨；抽字幕出现时和镜头衔接的帧，与工作台画面的非字幕区域比对。
2. 草稿帧率、画幅和微秒区间正确；相邻段以起点/终点分别换算再相减，避免取整产生缝隙。媒体引用都在 Resources 中且实际存在。
3. 检查原生文本内容、区间、样式，以及各独立音效的时间、裁入、倍速和音量。隐藏轨道不导出，修改版绑定本次 JSON 与底片哈希。
4. 在目标剪映中检查能否打开、媒体是否齐全、原生字幕能否修改、镜头能否单独变速、音效是否正常。未进行应用内测试时明确记 `not_reviewed`，不能以 JSON 校验通过代替。

本轮原生验证记录（2026-10-21）：Mac 剪映 **11.2.0，build 477** 已打开并播放新建的 15 秒 Demo 至片尾，3 个镜头片段、3 段原生文字和 4 个音频素材均正常加载，未出现媒体缺失；原生文字属性面板已检查。已有项目未改动。实际修改字幕后的预览、镜头手动变速和主观听音仍未审查，不能据此声称所有编辑与视听项目都已通过；其他版本、平台及新导出的草稿需要各自核验。
