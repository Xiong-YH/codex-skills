# 普通字幕：柔边底板与暖金重音

用于画面承担主要解释、字幕辅助连续阅读的片段。2026-11-03 用户认可暖色背景上的这版效果，并认可换成深蓝机房后的表现；2026-11-04 用户看过五项交互对照后明确同意这几个优化方向；属于视觉与交互方向认可，不等于生产执行器或实际成片验收。这是可选的普通字幕方案，不覆盖画面大字、对象标注或所有项目默认值。

## 已确认的视觉基线

参数以 1280×720 样张为基准，其他分辨率等比例缩放。文案、关键词和时刻按当前项目决定。

| 项目 | 基线 |
| --- | --- |
| 字体 | 微软雅黑示例，字重700，34px；字体缺失时沿 style 字体角色重新测量 |
| 位置 | 水平居中，行中心 y=87% 画面高度；按构图避开主体与平台遮挡 |
| 正文 / 关键词 | 暖白 #f5f3ec / 暖金 #f7cf82；可随项目配色调整，保持层级 |
| 下划线 | 仅重点词，字中心下方25px，厚3px，长度跟随实际字宽 |
| 阴影 | 黑色70%，模糊3px，向下2px |
| 底板 | 深色 #080f18，中央不透明度65%（透明度35%），高度84px |
| 左右留白与柔边 | 每侧从文字边缘向外延伸104px，在这104px内由中央不透明度线性降至0；文字下方均匀，无封闭侧边、边框或圆角框轮廓 |

用户反馈：最初贴字底板左右太挤；扩大留白后选择暖金文字。加入下划线时明确保留半透明底板、左右淡化；中央不透明度46%太低，提高至65%后反馈“看起来很不错”。后续精修不擅自去掉底板或回退低对比度。

## 实现边界与使用方式

目前是设计参考和独立 Canvas 试样，尚非注册能力，也未替换 runtime.js 默认字幕。试样不作为生产执行器，不含工作台剪辑或独立轨导出；动态演示有本地播放时钟，不能替代项目事件时间线。

现有工作台 Canvas 的 richTextJson 可做关键词变色和下划线，字段见 [details.md](details.md#工作台-canvas-字幕属性)。柔边底板须另放带透明渐变的独立素材轨，关闭本句默认底板；生命周期由该轨拥有。已有工程保留原设置。不能把试样参数当作 VideoSpec 新字段，也不能声称原生 Remotion 或剪映已支持相同外观。

正式接入时复用 text 的测量与绘制，字、下划线、底板共享排版结果；核对 Canvas 工作台属性、保存重开、独立编辑与实际导出，再登记能力。文案和时刻仍归项目创作源。

## 已确认的五项优化方向

后续选择本字幕方案时据文意与构图采用这些方向，逐镜写出取舍；并非每句叠加全部效果。沿用上方柔边底板基线，时刻归项目事件，具体节奏不固定为演示秒数。

| 方向 | 设计与执行要求 | 当前证据与生产边界 |
| --- | --- | --- |
| 语义重音 | 完整句先稳定出现，到重音时关键词转暖金；需要强强调时下划线短时向右展开，完成后保持稳定阅读，不反复循环或逐字跳动 | 已演示、方向获认可；实际旁白对齐与动态参数接入待验证 |
| 底板连续 | 相邻句之间保持底板，长度依文字测量平滑伸缩；同一阅读段不闪断，较长无字幕空隙按构图决定退出，不让空底板无意义常驻 | 演示了宽度过渡；跨句间隙、末句退出与独立底板轨道仍需生产验证 |
| 长句双行 | 按完整语义换行，关键词不拆开，最多两行；底板按最长行和实际总行高计算，行距给下划线留空间，超长拆句或回改时序，不缩字硬塞 | 双行方向获认可；演示为手工语义断行，未实现通用语义断句，也未验证所有长度和窄屏 |
| 高亮主次 | 普通说明不强调；重要提醒用暖金文字；关键结论用暖金加下划线。同一句可无关键词，由文意选择等级，不以颜色随机装饰 | 第4项同屏对照三档后获认可；演示故意复用同句以比较外观，实际等级依据语义任务，不强制绑定每种句型 |
| 构图避让 | 主体占用字幕区时，将整组文字、下划线与底板移到已预留的空位；在完整阅读段保持锚点稳定，优先在语义/镜头边界换位，不逐帧追踪跳动 | 第5项主体区域为示意框；不表示已有自动主体检测、自动避碰或场景跟随能力 |

## 正式接入与验收

- 关键词内容和等级从当前脚本语义确定；布局、行高、底板及下划线共享同一测量结果。位置与颜色继承项目需要，不把暖金推广为所有系列配色。
- 重音、句切换和旁白沿同一事件时间线；无配音演示的1秒显露、4秒分段只是观看机制，不可当固定生产节奏。动作完成后留可读区间。
- 在亮暗及复杂背景、小屏、长短句、双行、相邻句间隙和末句退出上核对；65%仍是已认可基线，实际镜头另审。
- 字幕避让不能只看最终截图：检查换位前后阅读连续性、主体动作与底板遮挡；双行检查重点最大范围与下划线碰撞。
- 实际应用须验证工作台分轨编辑、保存重开和配对导出。HTML演示、代码语法检查与方向认可均不替代成片播放、听音或跨后端支持验证。
