# 普通字幕：柔边底板与暖金重音

用于画面承担主要解释、字幕辅助连续阅读的片段。2026-11-03 用户认可视觉基线，2026-11-04 认可五项优化方向；2026-11-05 接入工作台卡与导出检查，新实装效果仍待用户审看。

**后续制作默认：** 本视频体系新制作的普通讲解字幕，默认继承本页已认可的基线及按语义取舍的五项方向。Agent 在设计、工作台编辑和交付前主动落实，填写本片关键词、等级、阅读区间及位置，保存选型并核对实际输出；无需使用者再次提醒或手动选择。当前指令、已有有效项目约定或特殊表达需要其他设计时，Agent 写明具体依据并落实相应方案；不能用“临时方便”或笼统“自定义”绕过。标题、画面大字、对象标注仍按各自任务设计，不套普通字幕外观。

## 已确认的视觉基线

参数以 1280×720 样张为基准，其他分辨率等比例缩放。文案、关键词和时刻按当前项目决定。

| 项目 | 基线 |
| --- | --- |
| 字体 | 微软雅黑示例，字重700，34px；字体缺失时沿 style 字体角色重新测量 |
| 位置 | 水平居中，行中心 y=87% 画面高度；按构图避开主体与平台遮挡 |
| 正文 / 关键词 | 暖白 #f5f3ec / 暖金 #f7cf82；可随项目配色调整，保持层级 |
| 下划线 | 仅重点词，字中心下方25px，厚3px，长度跟随实际字宽 |
| 阴影 | 黑色70%，模糊3px，向下2px |
| 底板 | 深色 #080f18，中央不透明度65%（透明度35%），高度84px |
| 左右留白与柔边 | 每侧从文字边缘向外延伸104px，在这104px内由中央不透明度线性降至0；文字下方均匀，无封闭侧边、边框或圆角框轮廓 |

用户反馈：最初贴字底板左右太挤；扩大留白后选择暖金文字。加入下划线时明确保留半透明底板、左右淡化；中央不透明度46%太低，提高至65%后反馈“看起来很不错”。后续精修不擅自去掉底板或回退低对比度。

## 实现边界与使用方式

**实际入口：工作台顶部“字幕方案” → “柔边重音”。** 保留文案、时间、裁入、变速及轨道，把实际字幕片段切换为已注册素材卡 `soft-highlight-caption`。关键词由本片语义决定，转换不会自动猜重点；在属性面板填写关键词（多个用 `|` 分隔），选择普通说明、变色或变色加下划线。字幕仍独立成轨，可编辑文案、字号、配色、位置、底板不透明度和重音延迟，保存于同次工作台 JSON。

**源与边界：** 字体测量、底板、关键词和下划线共用 [text 执行器](soft-highlight.mjs)，工作台仅用 [素材卡](../../workbench/src/cards/soft-highlight.tsx)桥接。该卡可叠在 Canvas 或原生镜头上，但只改变工作台剪辑分支；不替换 `runtime.js`、原生 VideoSpec 字幕或旧工程，也不是新的 VideoSpec role/recipe。当前支持工作台 MP4；剪映原生字幕导出尚未接入，选择该路径会提前报错。

**导出检查：** 有可见字幕时必须保存 `captionDesign`。`{mode:"soft-highlight"}` 要求实际字幕卡均为 `soft-highlight-caption`；`{mode:"custom",reason:"本片选用依据"}` 保留本片其他设计。缺选型、方案与实际卡不符、其他设计无说明，均由工作台和导出服务拒绝；隐藏的字幕轨不阻塞其他轨导出。检查识别字幕轨及已知字幕卡，不自动识别烘焙在镜头里的文字，也不评判说明是否合理或审美是否合格。旧工程可直接打开和编辑，首次导出时补选型。

字幕底板随同一卡绘制，跨句连续时由工作台从相邻片段推导上一句尺寸，在相同锚点和字号下平滑衔接；真实字幕空隙仍退出。工作台 Canvas 的旧 `richTextJson` 路径继续保留，使用方式见 [details.md](details.md#工作台-canvas-字幕属性)，不与新卡重复叠加底板。原交互试样与动态演示保留作设计参考，生产调用新卡。

[本次工作台实际样张](examples/soft-highlight/workbench.png)。已检查关键词和双行编辑、方案拦截、保存重开、JSON 重导入、连续播放、字幕轨及成片 MP4 导出。实际旁白对齐、其他平台和用户审美认可仍另验。

## 已确认的五项优化方向

后续选择本字幕方案时据文意与构图采用这些方向，逐镜写出取舍；并非每句叠加全部效果。沿用上方柔边底板基线，时刻归项目事件，具体节奏不固定为演示秒数。

| 方向 | 设计与执行要求 | 当前证据与生产边界 |
| --- | --- | --- |
| 语义重音 | 完整句先稳定出现，到重音时关键词转暖金；强强调可短时展开下划线后保持 | 新卡支持关键词、等级与相对本句的重音延迟；真实旁白对齐另验 |
| 底板连续 | 相邻句保持底板，依测量结果伸缩；真实空隙与末句退出 | 新卡支持连续片段在同锚点、字号与不透明度下的宽高过渡；不跨真实空隙常驻 |
| 长句双行 | 手动按完整语义换行，最多两行；底板按最长行及总行高计算 | 新卡支持双行及溢出报错，未实现自动语义断句，其他内容另验 |
| 高亮主次 | 普通说明不强调；提醒变色；关键结论变色加下划线 | 新卡提供三档，不自动判断文意或强制每句有重点 |
| 构图避让 | 整组文字、下划线和底板移到预留空位，阅读段内保持稳定 | 新卡支持 x/y 编辑；没有自动主体检测、自动避碰或场景跟随 |

## 正式接入与验收

- 关键词内容和等级从当前脚本语义确定；布局、行高、底板及下划线共享同一测量结果。位置与颜色继承项目需要，不把暖金推广为所有系列配色。
- 重音、句切换和旁白沿同一事件时间线；无配音演示的1秒显露、4秒分段只是观看机制，不可当固定生产节奏。动作完成后留可读区间。
- 在亮暗及复杂背景、小屏、长短句、双行、相邻句间隙和末句退出上核对；65%仍是已认可基线，实际镜头另审。
- 字幕避让不能只看最终截图：检查换位前后阅读连续性、主体动作与底板遮挡；双行检查重点最大范围与下划线碰撞。
- 实际应用须验证工作台分轨编辑、保存重开和配对导出。HTML演示、代码语法检查与方向认可均不替代成片播放、听音或跨后端支持验证。
