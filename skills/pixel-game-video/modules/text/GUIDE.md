# 文字

需要全片叙事导航时使用 [节点进度条](NARRATIVE-PROGRESS.md)：标签与节点绑定事件，进度固定在画幅顶部。此层不放系列名或页码；使用时预留顶部约 12% 空间。

负责字幕、标题、注释、标签的清晰呈现；脚本文案与镜头状态由输入数据提供。

| 角色 | 默认位置 | 使用方式 |
| --- | --- | --- |
| `subtitle` | 下方安全区 | 讲解字幕，建议最多两行 |
| `title` | 顶部 | 当前主题或章节 |
| `annotation` | 上部 | 对物体或关系的补充 |
| `label` | 中下部 | 标签或 HUD，可指定位置 |

每条 cue 使用稳定 `id`，起止引用事件，编译后得到半开帧区间。
可选 `x/y` 为画幅归一化位置；`accent` 非空时采用强调色。
`runtime.js` 用最终输出分辨率排字，按实际字体测量换行。
字幕底板只属于字幕层，独立于世界的相机和碎屏运动。
风格可提供字幕皮肤和文字描影；底板、边线与阴影由排字器统一绘制，不混入脚本文案。

工作台的 Canvas 字幕可关闭“显示本句底板”（默认开启，旧工程不变）。需要在字幕空隙中保持底板时，用保留透明背景的图片素材放入独立叠加轨，覆盖所需区间，位于文字下方、镜头上方；再关闭各句底板。位置、尺寸、透明度和区间由这条独立轨道拥有，不用延长文字时长或塞入空字幕填间隙。此开关属于工作台字幕属性，不新增 VideoSpec 字段。

字幕超过两行或文字超出安全区会报出 cue ID；应缩短、拆句或调整位置，不以极小字号挤入画面。
场景标签同样调用这个排字器，局部标签建议不超过八个汉字。
字幕 `phrases` 是拼音短句元数据，交给 [角色表演](../scenes/performance.py) 消费；本模块不生成口型。

验收：无挡字、重叠、裁切或旧字幕残留；连接线、节点、边框和转场前景同样须避开字形，不能只检查文字框之间的间距。小屏能读，文字停留能读完。

工作台 Canvas 字幕可填写 `richTextJson`，保留 `text/fontSize/color` 为实际文案与默认样式。JSON 使用归一化 `left/right/y` 指定单行区域，可附 `label:{text,x,y,fontSize,color}` 与 `emphasis:[{text,color,treatment,ink}]`。`treatment` 可用 `chip`（色块）或 `underline`（下划线）；按最长词匹配，修改文案后自动重新测量，超宽报错。此模式只画字和强调，底板放独立轨并关闭本句底板；不新增 VideoSpec 字段，也不改变旧字幕默认行为。

`richTextJson.rotation` 可选，单位为弧度，绕该行左侧基线旋转；默认0。用于贴合斜放的身份卡等物件，文字仍保留在独立轨道。
