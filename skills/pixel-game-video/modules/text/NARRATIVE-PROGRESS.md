# 叙事节点进度条

Canvas 的 `timeline.progress.nodes` 为可选的全片覆盖层；Remotion 尚未支持，会在编译时拒绝。每个节点用短标签和事件引用表达一段叙事。节点需按时间严格递增，首节点为全片第零帧。节点位置对应其在全片中的时间，填充连续推进至片尾；当前节点强调，已完成节点保留状态。

```json
{"progress":{"nodes":[
  {"label":"疑问","at":{"event":"s1.enter"}},
  {"label":"验证","at":{"event":"s3.enter"}}
]}}
```

进度条固定在全画幅顶部，不跟随场景相机、转场或人物移动。它只表示叙事进程，不表示真实任务完成度。章节名称按本片内容设计，不要求每镜一个节点。使用时为顶部约 12% 留白，不另叠页码、系列名或重叠标题。

导演工程在 storyboard.progress 维护节点顺序与事件；标签通过 `{"labelId":"..."}` 引用 script.labels。基础时间线的标签为交接解析后的字符串。
