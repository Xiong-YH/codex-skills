# 画面文字与字幕表现选型

本页维护文字表现的用途与设计约定，适用于导演方案和基础制作。它是选型指南，不是新增的运行参数、recipe 或已实现能力清单；当前参数见 [字段与绘制约束](details.md)。本体系用户的开场偏好由导演层 `references/computing-voiceover.md` 维护，独立安装基础技能时从当前项目 brief 获取，不要求安装导演技能。

## 根据表达任务选形式

| 本段任务 | 适合的表现 | 设计与使用边界 |
| --- | --- | --- |
| 连续讲解，主要看操作或人物 | 稳定字幕 | 固定在不遮主体的区域，按句替换；底部是选项，不能固定为唯一位置 |
| 引出问题、观点或反转 | 画面大字 | 利用留白或视觉中心，突出关键词；文字可以短暂成为主体，给出完整阅读时间 |
| 思路需要逐步建立 | 分步累积 | 按语义分句显露，保留前文供关联；不逐字抖动或无限叠满 |
| 指出讲的是哪个对象 | 对象旁标注 | 靠近对象，必要时用引线；明确固定于屏幕还是跟随对象，连接线避字 |
| 比较两件事或前后状态 | 对照排版 | 左右或上下对应，强调差异；阅读顺序清楚，不只靠颜色区分 |
| 数量、时间或程度变化 | 动态数字 | 数字变化，单位和含义稳定；现实数据与叙事示意分清，变化不挤动相邻文字 |
| 后面的事实改变前面的判断 | 替换／否定 | 前判断保留到反转，再替换、划去或显露反例；变化对应事实，不无理由碎字 |
| 文字是场景中的真实信息 | 场景内文字 | 如招牌、屏幕、纸面；核对透视、遮挡、受光与运动，需要完整素材或实际实现 |
| 概念跨镜延续 | 文字接镜 | 关键词保留或移动为下一镜标签，写清身份、位置和阅读承接；不同概念不可偷换 |

这些形式可按理解过程组合，不要求每片用全。一句话可由大字提出问题，转为对象旁说明，再保留关键词接镜；每次变化都须新增定位、比较、累积、反转或承接作用。同一阅读段维持稳定锚点，避免无动机跳位。

## 进入画面有两种关系

- **画面中的编辑文字**：参与构图，可位于上方、侧边或中央；不假装成画中实物。脚本明确屏幕固定还是场景跟随，位置与底板分别设计。
- **真实属于场景的文字**：如屏幕与招牌，其透视、遮挡和运动必须成立。遵守当前项目的插画合成边界，不能用贴字绕过完整情境素材要求。

底板按可读性决定，可设计为无底板、贴字小底板或宽条；复杂背景先检查对比、描边和阴影是否足够。关键词可设计颜色、字号或字重变化，颜色职责沿本片 style，不能每句随意换一套。图像素材预留文字区域，完整场景仍延伸到画幅边缘，不把文字烘焙进背景母图。

## 阅读连续性：按完整语义切换

先把文案分为完整的理解单元，确定哪些是同一主句的补充、哪些才是新的观点。默认保留主句，让补充、重点或步骤逐步显露；完成当前语义并留出阅读停留后，再整体替换。分步出现不等于每个动作换一句话，阶段名称也不自动成为额外字幕。

设计时同时考虑文字和画面：

- 每组写清主句、追加内容、保留范围、允许替换的事件，以及完整状态的阅读区间。关键词动画结束后才形成可读状态时，不能把入场时间全算作阅读时间。
- 观众正在看步骤展开、数字变化、人物反应或新图形时，避免同一瞬间再换整组文字。先保持文字让观众看动作，动作落稳再引入下一理解单元；确需同步揭示时减少其他新信息并实际复核。
- 检查前文是否被过早清除、新句是否抢在前句读完前出现、结论是否只短暂闪过、同义过渡句是否额外制造切换。出现这些问题时优先合并语义单元、保留或追加文字、减少独立换句，而非把每句统一延长或压缩字号。
- 时间由实际字数、重点、画面负荷与目标播放尺寸决定，不以固定每句秒数、固定切换次数或“总片长够长”作为通过依据。片长受限时简化表达与动作，避免挤掉阅读停留。

先审 storyboard 中的完整语义和阅读区间，再观看包含画面动作的连续预览。逐帧无碰撞、单张截图可读以及事件都有时间，都不能证明连续阅读成立。发现清楚的阅读中断时回改事件编排，修复前不将该镜记为通过。

## 重点字与道具共同推进的制作方法

2026-11-03，用户对“绩点与 offer”动态字幕 V3 反馈“好很多”。可迁移的是信息层级和事件配合，不是本例的颜色、片长、PASS、连接线或每句必震。适用于以文字重音和局部状态推进的讲解片段；人物表演、口型等另按当前项目约束。

1. **先做稳定排版。** 先审完整语义组的最终可读画面，再补入场动画。主句与追加句保留成组；正文、重点词与道具标签有明确层级。字号按目标播放尺寸检查，不能靠缩小字塞下长句，也不以填满留白作为目标。
2. **按文意选重音。** 事实、对比、提问、否定与结果需要不同强度。普通解释稳定出现；主要重点词可用“预留位置 → 短时放大冲入 → 回收落稳”；必要的震动只跟随关键落点，阅读期停止。检查重点词最大尺寸时的碰撞，不只审最终排版。通用时长见 [动作与停留](../motion/TIMING.md)。
3. **把重音写成事件。** 每个主要落点写清“文案重音 → 对象原状态 → 变化 → 视觉反馈 → 稳定结果 → 阅读区间”。字幕、道具、粒子引用同一事件；同一落点可协同揭示同一件事，不同时引入多个无关重点。帧数仍唯一维护在项目时间线。
4. **先试一段，再扩展。** 优先制作包含普通叙述、一个重点、一次状态变化和稳定阅读的代表片段。新片若有不同机制，另试该机制；不能只凭开场获认可就假定全片适用。沿认可的层级和强度扩展，按文意改变具体动作。
5. **用删减对照审片。** 关闭动效检查排版和理解，再看正常速度的实际导出视频；如果拿掉某效果不影响重点、关系或节奏，优先减去。检查小屏阅读、前文保留、强动作后的停稳，以及相邻重音是否过密；听音状态单独记录。

后续制作复用分析与验证方法，每片重新选择表现手法；不要求收敛到同一套动效能力、固定反馈组合或统一参数预设。认可样片用于比较可读性、主次和节奏，不作为需要复刻的目标。保留参考来源、原有语境与认可范围；实际采用的表现仍按 [能力目录](../../references/capability-catalog.md) 核对支持与可编辑性。本文不是新增字段、自动套用器或已注册的字幕预设。

## 可迁移手法参考：按主题重新设计

以下提取自火鸡参考片的观察及“绩点与 offer”V3 的尝试，作为可选的表达思路。它们不是整套配方，不要求每镜、每片使用，也不把 V3 中的全部做法视为用户逐项认可。

| 可抽象手法 | 服务什么表达 | 换主题时重新决定什么 | 应避免什么 |
| --- | --- | --- | --- |
| 前句保留，后句补全 | 建立对比、条件或递进，让观众关联前后信息 | 按新文案确定语义组、断句、出现顺序与阅读空间 | 照搬原片句式、换行位置或揭晓节拍 |
| 重点词短时超出常规尺寸，再收稳 | 为揭晓、结果或情绪重音增加分量 | 重新选重点词、尺寸变化、进入方向和强度；柔和主题可用轻显露代替冲入 | 每个重点都猛砸、整句反复缩放、以遮字换取冲击 |
| 先留位置，再补关键内容 | 制造有意义的等待，使缺失的信息成为揭晓 | 依据新主题决定是否真有未知项，以及留白能否自然阅读 | 为模仿效果生硬挖空句子、复刻原片独特构图 |
| 字幕落点与对象状态对应 | 让文字说出的变化在画面里兑现 | 重新选择主题中的真实对象和变化机制；例如“缓存命中”可表现为直接取到数据，无需套成绩章 | 每个主题都套 PASS、offer 或同一状态条 |
| 短促反馈后恢复稳定 | 让关键变化可感知，同时留出阅读 | 根据变化含义选择一次回弹、亮起、局部震动或其他反馈；可以不用震动 | 持续抖动、无意义闪光、机械照搬强度和帧数 |
| 关系改变留下新末态 | 用替换、分离、重排或断开呈现观点变化 | 新主题到底是断开、反转、分流还是合并；例如并行处理宜表现为分流，而非碎裂 | 所有否定都打碎、所有结论都画不等号 |

粒子的来源、状态含义与配合仍唯一归 [场景反馈](../scenes/GAME_FEEL.md#字幕重音震动与粒子的协同)，不在文字模块另建粒子配方。

### 参考转化与原创检查

- **不得抄袭参考作品。** 学习信息层级、注意力引导和状态变化等抽象机制；不得直接挪用参考中的文案、角色、美术素材，或照搬有辨识度的构图、镜头顺序和动效组合后仅替换文字、颜色。需要引用具体素材时另行确认来源、使用授权并标注；提供参考片不等于授权复用其素材。
- 每次从当前主题和脚本出发，先写“这里需要观众理解什么”，再选对象、布局、节奏和反馈。先独立形成方案，再回看参考检查方法是否适用，避免顺着原片逐镜换皮。
- 在现有分镜或设计说明中简记“借鉴的机制 → 本题需要 → 本次改造 → 未采用及原因”。不另建重复时间线，也不为凑差异任意改造与内容无关的细节。
- 审看时问：去掉参考片，这个画面是否仍自然解释当前主题？是否保留了原片独特的表达组合，只做表面替换？前者不成立则回到内容设计，后者成立则重新组织。


## 实现状态与生产交接

当前创作输入提供 role、x/y、整条 accent 与事件起止。普通字幕角色仍自动绘制风格底板；改位置不会自动取消底板。title、annotation、label 可无字幕底板排字，但角色选择不能冒充已实现的复杂字幕系统。

句内不同颜色与字号、逐词揭示、跟随对象、场景透视、划去及文字接镜等方案，必须核对实际执行路径；需要定制时明确待实现内容、源文件和可编辑边界。此前五秒样片中的金红混排由项目定制完成，不代表这些能力已注册或可在工作台逐词编辑。

设计确定后，文案只维护在 script；时刻只维护在 storyboard。不得为图省事把已约定的画面文字静默退回底部整句字幕。执行缺口先补实现与验证，或明确提出替代方案。

## 验收

逐项对照脚本的形式、位置、重点词、出现顺序、绑定关系、底板与收束。看每个显露阶段，而非只看整句最终帧；检查关键词放大后的碰撞、阅读停留、小屏可读性、主次、重复结论及旧字幕残留。跟随、替换与接镜检查连续片段，真实场景文字另查透视和遮挡。自动安全区检查不能证明这些设计合格，未检查项保留未审。
