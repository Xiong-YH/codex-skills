# 自定义组件五维

<a id="组件五维"></a>

自定义新的实体、路径、形变或关系机制时，用以下五项写一份简短约定，落实到素材和事件后做最小试样。仅选择基础 kind、一个风格、样式和可选特性时，直接按[基础组件规则](BASIC-COMPONENTS.md)复用，无需逐个重做五维。自定义组件可不带风格，按对象本身的形态设计；选用风格时同样遵守机械／能量互斥，堆叠继承当前风格。可借鉴开放、一体、传递三种手法，也可为对象设计其他造型；不要强塞进基础组件的三个布局。已有自定义组件复用已验证部分，仅检查本次变化；无需逐项等待用户审批。

| 维度 | 必须明确 |
| --- | --- |
| 表达 | 解释什么关系；初态、触发、末态；对象身份、数量与归属怎样连续 |
| 形态 | 外形、视角、比例、材质与受光，如何结合当前背景的像素密度和轮廓；造型按对象设计 |
| 动作 | 起动→路径或形变→接触→收尾→保持；单次运动短促，停稳后留阅读时间，按[动作时长与节拍](../motion/GUIDE.md#组件内部的离散动作与节拍)安排实际触点 |
| 素材 | 初末态及必要中间态、图层、锚点和接触点；有容纳或遮挡时，明确内部平面与真实遮挡轮廓 |
| 能力 | 哪些已实现、哪些需补素材或代码；本次验证的素材、视角和布局范围 |

## 最小核验

只演示一个完整动作，连续播放，再检查起动、运动中、接触、收尾和稳定态。检查对象是否重复或消失、接触是否错位、遮挡是否沿真实边缘、结果是否保留。翻开或展开等形变须有可读的中间过程，不能靠初末两张图瞬间替换。

声明支持位置或尺寸变化时，至少换一次对应布局，检查路径、落点和遮挡共同变换。换视角、容器结构或动作机制，重新核验变化部分。坐标与事件检查不能代替观看，单个试样通过也不代表任意素材可用。

用户只看局部效果时，交付可播放试样即可；正式视频再接入原制作流程。需要美术或动作参考时读[案例](REFERENCES.md)，案例中的造型、路径与秒数不作为通用模板。

复用入口：[完整集合](examples/style-atlas/README.md)同时列出当前筹码入托盘和历史供能装配，分别标记适用范围；历史混合外观不覆盖当前单一风格约定。
