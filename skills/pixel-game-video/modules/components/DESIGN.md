# 从脚本发散组件

先确定观众要看见的变化，再挑承载物。纸页可以排证据，插槽可以表现归属，消息可以决定下一步。组件可以是工具、结构、标签或一组关联的物件。用一次明确的触点完成变化，给结果稳定的阅读时间。

## 五维

| 维度 | 写清什么 |
| --- | --- |
| 表达 | 观众要明白的因果，初态与结果，哪些物件要保留或转移。 |
| 形态 | 选择纸、设备或实物承载。构图、尺度、层次与文字量在同镜可辨。跟 [R41 组件美术](../style/COMPONENT-ART.md) 核对。 |
| 动作 | 来源、路径、触点、完成后的状态与下一镜接住的东西。 |
| 素材 | 文字、图标、纸沿、遮挡物和角色是否需要单独层。 |
| 能力 | 现有组件是否贴合，组合时需要哪些事件，新增时怎样在工程内验证。 |

## 从一种关系找到多种做法

| 观众要懂的关系 | 可尝试的表现 |
| --- | --- |
| 收集与积压 | 资料进收件槽，书进归还堆，待办逐张压到手账页。 |
| 反馈与落差 | 暖色尝试数锁住后，给未成结果单独显露。回执或消息在结果读稳后分拍出现。 |
| 证据与取舍 | 并列证据、按条件筛出选项、批注落到资料对应位置。 |
| 归属与交接 | 从报告撕出一张纸签，沿场景边缘带到核对台。需要单个物件的路径与接收边。 |
| 试做与状态 | 按钮压下，操作台改显示进行中。完成事件可以带出回执或记录页。 |
| 方法与步骤 | 书签停在当前节点，计划逐格填入，完成的项继续作为参照。 |
| 组成和数量 | 多个子项在目录轨上归到同一主签。比较量使用共同的刻度和零点。 |

这些关系可落在不同场景和题材。图册提供 [当前可播放的组件与组合](examples/style-atlas/README.md)。表达超出当前输入时按 [接入方式](CUSTOM-RUNTIME.md) 做最小试样。
