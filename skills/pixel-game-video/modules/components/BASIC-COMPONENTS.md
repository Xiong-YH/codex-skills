# 基础组件：风格、样式与可选特性

十二种 `kind` 继续负责身份、数量、比较、指认、章节、流程、时间、条件、组成、大小、代码、结论。外观另选一种风格，可增加堆叠特性；不为不同外观新增 kind。字段按需查[信息组件合同](INFORMATION-COMPONENTS.md#参数与接入)。

## 四个决定

| 决定 | 唯一字段 | 合法选择 |
| --- | --- | --- |
| 解释什么 | kind | 十二类已有信息组件 |
| 材质和运动机制 | visualStyle | plain（朴素原版）、mechanical 或 energy；默认 mechanical，三者择一 |
| 如何组织主体和信息 | styleVariant | open、inset 或 relay；默认 inset |
| 是否增加空间层次 | features | `[]` 或 `["stack"]`；默认空 |

两种风格各有三种样式；堆叠独立开关。十二类 × 两种风格 × 三种样式共 72 个基础范例，计入堆叠共 144 种配置。配置数量不等于新的语义种类。旧 `styleLayers` 混搭数组继续拒绝。

## 样式是方法，不是三个固定外框

| styleVariant | 机械的表现 | 能量的表现 | 适用倾向 |
| --- | --- | --- | --- |
| open | 无框并列；独立齿轮、读数、工位和开放标签 | 开放式能量刻度；独立玻璃柱、轻承载和直接读数 | 主体明确、图像或数字需要突出，信息较少 |
| inset | 一体铭牌；层次壳体、嵌入读数和局部锁定机构 | 一体玻璃铭牌；透光载体、黄铜夹具和沿边充流 | 内容需要共同承载，对比、身份、代码或重要结果 |
| relay | 齿条揭幕；边缘传动、滑块或连续工位 | 充流揭幕；能量芯、管路、到达触点和结果保持 | 过程、传递、章节揭晓，需要清楚的动作因果 |

按内容选择，不因 kind 固定一种样式，也不把章节例子的造型照搬到全部组件。样式名称描述组织方式；流程仍须保留节点与先后，条形仍须保留共同零基线，代码仍须保留缩进与行号。样式不会自动制造内容中的因果证据。

可在同镜不同组件上选择不同样式，但保持一种主风格、主次和受光统一。不要为了“丰富”同屏铺满六套。需要超出这些组织手法的新物体、路径或形变，转[自定义五维](DESIGN.md)，不凭空填写新 kind 或 styleVariant。

用户已认可本轮组件合集；新内容与新布局仍逐次核验。[完整范例源与播放方法](examples/style-atlas/README.md)提供实际执行器、84 个参考实例（含十二类朴素原版）、堆叠与自定义集合。

## 无风格：保留朴素原版

`visualStyle: "plain"` 调用 [plain.js](plain.js)，保留原有十二类组件的简单边框、文字、数值与状态逻辑，不经过机械／能量装置绘制。适合文字密集、辅助信息、需要克制留白或画面已有强主体的镜头。

plain 不区分三种样式，也不附加堆叠：省略 styleVariant 和 features 即可；序列化默认保留 inset 与空数组，它们不代表朴素组件也有“一体式”外观。显式给 plain 配 open／relay 或 stack 会被校验拒绝。省略 visualStyle 仍按既有约定使用 mechanical，不把已有项目改成朴素版。

```json
{"id":"note","kind":"chapter","x":0.15,"y":0.26,"width":0.72,"height":0.34,
 "visualStyle":"plain","showEvent":"enter","data":{"index":"02","title":"从接口到数据"}}
```

十二个朴素范例加上 72 个风格范例，共 84 个基础参考；144 种风格／堆叠配置加朴素十二类，共 156 种配置。朴素组件也保留信息语义、文字溢出检查和短动作＋阅读保持；自定义组件同样可选择无风格，不强加金属或光效。

## 风格特征必须鲜明

| 风格 | 形态和材质 | 动作和状态 | 不混入什么 |
| --- | --- | --- | --- |
| mechanical：齿轮／机械 | 黄铜、深铁色、实心壳体、铆钉、齿轮齿条、导轨与锁扣 | 转动、滑移、咬合、接触后锁定；机构承担实际状态变化 | 不叠青蓝充流、玻璃能量芯或能量辉光来增强气氛 |
| energy：能量 | 青绿玻璃仓、能量芯、透明受光、刻度与充流路径；黄铜端帽、框边、底座和紧固件点缀 | 充入、传递、到达反馈，停止后保留结果；没有计量依据时只表示激活 | 不叠齿轮传动或活塞动作，不把全部部件涂成纯蓝色 |

小尺寸下仍能从轮廓、材质与运动认出风格，不能只换边框颜色或微弱亮点。齿轮应服务传动或读数，不给所有内容贴同一枚装饰。能量亮部集中在介质、通路与触点，文字保持清楚。

两种风格共享黄铜、深色金属和暖色局部受光，区别在运动机制与主表现。黄铜材质、分区框边与紧固件的共享**不等于风格混搭**。最初计数器用于参考材质与壳体层次；齿轮统一使用用户选定的[黄铜金色原图](assets/gears/brass.png)，大小和转向均不切换灰色钢轮，直接调用，不再用圆环、十字线或实心圆盘近似。能量以原玻璃管的青绿介质、黄铜端帽和层次底座为基准。

章节编号和数值窗独立划出可读区域：编号不盖在轮毂或能量核心上，数值与单位按实际字宽分区。更换编号、位数或单位后同时审看两种风格，不以动画正常或没有异常代替遮挡与裁切核验。

**主体优先按实物重构，不沿用通用面板再加装饰。** 数值优先计数器／玻璃管，流程优先传动工位／充能中继，层级优先主机／核心及其分支，清单优先验收机构／激活单元，代码优先带游标的纸带／光学代码载体。各类保留自己的轮廓和接触动作；两种风格在纯底和实际背景下都要可辨认。参考最初计数器、能量管的实物感，不照搬其布局到所有 kind。

## 堆叠只管空间关系

启用 stack 后增加分层承载、层片厚度、装入与遮挡；材质、色彩和反馈完全继承所选风格。关闭后回到单层承载，信息职责不变。不凭装饰层数暗示真实数量或架构层数，不把加厚外框当作全部堆叠表现。

齿轮的粗齿形、金属表面色阶和正面刻纹属于风格；**可见的轮体侧面、挤出厚度和层间错位属于 stack**。关闭 stack 时用正视造型，不烘焙侧面挤出；开启时从同一正面造型增加厚度，不能换成另一枚齿轮。正面材质光影不等于轮体厚度。

齿轮侧壁保持薄、连续，与齿轮尺度成比例；不通过多张同图错位复制制造重影。旋转时侧壁的受光和挤出方向稳定，不随齿轮朝向转成另一侧，正面齿形与镂空保持清楚。

风格动作和堆叠装入引用同一镜头事件，短促完成，随后留阅读停顿；数值/条形的 start/end 事件仍由工程拥有。时长及实际配乐触点见[运动规则](../motion/GUIDE.md#组件内部的离散动作与节拍)。

## 同一规则覆盖十二类

身份、对比、章节、结论用所选材质承载识别与揭晓；数值、条形用读数/充量表达真实数量；流程、时间轴、层级用传动/充流表示相应连接；清单用机械锁定或能量点亮表示条件满足；标注保持指向，代码保持字符、缩进和当前行。风格或堆叠都不能改变数值、先后、组成与条件的语义。

```json
{"id":"result","kind":"metric","x":0.15,"y":0.2,"width":0.7,"height":0.55,
 "visualStyle":"energy","styleVariant":"relay","features":["stack"],"showEvent":"enter",
 "data":{"title":"已完成","from":0,"to":3,"unit":"层","startEvent":"begin","endEvent":"land"}}
```

朴素分支由 plain.js 保留原版；执行规则由模型、`contract.py` 和 `style-layers.js` 维护，`apparatus.js` 按各类语义绘制主体物，`runtime.js` 提供状态与调用。Canvas 及其工作台桥接读取同一组件 JSON；不据此宣称原生 React 或最终成片已审。

现有 kind 和特性能表达时直接复用；新实体、路径、形变或关系机制才转读[自定义五维](DESIGN.md)。五维设计也遵守风格互斥，历史融合装置仅作旧实例，不作为本套基础风格模板。

核验覆盖十二类 × 两风格 × 三样式 × 两种堆叠状态、事件前中后与末态、非顺序取帧、非法混搭拒绝、文字和关系不变；机械与能量并排审看，确认风格强度与堆叠继承关系。技术通过与用户审美认可分开记录。

宽identity的响应式布局：实际宽高比大于8:3时采用同一mechanical／energy材质的横向底板，标题和说明按输出尺寸重绘；竖向装置布局继续使用原绘制。用于内容重组及有来源的面板遮挡，不增加独立visualStyle。图片视口由apparatus.imageBounds统一提供，预览展开读取同一结果，避免转场重复猜测组件内坐标。
