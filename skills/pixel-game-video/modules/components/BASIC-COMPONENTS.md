# 组件基础字段

外观由组件职责选定，细节按 [R41 组件美术](../style/COMPONENT-ART.md) 核对。

| 字段 | 意义 |
| --- | --- |
| `kind` | 选一个已实现的形态和状态逻辑。看 [参数目录](INFORMATION-COMPONENTS.md)。 |
| `id` | 本镜内可引用的稳定身份。转场按前后两镜的 ID 匹配。 |
| `x`, `y`, `width`, `height` | 用画幅 0–1 比例表示左上与尺寸。留出阴影、裁切以及字幕位置。 |
| `tone` | `gold` 重点、`accent` 已确认、`secondary` 常态、`danger` 未成。标签及结果向场景画面传递这个意义。 |
| `features` | 保存为空或 `["stack"]`。身份卡用它表示摆在一起的多层纸。 |
| `showEvent`, `focusEvent` | 本镜事件。省略显露事件时用 `enter`。 |
| `dimEvent` | 触发后把这个组件降为次要亮度，保留原位与内容。 |
| `data` | 本组件自己的文字、图标、动作时点和数值。 |

导入已有项目时，编译器读取此前的外观字段并标准化成当前组件。原片参考通过其随包播放器独立运行。
