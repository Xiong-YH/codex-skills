# 状态仪表：脚本驱动的完整范例

用户于 2026-11-01 对对话中的 HTML 原型反馈“这种就挺好的”，随后要求重构自定义组件架构。本目录把同一表达拆为组件、共享辅助与独立播放器；认可只覆盖原型方向，本版本仍需分别记录验证，不等于原型已经接入工作台。

## 需求与选型

句意：长期平安不保证下一次安全。可见答案：天数增长不被抹去，状态可被一次事件打断。基础 metric 能递增，bars 能增长，但不能直接表达原条块脱离、散落并保留，故新增局部机制。人物与仪表的归属线、环境和整段编排由播放器示意，正式制作归 scenes。

## 五维

- 表达：天数与安心值一起增长，后者是示意值，非真实测量。segment-0 等稳定 ID 贯穿整段；risk 后警告，break 到 settled 之间同一批条块从 meter 转为 falling、ground。天数和外壳保持。
- 形态：朴素像素仪表，独立数值区、状态区和分段条。不代表机械/能量风格新基准，不沿用原型外观作为所有组件默认。
- 动作：start→full 为持续积累，risk→break 为警告保持，break→settled 为短促落地，之后保持。示例帧数只在播放器事件表维护；正式项目引用本镜事件并按实际旁白安排。
- 素材：组件本身纯代码，无外部素材；局部 640×320，碎块落点包含在此范围中，场景地面须与局部 y=300 对齐。背景、人物与连接线不属于组件；透明绘制，不清屏。
- 能力：独立 Canvas；支持 count 4..40、有限安全数值 from/to、种子、标签和颜色；等比 contain 布局。没有通用物体碎裂、任意容器、自动文字换行、真实物理求解或工作台适配器。长标签需调用方检查文字区。

## 实际调用

先加载 ../../custom/runtime.js、../../custom/state-meter.js。调用 stateAt({frame,events,params,seed})，再由 PixelCustomRuntime.place 把 PixelStateMeter.draw 放进目标 bounds。试样 HTML 使用同一源码，浏览器直接打开即可，无网络依赖。

参数或视角改变重新检查对应范围；可编辑工程接入按 [CUSTOM-RUNTIME](../../CUSTOM-RUNTIME.md) 实现 scenes 适配器。本例保持 standalone，不增加 shot.components.kind。
