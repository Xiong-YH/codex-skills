# 普通片段：少字与组件风格延续

[打开机械／能量交互对照](index.html) · [对照截图](comparison.png) · [原版同状态取帧](original.png)

## 这次解决什么

用户反馈“很多地方文字信息太多了”，偏好“少量文字结合背景”，并要求普通片段保持静背景，通过组件物体或视角变化推进。8秒《通知与专注》试片已有三句字幕和一次转场，但自定义前景未延续既有机械／能量表现。用户要求查看同一组组件采用这些风格的样子，并在对照后确认“好了，这块的问题你帮我沉淀进去吧，可以把无关文件也清理掉”。

| 对象 | 机械版 | 能量版 |
| --- | --- | --- |
| 任务纸板与铅笔 | 黄铜齿条、传动笔架和承托滚轴 | 保留纸面，玻璃导轨与窄光带指示步骤 |
| 手机及开关 | 拨杆联动，关闭通知后锁定 | 关闭通知通路，信号仓变暗 |
| 通知气泡 | 黄铜夹固定的纸质通知条 | 玻璃载体，激活时局部点亮 |

两侧使用相同布局、尺度、文案及事件。切换“消息打断／关闭干扰／任务完成”，可看同一对象的状态；也可播放、拖动、关闭背景或查看纸张转场中途。齿轮沿用已选黄铜原图；背景复用工坊素材，均由技能内相对路径加载。

## 认可与验证范围

- 本轮认可覆盖少字、状态推进及自定义组件延续既有风格的方向，以及展示的这组造型；原始8秒试片不因此补记全片通过。
- 当前为固定正面视角、固定对象与输入的 SVG 局部试样。示意光路表示激活与任务步骤，不是精力或效率的测量。
- 已实际检查三种状态、背景开关、转场按钮、从头播放至末态、同帧往返一致、窄屏无横向溢出及浏览器无脚本异常；检查同框截图的主体、文字和状态。未进行新工作台编辑、分轨导出或成片审片，也未验证任意位置、视角或内容。
- 本页未注册为 `shot.components.kind` 或通用工作台组件。迁入新工程时按 [实现协议](../../CUSTOM-RUNTIME.md)接入并核验。
