# 请求加工站与等待缓冲架

2026-11-01，用户对两片段 HTML 反馈“还挺不错的，就按照这种来吧”，并明确更喜欢根据当前片段内容设计自定义组件；没有合适方案或已有组件很贴合时不定制。当前偏好唯一维护于 [DESIGN](../../DESIGN.md#当前创作偏好)。

[原样保留的可播放 HTML](index.html)内含两个片段的十六维脚本与九维外观约定，以及 C01/C02 独立样式和关联演示。为用户认可版本的自包含副本，无外部依赖；不是新增加工或队列 kind。

## 适用范围

- 机械风格：深铁导轨、黄铜夹具、分层承载，固定略俯视正面；不混能量辉光，不把机械配色推广为全片默认。
- C01 单件加工站：原筹码入位、夹持盖章、送出，保留编号；C02 等待缓冲架：有限双层槽位，按顺序等待和移交。调度由页内场景组织，两组件共享局部时间驱动。
- 本例仅两套有限输入：4 件、到达间隔 1.5 秒；12 件、间隔 0.36 秒；处理周期均为示意的 1.2 秒。结束时分别完成 4 件，以及完成 4/处理中 1/等待 7；不是实际性能测量。
- 认可覆盖本次脚本到组件的设计方向与本页视觉效果；不扩大到任意数量、任意队列策略、其他视角或通用物理机制。

## 核验与边界

原试样在 Edge 下已检查 722 个局部取帧状态的计数/身份守恒、到达和处理分区，倒拖同帧像素一致、重播、片段切换及 390px 页面无横向溢出；桌面关键帧已查看。此收纳副本与认可源字节一致，不把拷贝当作再次浏览器验收。

当前为 standalone HTML，无声音、无工作台适配、无正式成片。用户认可与技术核验分开记录；后续修改重新核验变化部分。正式复用时按 [实现协议](../../CUSTOM-RUNTIME.md) 提取组件、绑定项目事件并补场景适配，不直接将本页 ID 写入 shot.components.kind。
