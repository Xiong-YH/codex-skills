形态
固定三分之四视角的木托盘与同一组筹码，使用已确认的像素原图。
动作
一次短弧线转移；主运动20帧（0.33秒），落位收尾6帧（0.10秒），随后保持。
分层
托盘底面／后壁 → 筹码 → 前壁／近侧壁。前景层按原图实际斜向轮廓裁取，不再使用水平条带。
合理性
落点由托盘内部平面定位；同一组筹码仅绘制一次。换布局时，落点和遮挡轮廓随容器一起变换。
边界
本例验证固定视角下的整组转移与遮挡。换角度、换托盘形状或逐枚搬运，需要各自的素材与约定。
