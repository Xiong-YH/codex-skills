# 新组件接入

先用最小镜头验证对象、触点和末态，再决定复用或注册。跨对象与人物表演由场景和时间线编排。组件拥有自己可见的形态与局部状态。

1. 用 [R41 组件美术](../style/COMPONENT-ART.md) 决定表面、厚度、读点和遮挡。优先复用 `look.js` 的阶梯边、纸层、像素图标和裁切辅助。
2. 组件以现有帧号和本镜事件求值。连播、逐帧和倒拖到同一帧应一致。
3. 新的引擎 `kind` 同步更新模型、组件合同、目录和执行器。加一个能编译、能编辑的 [图册样例](examples/guide/README.md)。
4. 核对工作台的属性编辑、保存重开与导出。若用项目本身的独立素材，写清该镜的资产、触点和可编辑范围。
