# 自定义组件实现与接入

设计方法唯一维护于 [DESIGN](DESIGN.md)。本页约定新的独立 Canvas 组件怎样让试样与后续场景适配共用实现；不是新增 VideoSpec 字段，也不自动加载项目任意 JavaScript。旧实例保持原接口，修改时按需加适配层。

## 三层分工

| 层 | 拥有什么 | 不拥有什么 |
| --- | --- | --- |
| 组件定义 | 参数校验、局部状态、子对象身份和局部绘制 | 全片时间、背景、人物、字幕轨、音轨 |
| 场景适配器 | 把实际镜头事件、素材、样式、位置尺寸传给组件；跨对象业务关系 | 第二套组件绘制器或独立计时器 |
| 试样播放器 | 本例事件表、播放/暂停/拖动、布局、背景与调试信息 | 引擎注册、正式审片状态 |

新组件提供 `stateAt(input)` 与 `draw(ctx, state, options)`；绘制只使用局部坐标，素材和样式通过显式配置传入。也可沿已有模块接口封装，但保留纯状态求值和帧驱动原则。

共享辅助实现为 [custom/runtime.js](custom/runtime.js)：`progress(frame, events, start, end)`、稳定 `noise(seed, id)`、`place(ctx, bounds, designSize, draw)`。它只做确定性插值、稳定扰动与等比布局，不替组件决定表达机制。不在这里堆积天平、碎裂、充能等题材或业务状态。

## 时间与状态

- frame 和 events 使用本镜局部整数帧；事件表从项目唯一时间源转换。组件不能写死本片帧数，试样事件表与正式项目分别提供。
- 状态由当前帧和输入直接计算。避免 Date.now、绘制次数累计、Math.random、内部 requestAnimationFrame 或定时器；粒子轨迹用稳定 ID/seed，在任意帧直接求值。
- 完成后保留末态；事件前保留初态。复位或循环由明确事件/参数决定，不因播放器回调自动重播。
- start/contact/settled 是语义例子，不要求每个组件都用同一组事件。校验所需事件、顺序、有限数值、计量边界及本组件约束；缺项报错。
- 展开或形变需要中间态；转移保持身份和唯一归属。表达产生/复制/消耗时明确依据，不强制所有语义都数量守恒。

## 空间、素材与输入

局部坐标统一定义主体、接触点、落点与遮挡，再用同一变换映射到目标 bounds。place 默认等比 contain；响应式重排由组件单独设计并验证。子对象运动与整体位置变换分开。

绘制器不清空整个 Canvas、不自行画环境、不发声，不改变调用者 context 状态。文字、数量、种子、材质和事件引用按本例需求暴露，不必开放所有内部参数。素材从项目或 library 显式传入，来源和裁切边界留记录。离散动作按 [motion](../motion/TIMING.md) 决定。

完整示例：[state-meter.js](custom/state-meter.js)、[可播放试样](examples/state-meter/index.html)、[设计与边界](examples/state-meter/design.md)。这是接口示例，不要求所有组件采用仪表、条块或风险反转。

## 正式工程接入

| 项目需要 | 实际路径 | 必须说明 |
| --- | --- | --- |
| 局部概念或动作 | 独立 HTML，复用组件源码 | standalone，不宣称工作台可调用 |
| 内部参数可编辑并随镜头取帧 | 在 scenes 注册适配器，引用同一组件实现 | 补 catalog/contract、编译输入、依赖哈希、工作台 props 与绘制加载，不能只加元数据 |
| 已确定的完整画面素材 | 按 [项目媒体合同](../scenes/MEDIA.md) 接入 image/video | 内部对象不可编辑；replacement 覆盖场景/人物，需正确合成，不是透明覆盖万能入口 |

正式接入沿 [模块维护](../../references/module-development.md)，验证 build、工作台初始一致性、参数编辑、保存重开、拖动/时长变化与最终导出。素材烘焙不满足内部参数可编辑要求，不能作为静默回退。设计附件、HTML 或自定义 ID 不能直接塞进 shot.components.kind。

## 收纳与兼容

- 项目专用组件先留项目；可复用定义进入 components/custom，场景业务关系留 scenes。素材身份归 library，几何运动按实际复用再迁 motion。
- 例子调用实际组件源码，使用相对路径，必要运行依赖随 skill 保留。
- 新独立条目登记到现有 [物体目录](object-components.json)，补充说明放 capabilities.json；不建平行注册表。工作台接入完成后按真实执行字段记录能力。
- 兼容变更保留 ID；破坏参数或状态含义时用新版本。历史认可、本次技术/视觉验证分别记录。
