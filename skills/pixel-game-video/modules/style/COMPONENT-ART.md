# 组件美术：实体、硬边与可读状态

本系列默认采用 [R38 参考](../../references/current-style.md) 的组件表达：可操作的纸签、纸页、聊天窗、按钮、托盘与读数装置，硬边像素轮廓、克制厚度与明确状态。按本段关系设计轮廓，不把内容全部装进同一种矩形。

组件独立于场景画风选型，人物的超粗颗粒不强加到中文字和所有面板上。项目已有决定优先，具体色相、材质与装置不成为全仓默认。

## 从对象职责决定画法

| 要素 | 默认做法与核对 |
| --- | --- |
| 轮廓 | 先用清楚的阶梯边与大明暗面建立形体，少量像素簇补倒角、接缝；缩到实际占画尺寸仍能辨认，不靠马赛克滤镜或碎纹。 |
| 材质 | 纸有薄边、折沿或层片；托盘有开口、前沿与内槽；聊天窗有边界和消息裁切。只有解释确需时才增加金属框、玻璃和能量效果。 |
| 厚度 | 卡片薄于承载装置，堆叠时看得出旧纸边；`stack` 关闭不加复制侧壁。不要用巨大挤出或重影表现实体。 |
| 光与色 | 同镜主光稳定，少量离散色阶分面；颜色表达常态、重点、待处理和完成。R38 的纸色、深绿、暖金与浅绿可作为配色起点，题材可另定。 |
| 接触 | 先定接收边、落点和前后层；纸进入托盘后被前沿真实遮住，按钮按下才改状态，承载面不悬空。 |
| 主次 | 当前对象、触点或读数最清楚；背景、框架与辅助反馈降亮。气泡和碎屑不遮主数值，闪光／反射不洗掉字。 |
| 文字 | 标题、数值、单位、标签分层；留足长标签与位数变化空间。字在组件落位后完整显露，结果保留阅读。 |
| 连续性 | 同物跨镜保留文字、轮廓与身份色；变化有事件依据，任意帧和倒拖不产生额外副本。 |

像素网格、色阶、厚度按输出尺度确定；原片尺寸不复制为通用参数。薄纸、无材质图形也可成立，不为“质感”额外加机械结构。

## 制作前的最小约定

在现有组件设计中写清：解释对象与状态、轮廓／视角／相对尺度、主辅材质与颜色职责、文字区、接触点和遮挡层、起态到末态保持的特征。复用、组合还是定制按 [组件设计](../components/DESIGN.md) 判断。

代码绘制先实现状态与接触，再抽取真正共用的绘制辅助；素材生成按动作准备前后层、锚点与完整状态，文字单独绘制。图片生成须读当前图像工具技能，生成后看真实图及背景同框。

## 能力与验收

原片动态参考只证明本片表现。[基础组件图册](../components/examples/style-atlas/README.md) 提供正式执行器的纸质、朴素、机械与能量配置；后两类在题材需要时选用。[自定义协议](../components/CUSTOM-RUNTIME.md) 用于新机制，独立试样不自动成为引擎 kind。

用同一份实际内容核对起态、触点、末态和连续播放：落点成立、遮挡正确、焦点清楚、结果可读。更换文字长度、素材、机位或布局后复查变化范围。旧八组件美术认可保留在 [基线记录](../../references/iteration-history.md)，不替代当前片段验收。
