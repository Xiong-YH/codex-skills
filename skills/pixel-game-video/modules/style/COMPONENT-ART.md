# 组件共同画风：材质、体积与接触

**适用边界**：本页是组件自身的独立美术规范，不继承项目主画风或片段画风。八类场景画风的选择不得覆盖组件的颗粒、配色、材质、厚度、造型或投影；与背景同框只检查位置、遮挡、接触与阅读协调，不因场景换画风而给组件换皮。

本规范是本视频体系新组件生成、绘制和局部改版的默认美术要求，适用于基础组件与自定义组件，代码、图片和分层素材均按实际画面核对。2026-11-01 用户认可数值管/加工站的材质、厚度、接触和主次优化，并要求形成共同画风。已确认项目或本次明确要求优先；旧执行器、图库和历史认可不因本页更新自动迁移。

它约束同一世界中的视觉语言，不固定对象轮廓、场所、色相或装置结构。风格与堆叠合法组合仍唯一归 [基础组件](../components/BASIC-COMPONENTS.md)，机制设计归 [自定义设计](../components/DESIGN.md)，动作时长归 [motion](../motion/TIMING.md)，背景同框归 [ART-DIRECTION](ART-DIRECTION.md)。

## 共同要求

| 维度 | 生成与绘制要求 | 检查画面中的证据 |
| --- | --- | --- |
| 轮廓与像素簇 | 先用轮廓和大明暗面建立对象；硬边像素簇组织倒角、接缝与反射，不靠随机噪点、马赛克滤镜或密集描边冒充细节 | 缩到实际输出尺度仍能辨认主体，斜边/亮边不忽粗忽细，运动不产生无意义像素闪跳 |
| 材质分工 | 每个对象确定主材质和少量辅材；黄铜用窄硬亮边与暖色阶，铁件用克制哑光与结构暗面，玻璃用稳定窄反射、可辨内外层，纸卡用薄边和轻微层次 | 不只靠换色区分材料；玻璃内的介质、容器和外侧反射各自可辨；未使用的材料不强加 |
| 相对厚度 | 按真实承载职责分配厚度：卡片薄于托板，托板薄于主体。可见侧壁、层片和错位只在启用堆叠或自定义明确需要时出现 | 不对所有对象统一挤出；无重影复制；不以壳体加厚代替层次。stack 关闭时不偷加侧壁，正面受光可以保留 |
| 受光与色阶 | 同镜明确主光方向，反射、顶面、侧面与暗部遵守同一光源；用少量离散色阶区分平面 | 不把每条边都打亮；侧面亮暗随相机/结构关系成立，不随物体转动随意换边；旋转面、固定轴座与侧壁分开处理，不能整组随轮面旋转 |
| 接触与承载 | 先确定接触面、落点、容纳平面与真实遮挡，再画动作；支脚/夹具/托板连接可信，必要处加短而贴面的接触阴影 | 底座不悬浮，压头触到卡面而非穿入；对象落在承载面上。允许悬挂、漂浮的内容有明确依据，不一律加地面阴影 |
| 视觉主次 | 读数、目标物和实际触点优先；框架、边缘和背景降低对比与细节密度。能量亮部限于介质、通路和触点，范围随尺寸克制 | 辅助机构不比解释对象抢眼，辉光不洗掉文字、轮廓和单位；小尺寸仍有清楚的第一焦点 |
| 颜色职责 | 常态、重点、警告、完成等颜色先定含义，再应用到相关对象；亮度层级和材质色相分工，不把“变红”当成所有失败的默认动作 | 状态有文字/形态辅助，警告不引起无关部件换材质；不同片段不无意换皮。不要求所有项目深铁/黄铜或深色背景 |
| 文字与阅读 | 为标题、数值、单位和标签保留独立可读区域，运动部件和遮挡不侵入；文字角色复用 text | 更换位数/长标签后无裁切；装饰/反射不穿字；关闭装饰仍保留信息结构 |
| 时间中的一致性 | 同一对象在变化前中后保持身份、材质、厚度和光源；状态有依据地改变外观，接触后的结果稳定保留 | 任意帧、倒拖与连续播放一致；没有额外副本、瞬间换材质或不受控制的循环 |

材质色阶数、像素网格和厚度数值由输出尺度、视角与对象决定；试样中的 2/3/5px 和压头修正不是通用参数。朴素组件、纯文字或无材质信息图可采用更少层次，不为遵守本规范额外加装置、金属或立体效果。

## 每次生成前，先写一份美术约定

脚本已有组件外观表时直接补全并引用，不再维护第二份相同定义。共用约定可按 ID 继承，变化部分写清。至少决定：

- 对象和解释任务、视角/轮廓/相对尺度、基础或自定义身份。
- 风格与组织方式、堆叠开关；哪些面有厚度，哪些只是正面明暗。
- 主辅材质、像素尺度、主光方向、颜色职责、第一焦点与文字安全区。
- 接触点、容纳平面、分层遮挡、运动前后哪些外观保持，素材及实现缺口。

**代码绘制**：先实现布局、接触点和状态，再提取实际共用的材质/承载绘制辅助，复用同一语义角色。不要为各 kind 复制一套画风补丁，也不要为了统一材质改写各组件的机制。确定性求值和事件绑定沿组件实现协议。

**图片或分层素材生成**：把上述约定转换成可见形态描述，附当前背景/已认可样板作为相关质感参考；按动作需要明确透明边缘、前后层、锚点和必要中间态，文字分开排。实际使用图像工具前读取其技能。生成后检查真实图和同框效果，不能把提示词正确当作结果合格。

可用的提示结构：本段解释任务＋对象轮廓/视角/尺度＋材质及硬边色阶＋光源/厚度/接触面＋主次与文字区＋背景同框＋分层/状态需求。只带本对象需要的材料，不将整份材料表或示例场景机械粘贴到所有提示词。

## 验收与参考迁移

先看轮廓和缩小后的可读性，再看材质/厚度与接触特写，最后看实际背景和连续动作。至少覆盖本次使用的起态、触点、末态，以及实际目标尺度；更换内容长度、视角、素材或布局时验证变化范围。阴影、反射或厚度增加后，重新检查遮挡和文本。

对照试验保持内容、时间与缩放一致，原版取真实执行源；几何触点等确需变化时明确标注。共同辅助在多种轮廓上成立，才提炼成可复用实现；审美判断不能由像素差或测试通过替代。

**当前认可范围**：2026-11-01 用户对八组件对照明确反馈“整体过了我这关了”。认可覆盖数值管、加工站、流程链、检查清单、层级结构、等待缓冲架、黄铜齿轮计数器和机械流程链所展示的共同画风。查看 [认可的八组件对照页](examples/component-art-system/index.html)及[版本与认可范围](examples/component-art-system/scope.md)。更早的 [两组件对照](examples/component-art-baseline/index.html)保留为历史快照。认可的美术方向作为后续生成默认要求；不将固定内容、视角和布局推广为任意新结果已审，也不表示正式执行器已迁移。

**原参考库待后续整体重构**：本轮保留旧图片、合集、ID、执行器和历史认可；旧图可查信息语义与组织方式，新外观制作按本规范。后续迁移要同步基础三分支/合法样式、stack 开关、自定义实例及参考生成器，重新捕获实际执行器效果图、更新来源和验证范围，不能只批量润色旧截图。该迁移尚未完成，不把本页当作所有旧组件已经符合的证明。
