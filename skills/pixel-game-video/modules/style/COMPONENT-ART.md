# R41 组件美术规范

以《提问的艺术》R41 的原帧和动作作为这套组件的美术基准。按 [实际选段](../../references/asking-motion-reference.md#按镜头任务选段) 核对用法，按 [组件图册](../components/examples/style-atlas/README.md) 看现有执行结果。人物、台词和场景素材由各片提供。

## 形状、色彩与尺度

| 元素 | 画法 | 原片对照 |
| --- | --- | --- |
| 装订页 | 纸面用 `#edddba`，细边 `#bca881`，顶边窄亮线 `#fff1d0`。左侧装订带和纸上竖线分开，三层纸沿沿右下各错约 3 × 4 px。 | 00:57 对照页，01:42 总结页 |
| 资料卡与纸签 | 卡片有独立纸沿和投影。纸签可用浅绿 `#adc9ae` 表示已确认，暖色 `#deb783` 表示重点，深绿 `#405e56` 表示常态，淡绯 `#d7b0a1` 表示未成。小尺寸仍要看见边线和压住的阴影。 | 00:18 课程卡，01:00 项目经历纸签 |
| 章节牌与聊天窗 | 主面深绿 `#233b38`，边线 `#84a087`。标题用暖白。章节牌增加层次与窄内框。聊天分深绿来信和暖纸回话，头像、气泡、文字各占自己的位置。 | 00:10 聊天，00:36 片名 |

| 操作台 | 设备外壳、屏幕和承载面区分深浅。卡在屏幕里，按钮独立，按压才改变语句与状态色。 | 01:38 练习进行中 |

数字和汉字用清晰字形。纸面常用字色 `#35524a`，次要字色 `#638274`。在 1280 × 720 的对照画幅，纸卡边线约 2–4 px，转角两级，每级约 3–5 px。大号标题的立体暗边集中在下沿。人物颗粒更粗，两层看起来仍属于同一场景。

缩放按画高等比，文字、图标和边沿由执行器重绘。纸张层次按实际用量决定，实物厚度也随承载关系改变。图标指向实际对象或动作，同一画面留一处首要关注。

## 运动与阅读

| 发生什么 | 怎样看见 |
| --- | --- |
| 资料落位 | 从能解释来源的方向进入。边沿靠近停稳时亮字，收藏章在卡片之后单独落到对应位置。 |
| 新消息进入 | 良好阅读位置先留给最新消息。旧消息作为一列上推，窗口内裁切。人物与音效使用同一事件触发。 |
| 收件和计数 | 纸接触槽口之后由前沿遮挡。数字跟着来源变动，在终值锁住。下一个结果等主要读数能看清时再亮。 |
| 选择与点击 | 触点短促压下或扫亮，颜色改变后停在新状态。相邻对象保留足够参照。 |
| 交接 | 只带走有意义的同一张物件，保持文字、轮廓和身份色。设置去向、接住位置与新背景出现的先后。 |

一次落位、上推或盖章通常约 0.20–0.35 秒，阅读停留由镜头另外安排。特效集中在落点，用一束扫光或少量像素点收住。测试起态、触点、落稳、连续播放以及倒拖后的同帧一致性。

## 从 R41 延展

把收件槽换成借还台、档案匣或任务入口，可以复用容纳和近侧遮挡。把资料卡组合成证据页、错题夹或交接单，保留纸层与盖章的因果。把状态签设成筛选、标记或确认，就让其颜色与现场动作对应。每种新用途先确定承载对象和触点，再选纸、设备或实物结构。
