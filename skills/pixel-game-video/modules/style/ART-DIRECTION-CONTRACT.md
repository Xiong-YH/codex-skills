# 场景画风与分层美术合同

本系列新片以 [当前风格](../../references/current-style.md) 为默认：人物采用超粗像素游戏精灵，环境与场景道具采用更丰富的粗像素表现，组件遵循自身美术规范，文字独立排版。本次要求和项目已确认美术优先。

## 在一处记录本片决定

在 `brief.constraints` 保存项目画风与实际参考；片段特选写在 `storyboard.shots[].intent`，标清涉及镜头与返回主风格的位置。不扩展 JSON schema，不在四份创作源重复决定。

当前默认组合可写为：“超粗像素人物＋粗像素环境／道具；人物以完整姿态表演；组件按独立规范；文字保持清晰阅读。实际样张与来源保存于 media/art-direction/。”人物、环境的颗粒可有明确分工，同框统一光源、相对尺度、支撑与遮挡；不能随机混用不兼容的画法。

素材制作前取得这份约定，再补角色身份、场所、动作、镜位和接触。不能由各分支自行重选风格。新图必须在实际输出尺度同框核对；提示词与参考方向不能代替生成结果或认可。

## 人物、环境、道具与组件

| 分支 | 要落实的内容 |
| --- | --- |
| 人物／物种 | 身份剪影、主色、朝向、完整姿态与支撑／操作部位。超粗精灵允许头身压缩、符号化手脚与小结构省略，仍保持对象归属、触点和状态可辨。其他造型按其真实结构检查，不套用人类肢体或精灵比例。 |
| 背景 | 场所、机位、前中后景、主光、承载面与动作区，预留组件和主句空间；不把角色和文字烘焙到背景，不默认复用旧房间。 |
| 场景道具 | 用途、开口、视角、抓握／承托点、遮挡和末态；小笔等关键操作物按辨识度细化，不以颗粒统一为由删掉触点。 |
| 组件 | 按 [组件美术](COMPONENT-ART.md) 独立设计材质、厚度、状态色与文字区；场景换画风不自动给组件换皮。同框检查尺度、光源、接触与阅读。 |

超粗人物按 [当前风格](../../references/current-style.md) 的动作示例确定粒度与反应，用本片角色基准与完整姿态保持身份。姿态、位移与接触分别验证。

## 明确需要其他画风时

[八类完整画风目录](PIXEL-STYLES.md) 保留为可选资源，不是默认问卷或新片起点。完整单风格可用解析器展开：

```sh
node modules/style/resolve-art-direction.cjs ultra-coarse
node modules/style/resolve-art-direction.cjs chunky four-tone
```

解析器输出 `art-profiles.json` 中完整单风格的四分支提示词、版本／哈希与样板路径，不会读自然语言决定，也不会把当前人物／环境组合自动合成新预设。选择组合时在项目写齐分层约定，按需要分别取对应分支描述后做同框试样。目录 ID 不是引擎 `style.*` recipe，不能直接写进 `production-plan.style`。

素材与交接保存实际采用的规范、样图、来源和哈希。导演写观看任务，制作绑定真实素材和实现，审片看完整母图与连续合成；旧执行器、候选图和先前认可不自动覆盖新结果。
