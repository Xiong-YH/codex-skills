材质区分

预期收益：玻璃靠透光和反射、黄铜靠硬亮边、铁件靠哑光面，减少仅凭颜色辨材质。

厚度分级

预期收益：薄卡片、托板、主体各有厚度；空间层次服务结构，不让所有零件都像积木。

接触关系

预期收益：物体与承载面之间有落点和阴影；压头到卡面即停，减少穿入对象的观感。

视觉主次

预期收益：减小外围辉光与支架亮边，让介质读数和加工触点成为第一焦点。

具体改了什么，以及保留什么
对象调整前 → 试验版保持不变
数值管宽泛高亮 → 窄反射与内外介质色阶；端帽改成黄铜分区；底座减少重复错层，补落地阴影。energy、inset、stack，数值起终点、管体尺寸、读数区域与节拍。
加工站所有部件统一 6px → 卡片 2px、薄件 3px、机架 5px；夹具补硬边反射、铁架降低对比。同一门架与请求编号、进料/加工/送出阶段和 1.2 秒示意周期。
压头触点原下压幅度 26px → 按卡面位置修为 19px；补卡片和轨面的接触阴影。触发时间、压持时间、回位节奏与请求归属；这项明确改变几何落点。
像素尺度保留硬边绘制，采用离散材质色阶；不添加随机噪点或模糊照片纹理。两侧同分辨率与同缩放；本轮不宣称已统一整个组件库的像素网格。
