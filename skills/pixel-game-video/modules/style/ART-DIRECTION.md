# 风格基调与可变背景

场景画风定义人物、物种、背景和场景道具的共同视觉语言；组件按自己的合同独立制作，文字排版另行决定。背景是参与解释的画面内容，由本镜任务设计。延续已确认画面或只做局部修复时保留相关素材；新主题重新判断场景是否适合，不自动继承旧片的背景组合。

<a id="background-design"></a>

## 先构思画面，再寻找素材

空间、尺度、景别和解释任务由分镜/场景决定，按 [空间设计与素材选择](../scenes/SPACE-DESIGN.md) 执行；本页维护共同美术语言。

## 可复用的基调

先按 [像素样式选型](PIXEL-STYLES.md) 确定本项目的颗粒、比例、轮廓和色阶。下面的低饱和与冷暖分工是既有基调的一种做法；选择明亮、限色或其他样式时，以项目决定为准，仍需保证层级、空间和同镜一致性。

- 像素形体：使用清晰的像素簇组织轮廓、体积和材质，避免仅用马赛克滤镜处理普通插画。
- 色彩职责：低饱和基底承载空间；少量暖色强调重点，冷色区分辅助信息；警示色只表达相应状态。具体色相按项目选择。
- 光影关系：明确主光方向、主体与背景的明暗层次；局部亮点支持当前焦点，不能让背景细节持续争夺注意力。
- 空间关系：前中后景、透视、接触阴影和遮挡一致；独立人物、道具与背景的颗粒和受光协调。
- 构图：先确定主体、组件和字幕的位置，再生成背景的留白；不把所有镜头固定成同一张空墙。
- 可替换性：标题、字幕、标签与背景分层，避免把文字或固定主持人烘焙进背景素材。

组件生成与改版的共同美术要求见 [组件共同画风](COMPONENT-ART.md)；本页继续拥有背景同框方法，不复制各材质和承载规则。

## 场景分支统一，组件独立

按 [透传合同](ART-DIRECTION-CONTRACT.md) 取得片段有效画风，将同一套颗粒、造型、色阶、受光与投影要求传给人物、其他物种、背景和场景道具。先检查实际母图及同框结果，不以提示词代替视觉验收。

组件的美术由 [组件共同画风](COMPONENT-ART.md) 与组件自己的选型独立决定，场景画风不得向它透传。合成时安排位置、遮挡和阅读层级；不以背景的颗粒、配色或投影去覆盖组件样式。场景中的普通桌椅、包裹等道具仍须遵守有效画风；对象归属按制作职责判断，不仅凭外形像物体或面板决定。

## 样板及学习范围

画风差异先看 [可爱与粗像素的完整背景对照](references/index.html#background-comparison)：同一工坊、相近相机与布局，观察七项画法维度，点击可看原图。完整候选已生成，待用户审美确认；其他六类仍主要使用整景与局部观察，不将旧裁片当干净背景。对照中的题材、日光和留白不成为项目默认。

以下素材用于观察像素簇、材质、光影和空间层次，兼供合适镜头复用。它们不构成场所白名单；无需从中选一张作每支片的起点，也无需生成同样的房间。具体题材、配色和角度不提升为全仓库默认。

| 样板 | 学习什么 | 可以改变什么 |
| --- | --- | --- |
| [工坊](../library/backgrounds/engineering-workshop-v1.png) | 冷暖局部光、设备材质、主体留白 | 场所、设备、视角、光源位置 |
| [档案馆](../library/backgrounds/research-archive-v1.png) | 深浅层次、安静中央空间、边缘细节 | 建筑、货架内容、时间与景别 |
| [俯视桌面](../library/backgrounds/route-atlas-v1.png) | 实物边缘、工作区层级、俯视构图 | 桌面材质、道具、主体占位 |

生成提示词结构：本镜内容与解释任务 + 所需像素视觉语言 + 场所/尺度/景别/主光 + 主体和组件占位 + 字幕安全区 + 分层要求。仅在有帮助时带样板作为质感参考，避免把它的构图和场所一并复制。调用当前可用图像生成工具前读取其 skill；生成后核对实际图片的明暗、留白与颗粒，提示词不能代替已生成素材。
