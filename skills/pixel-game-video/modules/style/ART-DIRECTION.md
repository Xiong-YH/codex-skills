# 风格基调与可变背景

风格预设定义颜色职责、像素质感、文字与组件层级。背景是每镜可选择的内容，不是预设必须绑定的永久图。沿用旧项目时保留其现有背景；新项目可根据本镜任务生成、使用用户素材或选择样板。

## 可复用的基调

- 像素形体：使用清晰的像素簇组织轮廓、体积和材质，避免仅用马赛克滤镜处理普通插画。
- 色彩职责：低饱和基底承载空间；少量暖色强调重点，冷色区分辅助信息；警示色只表达相应状态。具体色相按项目选择。
- 光影关系：明确主光方向、主体与背景的明暗层次；局部亮点支持当前焦点，不能让背景细节持续争夺注意力。
- 空间关系：前中后景、透视、接触阴影和遮挡一致；独立人物、道具与背景的颗粒和受光协调。
- 构图：先确定主体、组件和字幕的位置，再生成背景的留白；不把所有镜头固定成同一张空墙。
- 可替换性：标题、字幕、标签与背景分层，避免把文字或固定主持人烘焙进背景素材。

生成提示词结构：项目固定基调 + 本镜场所/景别/主光 + 主体和组件占位 + 字幕安全区 + 分层要求。调用当前可用图像生成工具前读取其 skill，带适合的样板作风格参考。生成后核对实际图片的明暗、留白与颗粒；提示词合格不代表图片合格。

## 每镜素材合同

timeline.shots 可设置 background 或 replacement，字段为 `file,kind,fit,anchorX,anchorY,dim,trimStartSeconds,shortage`。file 只引用项目 media/ 内文件，kind=image/video。背景替换保留场景与人物；replacement 覆盖场景/人物，保留组件与字幕。未设置时沿用原风格背景。

视频按镜头局部时间确定性取帧，源声音不加入混音；保留原旁白/音效。默认不足时长报错，显式 shortage=hold 才保持尾帧。图片不使用视频裁切字段。素材字节参与 inputHash、交接和独立导出。源片段不能依赖个人绝对路径。

`style.pixel-editorial.v1` 的无图底色只是组件排版的备用底，不代表完整背景美术。新环境通过项目素材提供，不需要为每张新背景改 style 的 catalog/runtime。生成提示词与来源说明建议保留在项目 media 的同名元数据文件，输出、缓存和试稿遵循仓库忽略规则。
