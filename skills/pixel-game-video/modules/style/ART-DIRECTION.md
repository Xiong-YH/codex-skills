# 风格基调与可变背景

风格预设定义颜色职责、像素质感、文字与组件层级。背景是参与解释的画面内容，由本镜任务设计。延续已确认画面或只做局部修复时保留相关素材；新主题重新判断场景是否适合，不自动继承旧片的背景组合。

<a id="background-design"></a>

## 先构思画面，再寻找素材

开始新主题时，先设想“这句话发生在怎样的世界里、从什么位置看、哪个对象在变化”，再查看已有素材能否承担它。先翻固定图库容易把新主题压回几张熟悉的房间。

把本镜场所或空间载体、观察尺度、景别、主光、主体位置及解释作用写进分镜意图；导演工程沿用 storyboard.visual 的 subject/action/continuity，不增加另一份时间线。实体场所、物体内部、界面空间、像素化概念空间与图解都可选。设计需能通过实际素材和已实现的场景／组件落地；新的动态机制仍要另行实现与核验。

可从以下方向打开构思，按主题取舍：

| 设计维度 | 可以探索的变化 |
| --- | --- |
| 观察尺度 | 人与环境、工作对象特写、设备或数据内部、俯视全局、关系示意 |
| 空间载体 | 日常场所、自然环境、实体装置、软件界面、概念空间、混合图解 |
| 景别与视点 | 远景建立关系、中景观察操作、近景看状态；正视、侧视、俯视按解释选择 |
| 光与色 | 根据焦点和情境安排冷暖、明暗、时间与局部色彩，不把一套灯光复制到所有场景 |

这些是构思方向，不是必须轮换的场景清单。连续内容可以留在同一环境，用有意义的对象与状态变化推进；同一空间换色或换裁切也不自动构成新的解释。背景数量、新图比例和切镜次数均不设固定配额。

已有图恰好适合时可以复用；不适合时，生成或制作本项目素材。选定的 PNG/JPG/WebP 或视频放入项目 media/，直接通过每镜 background/replacement 接入，无需先扩充风格预设里的 environment 名称。专用场景如有覆盖限制，按其合同选择自由画布或补实现，不能用默认房间冒充已经完成的场景设计。

## 可复用的基调

- 像素形体：使用清晰的像素簇组织轮廓、体积和材质，避免仅用马赛克滤镜处理普通插画。
- 色彩职责：低饱和基底承载空间；少量暖色强调重点，冷色区分辅助信息；警示色只表达相应状态。具体色相按项目选择。
- 光影关系：明确主光方向、主体与背景的明暗层次；局部亮点支持当前焦点，不能让背景细节持续争夺注意力。
- 空间关系：前中后景、透视、接触阴影和遮挡一致；独立人物、道具与背景的颗粒和受光协调。
- 构图：先确定主体、组件和字幕的位置，再生成背景的留白；不把所有镜头固定成同一张空墙。
- 可替换性：标题、字幕、标签与背景分层，避免把文字或固定主持人烘焙进背景素材。

以下素材用于观察像素簇、材质、光影和空间层次，兼供合适镜头复用。它们不构成场所白名单；无需从中选一张作每支片的起点，也无需生成同样的房间。具体题材、配色和角度不提升为全仓库默认。

生成提示词结构：本镜内容与解释任务 + 所需像素视觉语言 + 场所/尺度/景别/主光 + 主体和组件占位 + 字幕安全区 + 分层要求。仅在有帮助时带样板作为质感参考，避免把它的构图和场所一并复制。调用当前可用图像生成工具前读取其 skill；生成后核对实际图片的明暗、留白与颗粒，提示词不能代替已生成素材。

## 每镜素材合同

timeline.shots 可设置 background 或 replacement，字段为 `file,kind,fit,anchorX,anchorY,dim,trimStartSeconds,shortage`。file 只引用项目 media/ 内文件，kind=image/video。背景替换保留场景与人物；replacement 覆盖场景/人物，保留组件与字幕。未设置时沿用原风格背景。

视频按镜头局部时间确定性取帧，源声音不加入混音；保留原旁白/音效。默认不足时长报错，显式 shortage=hold 才保持尾帧。图片不使用视频裁切字段。素材字节参与 inputHash、交接和独立导出。源片段不能依赖个人绝对路径。

`style.pixel-editorial.v1` 的无图底色只是组件排版的备用底，不代表完整背景美术。新环境通过项目素材提供，不需要为每张新背景改 style 的 catalog/runtime。生成提示词与来源说明建议保留在项目 media 的同名元数据文件，输出、缓存和试稿遵循仓库忽略规则。
