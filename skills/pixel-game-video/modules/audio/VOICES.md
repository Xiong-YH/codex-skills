# 解说小帅音色与口播计时

剪映专业版的「解说小帅」（中文·平淡）对应内部参考 ID `voice.jieshuo-xiaoshuai.v1`。采用该音色计时的项目使用下列同一套口径。

- 用户提供的试听文件保留原始字节。 [原始试听样本](assets/voices/jieshuo-xiaoshuai-demo.mp3)
- 历史选择、台词、文件哈希和媒体参数可核对。 [音色记录](assets/voices/jieshuo-xiaoshuai.json)
- 带对应台词的剪映原始导出。 [剪映朗读样本](assets/voices/jieshuo-xiaoshuai-generated.mp3)

## 1 倍速估时与校准

1. **接稿先算口播预算。** 解说小帅 **1.00×** 的发音基准为 **6–7 个折算字／秒**。只有文字时，先用折算字数除以 **6.5** 估算发音时间，再按[停顿建议](#停顿建议)计入停顿。汉字按字计，数字、英文和缩写按预定读法折算，标点用于安排停顿。
2. **由讲述推导片长。** 顺着分句确定讲述起止和换气位置，镜头内可同步发生的动作、转场和阅读共用时间。把需要独立呈现的无旁白段，以及讲完后仍需留给观众的时间，计入全片。语速和目标片长冲突时，先检查文案量和可收掉的等待，再决定片长。
3. **用本片 1.00× 音轨锁时间。** 有配音后先核对音色和倍率，以当前台词逐句实际起止及自然间隙替换估时，再同步字幕、切镜、动作和音效。改稿后复测受影响句及下游切点。记录音色、播放倍率、使用的文案版本及实测或估时状态。

[剪映朗读样本](assets/voices/jieshuo-xiaoshuai-generated.mp3)有 48 个汉字。按静音检测粗估，发音段合计约 7.62 秒，约 6.3 字／秒。计入内部停顿后跨度约 9.40 秒。实际分镜按本片 1.00× 配音的逐句时间校准。

### 停顿建议

首轮分镜按句意选取时长。每句预算为发音时间、句内停顿和句末留白之和。停顿从上一意群的发音结束量到下一意群开始。

| 停顿位置 | 建议时长 |
| --- | --- |
| 短并列、顿号 | 0.10–0.15 秒 |
| 逗号、意群切换 | 0.30–0.40 秒 |
| 一句话讲完 | 0.40–0.50 秒 |
| 对话换人 | 0.50–0.70 秒 |
| 转章节或让观众消化一个重点 | 0.70–1.00 秒 |

同一处同时承担句末、换话或转段时，取所需时长较长的一项。配音到位后量出该处已有的停顿，短于目标时只补差额。例如转段目标 0.80 秒、配音已有 0.45 秒时，剪辑补 0.35 秒。

## 旁白导入

按项目安排获取当前台词的配音。把已有音频转为项目内 48 kHz、16-bit PCM WAV，通过 `production-plan.narration` 或 direct 的 `audio.json.narration` 导入。默认制作流程消费已有素材，生成新配音按本次授权执行。参考 ID 仅供内部标识。混音见 [声音指南](GUIDE.md) 和 [配乐工作流](MUSIC.md)。
