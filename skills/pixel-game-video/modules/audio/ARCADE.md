# 游戏音效：六种已确认基础触点

六种已确认母版及三层素材在 [基础音效清单](assets/arcade-motion/manifest.json)，保留用户认可的PCM字节，状态为 `user-approved`。后续扩展、蓄力合成与网络参考均未获认可；本轮已停止音效探索，交付保留基础六种。实验稿不进入可选目录和交付包。音色认可与项目中的音量、密度、同步分别检查。

## 选型

| 稳定ID（variant=0） | 时长 | 动作节奏 | 选用依据 |
| --- | --- | --- | --- |
| `arcade-select` | 0.202s | 轻触→弱拍→短回弹 | 选中、焦点确认、小阶段触点 |
| `arcade-pickup` | 0.420s | 轻起→重收→小回跳 | 拾取、资源离开原位 |
| `arcade-seat` | 0.420s | 重击→短顿→回弹 | 抵达、落槽、卡片归位 |
| `arcade-launch` | 0.535s | 蓄力递进→末拍释放 | 展开、启动、空间打开 |
| `arcade-reject` | 0.430s | 顿住→回退 | 受阻、碰壁、无效选择 |
| `arcade-reward` | 0.840s | 轻重递进→收尾重音→余弹 | 真正完成、阶段结算 |

运行 `python scripts/video.py catalog audio` 获取ID、适用／避用语义、显著程度、时长、主触点、建议间隔和认可状态。先按真实状态变化选声音，再定音量与触点；同类状态保持声音一致，没有重要变化时允许留白。拾取与落位可成对使用；奖励只给明确完成。同一触点一般只选一个主音，避免叠加多次确认。

`at`定义音效开始帧，选型元数据不自动改变时间线。`arcade-launch`是已确认的短促启动／展开声，不将它当作未定稿的持续蓄力声。当前没有已认可的持续蓄力原子。

## 基础六种：电子＋鼓点＋回弹

- 电子主体保留街机音高、音程、滑动和识别性，以轻重包络增强动作感。
- 鼓点用底鼓、通鼓、手鼓或鼓边补触点、重量与弱拍，低频居中。
- 回弹从主体截取短片段，淡化边缘并收柔频带，只让安静尾音小幅展开声像。

具体包络、回弹位置／增益／声像、高频收柔量在基础清单中。包络控制点采用半余弦连接；回弹以100–2100Hz频带和4ms淡入／14ms淡出收边。三个stem已包含母版增益，以1:1:1相加可还原master（允许1个PCM量化单位误差）；不要分别归一化。后续改动从独立副本开始，试听后更新认可状态。

## 试听与混音

```sh
python modules/audio/preview.py --bank arcade --out <临时试听目录>
```

导出六种音效及试听页；`--bank arcade-core`等价。WAV为48kHz／16-bit／双声道，母版按字节复制；每种可单听电子、鼓点和回弹三层。

混音保留原始电平与立体声，应用cue.level、轻度x声像平衡、speechDuck和总线处理。`level=1,x=0.5`在压低及总线处理之前保留原幅度；旧G2仍使用原单声道规则。预留自然收尾时间。已确认原子可直接复用，项目仍需在实际MP4检查同步、音量和密度；未主观检查的项保留 `not_reviewed`。
