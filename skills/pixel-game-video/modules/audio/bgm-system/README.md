# 可复用 BGM 初版

三种原创底乐共用 120 BPM、4/4 拍和 8 小节的 16 秒循环。用同一段和声和动机写了三种节奏密度与音色。节拍不依赖某个视频的事件，换曲可保留同样的拍位，再按实际重音复核。

| 版本 | 声音 | 适合 |
| --- | --- | --- |
| `warm` 暖光 | 轻鼓与清楚的键盘动机 | 建立情境、稳定阅读 |
| `pulse` 步进 | 重一点的底鼓、军鼓和短贝斯 | 组件推进、交接和确认 |
| `calm` 归位 | 稀疏鼓点与更长的和弦尾音 | 看结果、比较和片尾 |

## 生成和复用

从基础技能目录执行下列命令。需要 Node.js 和 FFmpeg，`PIXEL_FFMPEG` 可指定已安装的 FFmpeg。使用随包 Garden 合成器和 [乐谱源](score.mjs) 生成，无外部采样。

```text
node modules/audio/bgm-system/build.mjs --out MUSIC_DIR
node modules/audio/bgm-system/build.mjs --out MUSIC_DIR --preset pulse
```

输出每种版本的 WAV 和同名 `.beats.json`，记录拍位、循环端点、采样率和 WAV 哈希。母带连续合成三轮并截取中间一轮，保留交界前的尾音。WAV 为 48 kHz、16-bit 立体声，循环边界为采样 0 到 768000，半秒一拍。需要循环时用完整 WAV，保持 `trimStartSeconds:0`。按 [配乐工作流](../MUSIC.md) 导入工程并选择淡出、增益和音乐入点。

在 60 fps 时每拍间隔 30 帧。只有音乐从文件首拍开始、速度为 1 时可直接把此网格加到工程入点。裁入、移位或变速后用实际采样位置换算，核对计划中的重拍和最终混音。原版及工作台的转场和事件音效依然独立。

## 《步进》一分钟版

```text
node modules/audio/bgm-system/build.mjs --out MUSIC_DIR --preset pulse-minute
```

保留《步进》的底鼓、贝斯和拨弦动机，新增 30 小节的完整编排。0–8 秒建立动机，8–20 秒鼓组推进，20–28 秒加入切分，28–36 秒撤掉大部分鼓并留出呼吸，36 秒主段回归，52–60 秒逐步收尾。节拍表保存六个段落起点和 120 个拍位。整首使用 `loop:false`；短片可以取任意合适乐句，并按实际入点、重拍和收尾重新核对。
