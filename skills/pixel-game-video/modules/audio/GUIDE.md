# 声音与混音：任务入口

管理声音资源、事件音效、已有旁白导入、配乐与混音，消费公共事件时间线。

## 职责边界

发声必要性由创作和实际听音判断，不因可卡点或启用游戏反馈而自动发声。本流程不自动生成配音或调用 TTS，历史音色资料不代表生成能力。

## 验收重点

实际听整段与跨镜连接，核对触点、旁白、尾音和片尾截断，按需做删音对照。同步与峰值检查不替代听感；未听音记为 not_reviewed。

全片分轨、保存重开和最终导出统一按 [工作台](../../references/workbench.md) 验证，本页不表示已完成当前项目验收。新增能力查 [模块维护](../../references/module-development.md)，职责调整查 [归属与迁移清单](../../references/module-ownership.md)。
