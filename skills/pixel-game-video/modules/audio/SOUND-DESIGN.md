# 把音效做成动作的一部分

分镜时选出观众需要听见的变化。BGM 提供段落推进、情绪和拍位。音效交代一个东西怎么动、碰到什么、状态是否改变。二者可以同拍，物件触点以可见接触帧为准。

## 给每段选声音

在现有导演 brief／制作 brief 记下本片的主音色、空间、BGM 和旁白关系，以及刻意留白的地方。在分镜声音栏写 **事件 → 观众听到什么 → 为什么需要听见**。先试包含不同类型触点和一段阅读留白的代表片段。

| 要让观众听懂什么 | 可用的声音 | 绑定的位置 |
| --- | --- | --- |
| 物件动了，或确实碰到了某处 | 用轻拟音匹配材质：纸面擦过、薄纸落位、木件沉落、机械咬合。近景可略清楚，远处可省或压轻 | 摩擦听到运动开始；敲碰听到首次有效接触或卡稳 |
| 操作有没有生效，轮到谁说话 | 发送、回复到达、轻确认、轻阻挡用不同短动机。同对象和同状态沿用同一声族 | 动作生效或新状态露出的第一帧 |
| 视线跨过了空间，或结果将要揭开 | 只有运动或揭示需要预告时才用短擦声、掠过或上扬。大节点可从既有街机声或配乐重拍择一，确需两层时分别承担冲击和材质 | 掠过用包络峰，铺垫声用末端；直切可以安静 |
| 两镜还在同一地方，或空间真的换了 | 有叙事用途时用一条轻环境底声贯穿相关镜头，跨切留尾或预入；可用工程内录音或 Garden 环境合成 | 根据空间的进入、退出和风格设置范围与淡化 |

一组连续动作先选最能传递变化的一处。比如一叠便签先给一次擦纸，真正卡住时再给轻落位；后面只是浏览就让它安静。拒绝和等待听起来应有区别：失败可以短促受阻，等待和尴尬也可以留白。整段只靠 BGM 时，在设计里写清它为何成立。

## 当前系列的常用音色

从工作台音效库顶部的「系列常用」选声。离线试听可从 skill 根目录运行 `python modules/audio/preview.py --bank series --out AUDITION_DIR`。目录里有八个动作的用法、音色 ID 和上轨起始电平。 [音色目录](catalog.json)

- 纸签抽出用纸面擦声交代运动，纸卡落位在接触帧加一声轻敲击。一组纸张连续移动时，选最有信息的一次落位。
- 选中与盖章用街机轻确认，数字锁定用街机落位声，结构展开用三段递进声。盖章跟印章压实，锁定跟终值定格，展开跟首层信息揭开。操作阻挡可从全库选力度合适的拒绝声。 [街机母版](ARCADE.md)
- 结果落空用一次短下落音，随后留时间读结果。消息发出用单音，收到回复用两声，落点跟各自的气泡出现。曲子有清楚的调性时，用 `pitch` 试和弦音，再放回配乐核对。 [当前系列画面](../../references/current-style.md)

## 选材和落地

- **轻拟音与界面**：从 skill 根目录运行 `python modules/audio/preview.py --bank tactile --out AUDITION_DIR`，打开输出的 `index.html`。八个短声是可直接调用的合成素材；`seed` 可改变拟音颗粒，界面声的 `pitch` 可按配乐调到同一音域（整数 MIDI 48–84）。试听目录给出各音色 ID 与适用场景。
- **其他材质**：需要更夸张的回弹或阶段结算看[街机组](ARCADE.md)；转场、环境和可调音色看[全库](SYNTHESIS.md)；要有特定真实材质，用本片录音或有使用授权的素材，记录来源并按同一合同导入项目 PCM。
- **写进现有源**：导演用 `production-plan.audio[]`，直接工程用 `audio.json.cues[]`。以下事件名只说明分工，实际值取自本片 storyboard／timeline。跨镜可以引用后镜揭示帧制作预入。无口播但有声的工程用 `audioMode="sfx-only"`。

```json
[
  {"id":"paper-move","sound":"synth.paper-slide.v1","at":{"event":"s01.paper-moves"},"level":0.22},
  {"id":"paper-seats","sound":"synth.series-paper-land.v1","at":{"event":"s01.paper-contacts"},"level":0.5},
  {"id":"reply-arrives","sound":"synth.series-reply.v1","at":{"event":"s02.reply-visible"},"level":0.5},
  {"id":"reveal-air","sound":"synth.whoosh.v1","at":{"event":"s03.reveal"},"align":"peak","params":{"duration":0.26,"peak":0.67},"level":0.16}
]
```

选用声可按用途裁剪。导入的短拟音先去掉前导空白，再把首音绑定到动作；固定 WAV 和本组轻拟音用起音。[峰值和末端对齐](SYNTHESIS.md#写进分镜和-videospec)仅用于声明支持的合成声。较长的环境可用淡化后的项目 PCM；保持可独立移动和替换，交付时不要把它并入 BGM。

已有工作台剪辑时，把选好的音效拖到音效轨，对准实际帧，再按本片的 BGM 调整音量并保存当前工作台 JSON。需要调合成参数时沿源工程修改并另行导入。 [工作台的分支规则](../../references/workbench.md#4-编辑存档与原创作源)

## 先对照听，再收混音

1. 同一个片段听 **关闭音效 → 开启音效 → 单听音效**。在工作台隐藏音效轨，再恢复；BGM、旁白、画面和播放音量保持一致。单听用来查起音、材质和尾音，实际取舍以混音后的观看为准。静态阅读或等待留一段给观众喘气。
2. 单听觉得接触发软时，先把候选对齐到相同峰值，比较前几十毫秒的敲击、主体厚度和尾音。用短促音头和能在小扬声器上分辨的中频保住实物触感，再调进配乐。
3. 让主要接触、锁定和状态反馈在起音时盖过当下的 BGM。主音效可从 `level` 0.50 试起。用同一时间窗的分轨 RMS 比较时，先试听高出 BGM 约 3–6 dB 的版本，再按音色和冲击力度调整。擦动、空间声和次要动作按各自的画面作用混音。关键声仍被盖住时，检查重叠的鼓点和频段，给该落点留音乐空间。有旁白时保住字句，手机外放也要能分辨关键变化。
4. 源构建检查 `build/sfx-events.json`（`video.py build` 提示计数与问题代码）。对照 `at`、`anchorFrame` 和 `anchorSample` 核查事件，`sample` 是对齐到工作台网格的片段起点。需要峰／末端对齐时，两者可不同。读报告时看：

   | 提示 | 要核对 |
   | --- | --- |
   | `bgm-without-sfx` 或 `sfx-disabled-by-silent-mode` | 确认整片音乐独奏／静音是设计决定；有计划的触点须出现在实际编译分轨里 |
   | `sfx-zero-signal` | 该 cue 在片内放置的 PCM 信号为零；查 level、素材和剪裁 |
   | `sfx-tail-trimmed` | 片尾裁了该声的尾巴；听是否需要换短声、淡出或为收镜留时间 |
   | `sfx-shared-anchor` | 多条 cue 绑同一帧；听是有效分层还是重复确认 |

5. `placedPeakDbfs` 是源混音的片内峰值。有配乐的无旁白工程可看每条 cue 的 `onsetLevels.sfxVsBgmDb`。它比较母带处理前同一段约 100 毫秒的两轨 RMS。正值表示这段音效电平更高。工作台改动后回到实际导出复听，记录保留的声音、留白与修订时间码。未实际听音保留 `not_reviewed`。 [Garden 审片](GARDEN.md#预览与审片)
