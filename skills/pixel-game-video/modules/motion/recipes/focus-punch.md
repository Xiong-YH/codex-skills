# 焦点冲入切换

`motion.focus-punch.v1`，`target:"scene"`，从后镜头 enter 开始。

- `x`、`y` 指定画幅归一化焦点；`zoom` 控制冲入倍率，范围读取 catalog。
- `incomingX`、`incomingY` 与 `incomingZoom` 可指定新镜开始的焦点特写，随后拉回原构图。承接同一物体时比较切点两侧的位置与尺寸，避免大特写突然跳回中景；省略则沿用中心 1.65 倍回落。
- 旧画面冲入焦点，在高速运动处换景，再回落到新画面构图。
- 适合物体出现、关键动作或论点推进；60fps 可从 36–40 帧起试。
- 人物是否出现由镜头 `actor` 决定；站立人物可跟随统一运镜改变景别，不需要肢体活动。新字幕与旁白排在落位后，承接焦点的物体在切入时已可见。
- 音效另绑 enter 事件，不由转场代码自动触发。

检查主体冲入方向明确、换景藏在运动中、结束文字可读且无镜像。
