# 已认可的二维动态设计库

先打开[六效果HTML](../examples/advanced-2d/index.html)播放和拖动，不从静态图猜动作。
用户本轮反馈：“第一个不太行，其他几个可以沉淀到我们的库里面”。据此排除该版弧线移焦，
保留以下六个设计与真实GSAP时间轴。认可范围是此版观看效果，不是所有参数或正式引擎已支持。

| 设计 | 解释任务 | 现有能力关系与尚缺部分 |
| --- | --- | --- |
| 焦点接力 | 同一空间依次看多个对象，再回全貌 | camera-path可承载基本位置/倍率，具体节奏和构图仍要按本片适配 |
| 分层视差 | 远景、内容、前景按不同速度横移 | layer-move只有background/actor/content三组；此试样far/mid/near不能直接套到任意背景 |
| 甩镜接场 | 快速同向换景，速度峰值配模糊，末态清晰 | 新的跨镜空间/模糊组合；尚未注册通用配方 |
| 对象匹配 | 同一对象跨布局延续，周围版面改变 | 现有component-handoff支持有限组件匹配；GSAP Flip的通用DOM布局变化尚未接入 |
| 前景遮挡 | 前景满遮时切换，随后露出新场景 | 现有panel-occlusion约束档案面板；本试样任意前景墙不能当成其通用能力 |
| 弹性落稳 | 快速接近重点后轻微超调收束 | 此版使用GSAP elastic；现有slam/back曲线不是同一个效果，正式适配待完成 |

HTML、CSS与JS及固定版本插件随技能保存。曲线、空间和时间线可以直接读取；
这是一份设计源，不新增可执行recipe ID，不自动修改原项目、工作台或导出后端。
制作采用其中效果时，在导演方案中明确本次设计，并先适配到实际执行器、验证任意帧求值、
工作台编辑和导出，再标正式可用；不能拿相近旧配方冒充已认可效果。

试样使用GSAP 3.13.0的时间轴与Flip；上游文件保留原版权头，许可链接见
[来源说明](../examples/advanced-2d/vendor/GSAP-LICENSE.txt)。本轮未引入3D。
弧线移焦仅拒绝上一版具体试样，不泛化为所有题材禁用弧线路径。
