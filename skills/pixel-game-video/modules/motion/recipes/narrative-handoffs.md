# 物体与空间的接力

| recipe | 参数 | 画面任务 |
| --- | --- | --- |
| `motion.book-sweep.v1` | `x,y` 起始书页中心，0–1 | 书页放大铺满画幅；在完整遮挡时换景，再扫离揭示新空间 |
| `motion.shelf-travel.v1` | 无 | 两个完整房间横向交接；前景书架始终遮住交界，先出后入 |
| `motion.scene-to-card.v1` | `x=.54,y=.30,width=.29` | 上一完整镜头收成下一镜中的真实图卡；保持画幅比例 |

这些配方作用于完整世界，字幕保持独立。`x,y` 对 scene-to-card 表示图卡左上角；宽高的归一化数值相同，目标必须在画面内。后镜头应实际绘制同一来源的图卡，防止转场结束时内容跳变。

适合“书本进入研究空间 → 换到实践空间 → 两条路线归纳”的叙事；不是每个主题都要套三种特效。可从 36 / 48 / 36 帧试起，完成后再进入新句。执行在 `narrative-transitions.js`，空间与道具仍由 scenes 维护。

检查：书页换源点有完整遮挡；横移时交界藏在书架后，没有两个人同时抢镜；图卡落位与后镜源图、比例和边框一致。实际示例：director 的 `cs-postgrad-narrative-18s`。
