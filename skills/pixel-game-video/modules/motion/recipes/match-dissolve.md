# 主体匹配与场景接续

`motion.match-dissolve.v1`，world 转场，target 为 scene，无额外参数。

前后镜需先设计同一物体的相同位置、大小和形状。完整旧房间保持前20%的时间，中间60%用平滑曲线接续完整新房间，后20%保持新构图。字幕独立，不缩放或裁断连续背景。

本配方不会自动识别主体，也不替作者匹配几何。前镜标题与新标题需错开，避免溶解期间叠字；新旁白与机制动作安排在落稳之后。可由场景自身完成同一块真实面板内部的状态更新，此时不必额外套全屏转场。

验收：同一主体保持清楚稳定，房间交替无裸底；看切点两侧与中间帧，检查是否出现双重文字或主体重影。时长按内容决定，不能把长时长视为自动通过审美检查。
