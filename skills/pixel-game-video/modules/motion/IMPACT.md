# 个体冲击与回弹

用于问题揭示、关键字、状态确认、道具落位等有明确事件的单个视觉对象。字幕词组、卡片、印章、槽位边框或图标都可调用同一份 [逐帧参考代码](impact-reference.js)。这是从《绩点与 offer》V3 的“为什么？”提炼的局部运动参考。场景背景微震、闪光和粒子可分别选用。

## 使用

1. 先定对象的最终位置、尺寸与锚点，并检查最大放大时是否挡字、碰到其他对象或超出画幅。
2. 用同一个触发事件计算每帧的相对秒数。保持同一对象、字形、字号和排版，只对该对象逐帧应用缩放与位移。需要入场显露时，由调用端在触发前隐藏。冲击段禁止用多段静态字号或位置近似。
3. 落稳后保持完整语义或结果。字幕与组件可在同一拍协同，但分清主次，通常只给主对象完整强度。反馈较重时，次要对象可仅亮起或保持稳定。

```js
const { sampleImpact } = require('./impact-reference.js');
const pose = sampleImpact((frame - hitFrame) / fps, { strength: 0.8 });
// x/y 以 1280×720 参考像素表示，scale 以最终尺寸为 1。
const pixels = height / 720;
ctx.save();
ctx.translate(anchorX + pose.x * pixels, anchorY + pose.y * pixels);
ctx.scale(pose.scale, pose.scale);
drawTargetAtOrigin(ctx); // 文本、图标、组件或边框均可
ctx.restore();
```

浏览器先加载参考脚本，再用 `PixelVideo.impactReference.sampleImpact`；DOM/Remotion 在稳定锚点上应用同一份 `translate + scale`，预览和导出每帧共用函数。默认约 0.37 秒完成「1.62 倍入场 → 快速压下 → 0.93 倍过冲 → 回到 1」。强度在 0–1 之间调节幅度，duration 以秒调整时长。帧率由调用端转换成秒。触发前和结束后返回静止姿态。

`flash` 提供可选的短闪透明度，调用端可仅施加到该对象；粒子从实际触点产生，可参考 [游戏反馈辅助](game-feedback.js) 的 burst。场景状态由触发事件改变，粒子和短闪不替代状态变化。无须同时叠加所有反馈。

## V3 屏幕叠加

组件演示确认采用原版强度。用与对象相同的触发时刻调用 `sampleScreenImpact(elapsedSeconds)`。背景以中心为锚点预放大至 1.012 倍并施加衰减微震，位移按画幅高度缩放。对象在自己的锚点上独立回弹。最后在整帧上绘制暖色 `#fff3d5`，不透明度 12%，仅持续 1/30 秒。在 30 fps 导出中占一帧。屏幕层可单独关闭。不要为了让闪光更显眼而延长或加亮这套已确认效果。

[组件对照演示](examples/impact/index.html) 可切换屏幕叠加。通知卡、印章和缓存槽复用同一份参考代码。

## 验收

查首帧、收过头、回到原位和随后保持的帧；实际导出以正常速度连续播放，检查是否有台阶跳变、裁切、遮挡或落稳后仍在抖动。字幕另核语义完整和读完时间；组件另核最终状态是否清楚。参考代码可独立执行，当前未注册为工作台卡片或 VideoSpec 配方。接入新项目时核对编辑、预览与导出的实际调用路径。
