# 互动卡组合配方（尚无执行器）

保留原运镜 skill 的创作规则，作为后续场景扩展依据；当前 catalog 不发布此能力。

- 先结束强运动，再呈现问题、输入示例和指向提示。
- 卡片元素可在 0.15–0.3 秒内淡入；打字按完整字符展示。
- 只让光标局部闪动；问题保持稳定，完整示例停留后才换下一例。
- 收尾可用 0.3–0.5 秒叠化接标识或最终信息；旧卡片整体透明度必须归零。
- 是否出现互动环节由用户目标决定，不能强制所有视频带评论引导。

接入前需补充参数合同、timeline 事件和文字安全区；不修改相机执行器来堆叠卡片逻辑。
验收：无残留卡片、箭头遮字或最后信息阅读时间不足。
