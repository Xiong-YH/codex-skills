# 人物取数表演

`scenes.cache-adventure.v1` 沿用 [数据旅程](cache-journey.md) 的六个 phase、事件和标签合同，必须选择 actor，objects 为空。具体行为在独立 `cache-adventure.js` 维护；原来的示意图场景仍可单独使用。

- question：工作台中景，人物先歪头反应，再动身。
- fetch：机房全景，人物跑到数据仓，伸手取 A，抱着返回；镜头可按相同事件跟拍。
- store：人物与缓存近景，原 A 保留在手里，副本沿弧线落位，完成后显示缓存内 A。
- hit：工作台中景，短距离伸手取 A，缓存仍保留 A。
- miss：缓存仍有 A，请求 B 后转身跑出；在前景机柜遮挡时切到机房，抱 B 返回。
- summary：人物与缓存同框，短暂反应后安定停留。

表演调用 library 的原图关节组合，不重画人物；镜头参数在 motion、时序在创作工程事件、声音在 audio、字幕在 text。旁白独立讲述，人物使用原图休息嘴型。场内的背景切换只在 miss 的回源动作中使用；它不是可任意换环境的通用场景编辑器。

路径时间是教学比喻，不是硬件延迟实测。它仍不模拟缓存容量、失效或替换策略。
