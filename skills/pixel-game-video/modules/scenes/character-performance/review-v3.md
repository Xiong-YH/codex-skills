# 第三轮：独立参考视频与家具纠错

用户要求为几条连续动作补视频，并指出人物侧桌脚缺失。本轮将八项关系全部绑定独立5秒MP4，不再用同一旧片的选段代表不同模式。视频是代码人物的结构排练，模式和审美均待用户反馈。

## 家具缺失的确定事实与原因边界

漏脚在原始九格图片中已经存在，不是网页裁切或隐藏图层造成。生成结果有结构错误；上一轮验收只检查了人的肢体与手机归属，没有逐件检查桌面—围板—支撑—地面的连接，这是可以确认的流程漏项。不能推断模型内部为何漏画，也不以遮挡解释整个支撑缺失。

使用内置image_gen整幅编辑，保留九种人物动作，修正桌面围板、人物侧前支脚和其他支撑。当前候选为examples/asking-s02a/assets/seated-actions-v2.png；旧图保留并在assets.json标为结构失败。已逐格观察近侧左支脚从前围板连续落地、凳子与桌子独立、末格桌上无同一手机副本。细小彩边与帧间差异仍有保留，不宣称用户已认可新图。

## 视频与检查范围

源代码、录制脚本与清单在examples/relationship-studies/。八种关系分别有独立情境与结果；接触先后和对象持有权由代码明确控制，固定长度手臂会拒绝不可及目标。每个视频为960×540、H264/yuv420p、30fps、精确5秒、静音；最终停帧补足容器边缘不足，未拉长主动作。

manifest.json保存源与输出摘要、帧数、时长及整段解码结果。库页面对八段分别验证元数据加载、播放、暂停、拖动、复位和小屏布局；家具修正版已接回动作参考图及S02A原试样。静帧用于核对接触与结构，连续媒体已录制并实际播放；本轮未交工作台正式成片或宣称角色连续补间能力。
