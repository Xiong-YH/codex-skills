# 八段动作关系参考视频

每段5秒、960×540、30fps、静音，独立演示一种关系。人物和场景由studies.js逐帧绘制，是动作结构排练，不是正式小棕美术、骨骼能力或工作台最终交付。MP4与来源摘要见manifest.json；视频用于人物表演库详情页原位播放，用户认可待定。

| 参考 | 可见过程 |
| --- | --- |
| 注意重定向 | 新线索先出现，留感知延迟，再改变朝向与手势 |
| 蓄势与收束 | 准备、触点施力、球沿滑轨运动并停稳 |
| 启动与抑制 | 手在触点之前停住并撤回，按钮不响应 |
| 反馈闭环 | 第一次方向不匹配，接触调整方向后再试，结果改变 |
| 耦合与解耦 | 抓住后物体与人物同行，落到底座后释放 |
| 累积与阈值 | 负荷逐项增加，到界限后转交底座，释放身体支撑 |
| 重复与变奏 | 相同起势在不同条件下分别中止和触发，保留对照 |
| 接续与交接 | 同一物体递出、双方接稳、原持有者撤手，归属转移 |

Canvas排练使用固定长度双节手臂求解，目标不可及会报错，避免靠无限拉长手臂拼接触点。身体、脸和四肢为同一代码绘图，不编辑或拼接既有栅格人物部件。接触对象仅一份，底座有连通顶板与双侧落地支撑；这些约束只覆盖本例。结构与状态仍需实际观察，数值求解不证明美术自然。

可打开index.html?study=inhibit查看同源实时排练。媒体由浏览器连续录制Canvas后编码H264/yuv420p；这是独立参考，不替代正式工作台分轨、导出与审片流程。
