# 背景拆层与视差片段

支持按镜头需要，将完整背景整理为可独立合成的图层，再制作视差背景视频。适用于需要交代空间纵深、横移观察或前景遮挡的镜头。固定阅读、平面图解或缺少可分离空间关系的背景，可继续使用整图。层数、题材、画风、移动幅度和片长由本镜决定。

## 支持方式与接入范围

这是 `scenes.layered-background.v1` 制作工作流，使用现有 [项目媒体合同](MEDIA.md) 接入 Canvas 工程。该 ID 用于能力查询。实际调用仍是 `timeline.shots[].background` 或 `replacement`，没有新增 scene、motion recipe 或图层字段。

当前支持先制作图层素材和独立合成片段，再导入工作台。工作台中编辑的是合成后的视频片段；内部各层的回改依赖项目保留的素材、合成源码和参数。现有背景 PNG 与背景执行器仍按原合同使用，原生 Remotion 的媒体支持以其白名单为准。

## 判断与准备素材

1. 先按 [画风透传](../style/ART-DIRECTION-CONTRACT.md) 确定本镜有效画风。沿用背景时查看原图与来源，明确它是构图参考还是需要保留的原始素材。
2. 按空间距离、遮挡和相互连接关系划分图层。例如后墙、置物架、工作台；天空、远山、近处树木也可采用同一方法。层数以需要独立移动的空间关系为依据。
3. 将接触和承托的对象放在同组，例如台灯、电脑及其桌面。若必须拆开，记录共同锚点与运动关系，防止灯臂断接、桌脚漂移或落地物滑动。人物与其脚下平面也要检查相对运动。
4. 补齐移动后会露出的遮挡区域，并为最远构图准备足够的画外余量。后景应覆盖整个相机范围；上层保留真实 alpha，检查支架、叶片和灯臂之间的空隙。

完整 PNG 通常需要生成式重建才能得到被挡住的背景，不能仅靠矩形裁切得到完整图层。生成式拆层应标记为参考重绘，逐层核对布局、物体身份、比例与光源；只有实际验证过的素材才可声明与原图逐像素对齐。源素材已分层时优先复用。

## 生成指令的组织

使用可用的图像生成／编辑工具，引用同一母图并明确其角色。按层分别说明下列内容，透明层请求真实透明背景。

- **共同约束**。本镜有效画风、画幅、镜头与透视、共同坐标、像素颗粒、配色、光源和需要保持的对象身份。
- **后景**。保留哪些墙体或远处环境，移除哪些遮挡物，补全哪些露出区域，覆盖多大的运动范围。
- **中景／前景**。只保留哪些完整对象及连接结构，哪些区域透明，哪些对象属于其他层并须移除。

生成后查看实际图片和 alpha。棋盘格被画进 RGB、边缘残留背景色、重复物体、丢失支撑或比例改变时，先修复素材，再合成。素材生成指令、来源、版本、尺寸和哈希随项目保留，通用库只引用已确认素材。

## 合成与运动

- 所有层使用同一构图基准，按后到前合成；先看静态合成，再看运动极值和中间帧。需要缩放时统一网格与比例，像素场景使用最近邻采样和整数落点。
- 用一个相机进度驱动各层的相对位移。通常远层位移小、近层位移大；依据本镜空间关系选择方向、曲线与范围，避免把同一平面拆成互相滑动的物体。
- 有解释任务的移动按 [motion 选型](../motion/SELECTION.md) 和本镜事件收束，落稳后留阅读。环境轻移可循环，循环时同时核对位置、速度与亮度的衔接；不沿用示例的摆动曲线作为默认。
- 极值构图检查露底、截断、层边缝隙、影子脱离、灯光位置和前景遮挡。字幕与必要说明保持独立，由 text 和工作台管理。
- 合成按整数帧确定性求值，支持按帧重渲染。项目保留层文件、层序、变换基准、运动参数和合成源码，修改层后重渲染该片段。

## 进入工程与核验

环境视频作为 `background` 导入时，可继续叠加场景人物与组件。片段已经含本镜人物和场景时使用 `replacement`。文件放在项目 `media/` 下，按 [媒体合同](MEDIA.md) 配置尺寸适配、裁入与不足时长处理，再构建、进入工作台完成剪辑与最终导出。

先核对图层透明度、静态拼合、对象连接和关键构图，再正常速度连续观看实际合成片段，比较静止／视差状态是否确实改善空间感、是否影响阅读。最后核对视频尺寸、帧率、时长、完整解码与接镜；循环片段另查首尾连续性。机器检查与人工审片分别记录，未播放的项目继续标 `not_reviewed`。
