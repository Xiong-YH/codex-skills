# 素材库

只维护素材身份、形状、锚点、变体和来源；不维护镜头时间。

| 文件 | 用途 |
| --- | --- |
| `catalog.json` | 素材 ID、原生尺寸、锚点、哈希 |
| `assets/02-brown-fluffy.png` | 已确认 02 原始 32×36 人物，可直接预览 |
| `prepare.py` | 校验人物哈希、生成十个脸部变体 |
| `runtime.js` | 放置人物、缓存三种像素物体 |

人物：`actor.lead02.v1`，身体像素在所有口型与眨眼帧中完全一致。
物体：`prop.task-block.v1`、`prop.book.v1`、`prop.core.v1`。
这些文件从原始工程保留；构建过程不读取历史目录。

项目放置物体：`{id,asset,x,y}`；坐标按画幅归一化，范围 0–1。
物体 ID 供运动引用；素材 ID 供查库。同一素材可以生成多个物体。
书封是二维正面图层，没有三维书脊或封底；翻转不会产生镜像字。

新增人物需同时提供脸部坐标适配与完整变体；不能沿用 02 的像素位置。
换角色前核验静帧比例；已确认角色直接复用。
张嘴时点由 [scenes/performance.py](../scenes/performance.py) 管理，位移由 [motion](../motion/GUIDE.md) 管理。
