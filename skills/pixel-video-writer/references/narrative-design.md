# 阶段二：全片叙事设计与已有参考

先读 [全局创作目标](audience-experience.md)。本阶段确认的是**开头 → 核心内容 → 收尾**的整条观看链路，同时明确情绪与认知如何变化。核心内容的骨架和模拟方法只是其中一部分，不能用选一个结构名或列核心知识点替代全片设计。

## 先查已有逻辑和参考

以下五套为现有核心骨架，优先检查适配性，给一套推荐和一个备选，不一次铺开全部选项；允许按内容改写，后续再补充新的逻辑。它们是方法起点，不是都有已验证成片的配方。

| 核心骨架 | 推进方式 | 方法与案例参考 |
| --- | --- | --- |
| 问题解答 | 问题 → 原因 → 解法/机制 → 边界与回答 | [视觉叙事方法](../../pixel-video-director/references/visual-storytelling.md#先确定整段如何推进理解)；[缓存工程](../../pixel-video-director/examples/cache-journey/brief.json)可查机制演示，属于工程参考，不作留存效果证据 |
| 认知纠偏 | 常见看法 → 反例/矛盾 → 更准确解释 → 结论与限定 | [优绩主义供稿](merit-offer-case.md)是完整文案参考；[欲望合同](../../pixel-video-director/references/desire-contract-case.md)仅观察到片段，不能引用其未见结尾 |
| 对比选择 | 共同目标 → 统一比较条件 → 差异与代价 → 适用选择 | [比较关系方法](../../pixel-video-director/references/visual-storytelling.md#概念动作与视觉母题)；优绩主义供稿中的候选人比较可借鉴信息顺序，但其全篇归认知纠偏，不冒充纯对比样片 |
| 过程拆解 | 目标与起点 → 关键步骤 → 结果验证 → 易错点 | [视觉叙事方法](../../pixel-video-director/references/visual-storytelling.md#先确定整段如何推进理解)；[选择边界工程](../../pixel-video-director/examples/bounded-choice/brief.json)可参考条件筛选，不作完整教程或已认可成片证据 |
| 情境故事 | 处境与目标 → 阻碍 → 尝试与转折 → 结果与提炼 | [情境模拟式讲解](scenario-simulation.md)提供参与和状态推进方法；[优绩主义供稿](merit-offer-case.md)可参考角色换位，不把故事与模拟视为同一概念 |

**选型必须带参考**：展示参考链接、借鉴了哪一步、为何适配本主题，以及已知的观察/验证范围。只有方法参考时明确没有对应完整成片案例，不以任意链接充数。可以在骨架上选择情境模拟、角色换位、方法试用、条件变化等推进机制；“反向切入”用于问题和观察角度，不自动成为一套完整骨架。

## 三部分怎样设计

| 部分 | 需要决定什么 | 本阶段产物 |
| --- | --- | --- |
| 开头 | 首两秒让谁感到相关，前五秒提出什么冲突/疑问/收益，为什么继续看；开头承诺怎样进入核心 | 默认给两条简短候选开头和推荐理由；说明预计 0–2 / 2–5 秒的信息任务，无音轨标未对齐；画面、动作和声音交给导演细化 |
| 核心内容 | 选择哪个已有骨架、参考哪里；每步提供什么新依据，怎样连接、转折与回收；采用模拟时观众做什么 | 具体内容路线＋关键转折＋参考与借鉴点；不只写结构名称或“增加代入感” |
| 收尾 | 回答开场哪一个问题，给什么新的判断/行动与适用边界，如何处理前面激起的情绪；是否需要关注/评论等引导 | 明确结尾落点与一句候选收束句；有引导说明用途，没有则写无，不默认堆转化话术 |

两条开头是供比较的局部方案，用户已给定或局部改稿时按授权范围处理；本阶段的短句用于确认方向，完整文案仍在阶段三展开。无法合理安排在五秒内的信息应重写或移动，不能把整段长开头硬标“五秒完成”。

另用一行写清“观众起初的感受/判断 → 由什么内容触发变化 → 观看后留下什么”。如代入、意外、反思和行动感，必须绑定实际信息、选择或结果，不要求每段反转，不编造效果数据。

## 确认与衔接

确认对象包括开头方向、核心推进、收尾落点和情绪/认知路线；整体展示、一次确认，不增加四次审批。已有明确确认或授权自行选择时沿用。用户沉默、浏览、复制或泛泛认可视觉样式均不等于确认本片路线。

文案、视觉与 Check 继续继承三部分与全局目标。关键开头承诺、核心结论或收尾方向发生变化，说明影响并确认受影响的全片链路；不将当前五套结构封闭为永远只能选这些。

跨技能的方法页和工程链接为联动时的可选参考，按 [技能定位](handoff.md) 解析 DIRECTOR；独立安装未提供这些案例时，使用本页骨架说明、情境模拟与优绩主义供稿即可。缺少对应成片案例要如实说明，不为纯文案安装导演或构建工程。
