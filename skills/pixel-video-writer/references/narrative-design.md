# 阶段二 · 全片叙事设计

按 [编剧流程](script-workflow.md) 继承已确认的受众、问题与价值。结合 [观众目标](audience-experience.md)，设计从开头到收尾的观看链路，并写清情绪与认知如何随内容变化。

| 模块 | 带回全片路线的结果 |
| --- | --- |
| [开头](opening.md) | 可上屏的候选、前两秒与前五秒的信息任务、观众自然产生的追问和正文兑现点 |
| [核心推进](core-development.md) | 正文骨架及借鉴依据、首次兑现、逐步推进与转折、可支撑的结论 |
| [收尾](closing.md) | 回收的开头承诺、候选收束句、观众带走的判断或行动及其适用边界，适用时附评论区留言邀请 |

正文已有关键证据时，可从它反推开头与收尾。组合时把「开头给出什么、观众会追问什么、正文在哪里第一次回答、片尾兑现什么」连起来读。在主句或对象标注中交代事实与限定，视听表达交导演细化。

另写一行「观众起初的感受或判断 → 由什么实际内容触发变化 → 观看后留下什么」。绑定到具体信息、选择或结果，避免给每段硬加情绪反转。

## 确认与衔接

整体展示开头方向、核心推进、收尾落点和情绪与认知变化，沿编剧流程一次确认。已有明确确认或授权自行选择时沿用。用户沉默、浏览、复制或泛泛认可视觉样式均不等于确认本片路线。

成稿和交接继续沿用这条路线。关键开头承诺、核心结论或收尾方向变化时，定位受影响的段落和依据，按当前授权同步修订或确认变更。文案自查回到 [编剧流程](script-workflow.md#3--尽早交付完整文案)。
