# 编剧常见踩坑

写全稿、消化用户供稿或按 ID 返稿时，选适用于本稿的规则检查。规则编号用于追溯不同项目的改稿证据。 [案例索引与续记办法](script-pitfall-cases.md)

## 叙事与内容

| 编号 | 触发信号 | 编剧怎么改 | 怎么复核 |
| --- | --- | --- | --- |
| W01 | 后文用同一案例推进，口播只给泛称，具体是什么要看画面才知道。 | 在后文需要它之前，点清案例是什么、谁拿它说明什么。 | 遮住画面，能指出案例首次引入的文案 ID，能认出后续仍在说同一件事。 |
| W02 | 后文要查一个词、追问一个条件或用到一个结论，前文找不到它的来由。 | 按 ID 找出后文依赖的事实、定义或回答，在需要它的位置补一句能直接念的话。问答段可对照「问了什么 → 答了什么 → 拿答案做什么」。 | 连读受影响的段落，能复述后文用的是前面哪条信息，以及为什么能接到下一步。 |
| W03 | 视频承诺给出下一步，结尾只给「试一试」「多了解」这类宽泛建议，或建议的动作超出观众当前具备的条件。 | 对照目标受众和所处阶段，写清要做的对象、能开始的一步和可检查的结果。需要从案例回到现实时，给观众一个在自己处境里能开始的动作。 | 听完能说出这一步适合谁、什么时候能做、怎么开始，以及怎样知道做到了。 |

## 逐字稿与交接

| 编号 | 触发信号 | 编剧怎么改 | 怎么复核 |
| --- | --- | --- | --- |
| W04 | 同音错字在听感上难发现，拗口的引语和搭配在默读时容易滑过去。 | 先校字，再按口播顺序检查。按 ID 分开记审查意见和候选台词，改写时保留原意和适用限定。 | 对照原句核字，连读上下句核对说话人、指代和停顿。注明做了文字走读还是实际试读。 |
| W05 | 用户要求改的术语、引语或固定表述同时出现在口播和画内。 | 列出受影响的文案 ID 和画内位置。编剧回写唯一文案源，导演在画面设计源同步涉及的文字。 | 对照同一版本核对旁白、字幕和画内引用。按约定检查用词、含义或逐字一致。 |
| W06 | 台词里有要根据成片确定的值，当前只有估时或初剪数据。 | 接稿时记录 `文案 ID / 待回填字段 / 取值口径 / 负责人`。分别记录口播估时、配音实测和导出实长。 | 用当前导出按约定回填。片长变动后，重查受影响的台词、字幕和配音。 |

已确认原文的改动权限和各层回写归属，按 [接稿与修订合同](handoff.md#唯一来源与修订) 处理。
