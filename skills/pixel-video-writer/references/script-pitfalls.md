# 编剧常见踩坑

写全稿、消化用户供稿或按 ID 返稿时，按适用条目检查屏幕主句、对象标签及前后衔接。

## 叙事与内容

| 编号 | 触发信号 | 编剧怎么改 | 怎么复核 |
| --- | --- | --- | --- |
| W01 | 后段依赖前段的对象或结果，观众从名称和标签认不出来。 | 在首次出现时点明对象与用途，后段沿用同一名称或交代变化。 | 连看两段，能指出前段交出的对象或结果，以及后段怎样用它。 |
| W02 | 后文要查一个词、追问一个条件或用到一个结论，前文找不到它的来由。 | 按 ID 找到后文依赖的事实、定义或回答，补能直接上屏的主句或标签。 | 连读受影响的段落，能说出后文用的是前面哪条信息，以及为什么能接到下一步。 |
| W03 | 视频承诺给出下一步，结尾只给「试一试」「多了解」这类宽泛建议，或建议的动作超出观众当前具备的条件。 | 对照目标受众和所处阶段，写清要做的对象、能开始的一步和可检查的结果。 | 看完能说出这一步适合谁、怎么开始，以及怎样知道做到了。 |

## 屏幕文字与交接

| 编号 | 触发信号 | 编剧怎么改 | 怎么复核 |
| --- | --- | --- | --- |
| W04 | 主句分屏后失去主语、条件或因果关系。 | 按完整语义组织每次显露。细节交给对象标签，保留会改变判断的限定。 | 按出场顺序阅读，核对当前画面能明确指代和限定。 |
| W05 | 术语、引语或数字在主句、标签和图表里出现不同版本。 | 列出受影响的文案 ID 和画内位置，回写文案源和引用它的画面。 | 对照同一版本核对显示内容、单位和数据依据。 |

已确认原文的改动权限和各层回写归属，按 [接稿与修订合同](handoff.md#唯一来源与修订) 处理。
