# 情境模拟式讲解

## 来源、适用范围与状态

2026-11-03，用户提供“绩点更高却未先获得 offer”的完整文案，并明确认为“这种带入情景的模拟……值得归纳”。本页提炼的是用户供稿中的叙事方法，未观看对应视频，不据此记录运镜、动画、声音或成片审美认可。原稿的面试官、三张牌、A/B 人物与求职主题仅为案例，不固定为新片模板。

本方法用于阶段 2 的叙事设计，可与问题解答、认知纠偏、对比选择、过程拆解或情境故事结合；它是推进理解的机制，不增加第六套必选结构，也不要求每片使用模拟。

## 方法核心

让观众进入一个有目标、条件和后果的具体情境，参与一次判断或行动；再用结果、换位或条件变化，使观众理解抽象观点，最后回到现实中的行动与边界。

通用路线：**进入情境 → 明确目标与规则 → 获得信息 → 判断或尝试 → 看见结果 → 解释与迁移**。提问式开场、身份翻转和反转按内容选用。视频口播中的“参与”可以只是邀请观众在心里作答，不自动要求实现互动游戏；观众可能有不同选择，用“假设你选了……”等条件表达，不替观众宣称已选择。

## 供稿中的具体运用：角色换位式认知纠偏

| 段落任务 | 原稿设计 | 承接作用 |
| --- | --- | --- |
| 建立冲突 | 你绩点更高，他先拿 offer | 激活“表现更好应先得到机会”的期待 |
| 邀请参与 | 让观众成为面试官，两个候选人、一个名额 | 给观众明确身份、目标和限制 |
| 逐层形成判断 | 成绩与竞赛 → 项目使用情境 → 实际问题处理 | 判断依据从校园表现推进到岗位相关能力 |
| 得出条件性结果 | 假设观众选择 B | 保留选择理由，为后续换位提供依据 |
| 翻转身份 | “现在，你是 A”，再次拿起成绩牌 | 同一结果进入自身处境，引出失落与自我归因 |
| 解释并给行动 | 分析“表现好就该有好结果”的期待，调整准备顺序 | 从体验回到观点，再给出按岗位需要准备的行动 |
| 补边界与收束 | 成绩仍有价值，结果不完全可控；落选不等于全面无能 | 回应开场，并给情绪留空间 |

本例的三个关键机制：信息逐层揭示；同一结果下更换观察身份；前面的成绩牌在后文重新出现，成为自我争辩与怀疑的依据。借鉴时保留这种前后依赖，按新主题重新选择道具与情境。

## 可采用的三种变化

| 变化方式 | 怎样推进理解 | 适用问题 |
| --- | --- | --- |
| 角色换位 | 同一件事，先做决策者，再成为承担结果的人 | 评价、选择、公平感与自我归因 |
| 方法试用 | 保持目标，先尝试原方法，再用新方法处理同一任务，对照结果 | 方法论、教程与习惯调整 |
| 条件变化 | 保持任务或规则，改变一项相关条件，观察选择与结果变化 | 资源限制、决策、概念边界 |

三者是设计选项，不是要求顺序拼接的固定步骤。方法试用中也可直接示范有效步骤，不为转折编造一次失败。

## 阶段 2 需要向用户讲清什么

先沿 [全片叙事设计](narrative-design.md) 确定开头、核心、收尾和情绪/认知路线；模拟是核心推进机制，不能占掉整个全片结构。给推荐结构、理由、参考、具体路线和备选；使用本方法时，再用短句明确：

- **代入情境**：观众是谁，要完成什么，有什么条件。
- **参与任务**：观众要判断、选择或尝试什么；依据按什么顺序出现。
- **关键转折**：哪一步结果、换位或条件变化带来新增理解。
- **回收与迁移**：前面什么判断、对象或状态会被后面使用；最后落到什么现实行动与限定。

这些内容归入既有具体路线说明，不另建时间线、运行字段或冗长审批表。与用户确认具体推进方式，不能只确认“认知纠偏”等大类名称。实际画面交给导演，按其四阶段流程逐步细化。

## 设计检查

- 情境、信息和结果存在前后依赖；删去模拟后若观点表达几乎无损，检查它是否只有装饰作用。
- 选择依据应足够、公平；可以逐步揭示新信息，但不靠隐去必要条件或贬低另一方制造唯一答案。
- 换位保留同一结果和已有依据；条件变化明确变了什么，不能悄悄更换比较标准。
- 虚构情境、道具与示意结果帮助解释，不充当现实因果或普遍结论的证据；具体事实另核依据。
- 结尾说明适用边界和可行行动，不把某个结果扩大为对一个人的整体评价。
