## 怎么续记

1. **先在本项目定位问题。** 记录反馈或检查发现的现象、版本、文案 ID 和原句。改法注明候选、已采用或撤回。复核写明用了什么证据、查到哪里、用户确认了什么。完整稿件、审片证据和单片偏好随项目保存。
2. **同类问题沿用编号。** 从能复用的案例摘出足够理解的上下文，在同目录对应项目的 `*-copy-case.md` 续记。新项目建一页并加一行索引。重复出现的同类问题只补案例证据。
3. **新问题先作为案例记录。** 暂时归不到现有规则时标「待归类」。有实际修订和复核的证据后，按用户已确认的适用范围提炼触发信号、处理和复核方式，再更新或新增规则。

每个案例条目可用一行记录 `规则编号或待归类 / 版本和文案 ID / 现象与原句 / 改法及采用状态 / 复核依据与范围`。沿用已有规则编号，新规则顺延编号。技能内链接用相对路径。
