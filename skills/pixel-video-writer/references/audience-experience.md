# 全局创作目标：留住观众，并带来认知与情绪变化

2026-11-03，用户明确：最重要的指标是“五秒完播率、两秒跳出率”，要求贯彻全局；内容还应在观看中及看完后调动情绪与认知，如“居然是这个观点”“太真实了，这不就是我吗”，以及从“怎样成功”转向“为什么失败”的反向切入。本页是编剧维护、导演与制作通过项目资料继承的观众目标唯一维护位置，适用于本视频创作体系的需求、叙事、文案、视觉、检查和后续制作复盘；不推广为其他独立技能的默认目标。本次新要求优先。

## 目标与证据

- 优先优化方向：**降低两秒跳出率，提高五秒完播率**，并用后续内容兑现开头承诺。沿用用户指标名称，实际计算采用发布平台或用户提供的口径；未提供口径与目标值时标待补，不自定分母、合格线或预期提升数值。“五秒完播率”不等于全片完播率。
- 创作阶段只陈述设计意图与待验证假设；不能凭脚本、试读或示例认可宣称指标已提升。发布后有数据时记录平台、口径、内容版本、统计区间和样本量，比较相近受众与分发条件，避免把变化简单归因于一句开头。没有数据写未验证，不阻塞脚本设计。
- 同时追求观看中的代入、疑问、意外、理解，以及观看后的被理解感、新判断或行动意愿。写具体触发内容和理解变化，不编造情绪评分，不把争议、羞辱、恐吓或信息误导当作效果保障。

## 怎样产生认知与情绪变化

| 方法 | 具体设计 | 判断依据 |
| --- | --- | --- |
| 真实代入 | 一个可辨认的处境、动作或内心话，如拿着成绩牌问“为什么没选我” | 目标观众能认出自己的经历，细节不只是泛泛焦虑 |
| 期待与结果发生冲突 | 先建立观众熟悉的判断，再给相关结果、反例或条件 | 新信息足以改变理解，不靠隐去必要条件制造意外 |
| 换位与重新解释 | 同一事件换观察身份，或用新的解释重读前面的事实 | 前面的判断和对象仍然起作用，关键变化可被观众跟上 |
| 反向切入 | 从“怎样成功”改问“为什么失败”，或从“加什么”改问“什么在阻碍” | 题材有实际依据；最终给更准确的解释与行动，不止换个否定标题 |
| 收束与释放 | 回应开场、补边界，让人看见能改变什么与不能全归咎自己的部分 | 不留下单纯的自我否定，也不许诺方法包治问题 |

按主题选择，不要求每条都有反转、每段都强刺激。情绪变化服务理解，稳定解释与阅读停顿也是链路的一部分。

## 贯穿流程的执行要求

| 环节 | 必须落实的决定 |
| --- | --- |
| 需求 | 用“帮谁、解决什么问题、提供什么价值”三项摘要聚焦内容；全局目标自动继承，无需增加一轮指标问卷。写明目标观众的处境与希望改变的理解，已有实际目标值原样记录 |
| 叙事 | 设计完整“开头 → 核心 → 收尾”。0–2 秒给出可辨认的相关处境/冲突，2–5 秒建立继续看的问题或收益；说明内容如何兑现、情绪在哪里变化、结尾留下什么 |
| 文案 | 保留开头、核心、收尾分组；开头用实际候选短句检验，删去不承担任务的寒暄和前置解释。核心持续提供进展，结尾回收，避免只有开头吸引 |
| 视觉与声音 | 前两秒焦点清楚，主句可读。前五秒的对象变化、文字和配乐支持同一问题。全片关键转折可见，结果落稳后给观众留阅读时间 |
| Check | 核对前两秒相关性、前五秒继续看的理由、承诺兑现、认知变化与片尾回收。注明每项依据来自设计、实际播放还是平台数据 |
| 制作与复盘 | 把目标与具体设计决定写入 brief.constraints。按真实剪辑检查首屏、文字和配乐。发布数据回来后定位问题、比较版本并更新设计依据 |

开头时间安排是设计窗口，非固定字数或必须完成全部信息的机械时限。已有文案不能在未核实时标“已满足五秒要求”。
