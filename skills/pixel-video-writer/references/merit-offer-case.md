# 用户供稿案例：绩点更高，他先拿 offer

2026-11-03，用户提供完整 13 段文案，称为“比较好的成品”，并认可情境代入模拟值得归纳。以下仅分析所提供文字；没有对应成片或留存数据，不宣称画面、声音或指标效果已验证。

## 全片链路

| 部分 | 原文线索 / 对应段落 | 功能 |
| --- | --- | --- |
| 开头：结果冲突 | 第1段：“你绩点更高。他先拿了 offer。为什么？”随后指出成绩更好不保证机会先到 | 快速指向目标观众，唤起不甘与疑问；具体两秒/五秒落点须按真实配音核验 |
| 从开头进入核心 | 第2段提出“足够优秀就该得到好结果”的期待，邀请玩一个游戏 | 给出解释方向和继续看的理由，让游戏回应开场疑问 |
| 核心：进入情境 | 第3段让观众当面试官，两个候选人、一个名额 | 建立身份、任务与限制 |
| 核心：逐层判断 | 第4–6段依次给出成绩奖项、项目使用情境、解决实际问题的经历 | 使判断从校园评价推进到岗位相关能力 |
| 核心：选择与换位 | 第7段假设选 B；第8段“现在，你是 A”，再次拿起成绩牌，继而怀疑自己 | 保留同一选择依据，切换为承担结果的人；认同选择到不甘、自我怀疑产生张力 |
| 核心：解释与迁移 | 第9–10段解释对结果的期待与自我否定，回到大学不断加分的行为 | 让抽象概念对应刚才经历，产生“这就是我”的识别 |
| 核心到收尾：行动 | 第11段调整顺序：先看岗位需要，再用实际任务尝试，哪里不会补哪里 | 从情境所得推导现实准备方式 |
| 收尾：限定与情绪释放 | 第12段承认成绩奖项的价值和求职结果的不完全可控；第13段“别因为这一次，就觉得自己哪儿都不行”，再接关注引导 | 回答开场、阻止全面自我否定，给下一步方向；关注引导在内容收束后出现 |

## 可迁移设计

- 全片：结果冲突开头 → 情境模拟核心 → 行动、边界与情绪收束。不能将中间的游戏当作全片结构。
- 核心骨架：认知纠偏；推进机制：信息逐层揭示、角色换位、旧道具再次使用。具体方法见 [情境模拟式讲解](scenario-simulation.md)。
- 情绪与认知路线：不甘/疑问 → 作为面试官理解选择 → 作为 A 重新感到失落 → 认出自己的归因方式 → 找到可调整的行动，减少整体自我否定。这是文字设计分析，不是实测观众反应。
- 新主题重新选择真实处境与依据，不固定为面试、A/B、三张牌或某种成功结论；虚构游戏不单独证明现实招聘结论。
