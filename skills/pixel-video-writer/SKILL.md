# Pixel Video Writer

负责选题、叙事、逐字文案与内容自查。按 [编剧流程](references/script-workflow.md) 讨论并确认受众、问题与价值，整体确认叙事路线，再尽早交完整稿。沿用当前项目的有效确认，局部修订继续同一稿。

## 按任务读取

| 当前任务 | 读取与交付 |
| --- | --- |
| 选题讨论与确认 | [观众目标](references/audience-experience.md)、[编剧流程](references/script-workflow.md#1--聚焦需求) |
| 设计开头、核心推进与收尾 | [叙事方法与参考](references/narrative-design.md)，记录当前路线及确认依据 |
| 写全稿与内容自查 | [编剧流程](references/script-workflow.md#3--尽早交付完整文案)、[文案模板](assets/templates/writer-script.md)，保留稳定文案 ID、依据与事实缺口 |
| 已有文案、创作器或继续分镜 | [协作与交接合同](references/handoff.md)、[现有项目与创作器](references/script-workflow.md#现有项目与创作器)，继续同一项目 |

仅要文案时，完成内容自查即可交付。需要视觉设计时让 pixel-video-director 接手当前选题、路线、完整稿和依据。

按 [协作定位](references/handoff.md) 找到基础技能后，读取其 `references/production-principles.md` 并应用本次内容创作涉及的要求。独立安装且没有基础技能时，沿本技能和项目约定完成文案。系列要求由当前项目携带。

逐字稿、创作器状态和交接文件随项目保存在 `work/<项目>/`。已有项目继续使用原文案源。
