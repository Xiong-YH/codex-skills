# 像素视频运镜与转场

把叙事节点转成可执行的图层运动：让观众能追踪主体，理解积累与突破，并在关键文案出现时获得阅读时间。

## 使用范围

- 制作或修改动画时，沿用用户现有工程、渲染工具和画幅；这是一套动效配方，不指定 Remotion、HyperFrames、Canvas 或剪辑软件。具体 API 与渲染流程按所选工具的文档或已有技能处理。
- 只要求方案时交付时间线、图层和关键帧参数；要求成片时在工程中实现、预览并导出，不能把参数方案当成成片完成。
- 若用户只改某个转场，只改对应区间；不自动重写文案、换角色、加配音或扩成长片。
- 可与像素视频制作工作流配合使用，不替代角色美术、配音或视频获取流程。

## 核心判断

区分三个层级：相机变换影响整个场景和空间关系；物体变换只影响某一主体；合成特效改变光、遮罩、文字或碎片。书封独立放大应描述为物体缩放，不能直接称为摄影机推镜。

先找当前叙事节点，再从 [动效配方](references/recipes.md) 选用相关配方。用“积累”匹配计数和重复动作，用“突破”匹配碎屏或光效，用“揭示答案”匹配物体入场，用“参与”匹配稳定互动卡。无需把所有配方塞进每条视频。

为所选效果记录：时间区间、主视觉锚点、参与图层、起止状态、缓动、进入和退出方式。参数根据片长、字量和已有节奏调整；参考值不是固定模板。

保持前后场的主体或关注点在相近屏幕位置。复杂转场中让新信息及时可见，避免先播完特效再展示答案。强运动后留一个稳定的可读状态；箭头、打字等局部动作不必带动整个画面。

## 实现约束

- 动画按视频时间或帧号确定，随机碎片采用固定种子；跳转、预览和导出应产生同一画面。
- 像素素材保持清晰边缘；正文可以高清渲染。运动位置可连续，静止时对齐像素网格，避免小字长期抖动。
- 转场开始前准备好下一场。上层碎片、闪光、旧卡片在结束后归零透明度或移出，不能继续遮挡或截获交互。
- 文字动画保留足够的完整显示时间，按实际内容判断，不硬套秒数。装饰性闪光避免频繁全屏明暗交替。
- 无音轨或未检查音轨时不声称卡点成功；需要卡点时先取得音频节拍依据，再安排视觉峰值。

## 检查与交付

检查每段转场前、过程中、结束后的连续画面，并播放整个相关片段：主体是否跳位、碎片是否露出空洞、书封是否意外镜像、数字是否到达终值、透明层是否残留、字幕是否被遮挡。抽帧用于定位问题，不能替代播放检查节奏。

交付实际完成的预览/视频或方案，简述改动与验证范围。把“基于参考画面的观察”“实现方式的推测”和“新制作的参数建议”分开；不能声称知道参考作品的源工程或具体软件。

需要了解配方来源时阅读 [参考案例](references/reference-case.md)，不要默认下载或嵌入原视频素材。
