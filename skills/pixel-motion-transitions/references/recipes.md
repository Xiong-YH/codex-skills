# 动效配方

以下数值是新制作的可调起点，不是对参考视频工程参数的测量。坐标用画幅比例，时间用秒；p=clamp((t-start)/duration,0,1)。

## 1. 碎屏揭示：把“质疑”变成“突破”

图层自下而上：下一场 → 上一场碎片 → 裂纹高光 → 必要的独立字幕。

- 下一场主体与旧场主体对齐，破裂中心靠近当前视觉锚点。
- 参考节奏：裂纹预告 0.15–0.3s，碎片散开 0.45–0.8s，然后让新场稳定。
- 把旧场分成固定种子的放射状多边形；各碎片共用同一张旧场纹理并保持原纹理坐标，不能把整图分别缩放进每个碎片。
- 裂纹从中心向外建立；随后碎片按径向位移并小幅旋转，边缘碎片可以略延迟。可用位移 d(p)=v*p+a*p*p，避免每块同速同向像整屏平移。
- 飞散过程中露出下一场，后半段逐渐降低碎片透明度；结束时全部清除。下一场不能留到最后一帧才加载。
- 不便实现碎片时，可用裂纹遮罩加分区擦除近似，并说明这是简化版。

验收：无裸底闪帧、中心主体不跳位、碎片纹理连续、末帧无残片。碎裂改变场景才是转场；同一场景上叠裂纹仅是特效。

## 2. 固定场景＋计数：把重复变成可见的积累

保留窗、桌面或地平线等空间锚点，仅更新人物循环动作、天数、进度和少量环境状态。

- 计数可用 value=round(start+(end-start)*p^gamma)，gamma 可从 1.5–2.5 起试；需要匀速时 gamma=1。
- 进度与同一 p 或同一数据值绑定，终点明确钳制到 end。使用等宽数字并预留最大位数，避免布局左右跳动。
- 角色动作短循环、幅度小；日夜变化或衣着变化可以提示时间。无需每次数字变化都切镜。
- 关键数字到达后短暂停留，再触发下一事件。

验收：终值正确、进度一致、人物脚底或支撑面稳定；不会因文字变长让整个场景移动。

## 3. 金光爆发：积累到阈值后的高潮

图层：原场景 → 局部光晕 → 径向粒子/光线 → 突破标记 → 字幕。

- 参考节奏：0.1–0.2s 升亮，0.25–0.5s 回落，再留 0.3–0.6s 读结果。
- 用单次亮度包络和标记缩放超调制造冲击，例如 0.7→1.1→1.0；不要持续频闪。
- 保留人物轮廓和结果数字。可加轻微场景震动，但字幕不跟随震动。
- 若连接书封场，在光效收束时切换，或用亮度遮罩衔接；两种做法按叙事选择。

验收：结果可读、高潮只突出一个重点。光效峰值不能自动当作剪辑边界。

## 4. 书封旋转＋放大：让答案入场

背景放射线与书封分层；用物体动画制造接近感。

- 可从 25% 左右的最终尺寸开始，在约 0.8–1.2s 内放大至最终尺寸，先快后慢，最终尺寸由版式决定。
- 有真实封面/封底/书脊时，可用带透视的三维竖轴旋转；只有封面时，使用有意设计的正面→窄侧面→正面翻转，处理背面隐藏，避免展示镜像文字。
- 二维近似可用宽度因子 max(epsilon,abs(cos(theta)))，但应说明它是图层翻转效果，不是具有真实厚度的三维书。
- 中心位置保持稳定。背景可缓慢转动或改变光强，不能喧宾夺主。
- 入场后停转并保持正面，字幕或发布日期出现时给足阅读时间。

验收：没有负缩放导致的镜像字、侧面没有突兀跳回、最终封面完整清晰；不要把物体变大误报为相机推进。

## 5. 互动卡与收尾：从观看切到参与

先结束强运动，再展示提问、输入示例和指向提示。

- 切换场景后，卡片元素可在约 0.15–0.3s 内淡入。打字按完整汉字/字符显示，光标只局部闪动。
- 示例数字可以变化，但问题本身保持稳定。完整输入示例停留后再变换，不强制沿用 DAY 文案。
- 收尾可用约 0.3–0.5s 叠化切到书封/标识和时间。若设计要求清爽收尾，旧卡片整体透明度必须降至 0；若有意保留残影，明确其装饰目的并降低对比度。
- 是否保留互动卡、保留多久取决于用户目标，不要求所有短片都带评论引导。

验收：旧卡片无意残留、提示箭头遮字或最后信息停留不足时，先修复可读性。
