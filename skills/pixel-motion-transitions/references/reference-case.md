# 来源案例与证据边界

来源：一只索尔的《原子习惯》预告，https://www.douyin.com/video/7695980817403372971 。此前会话取得的视频为 576×1024、30fps，视频流约 28.73s。下列来自连续抽帧观察，未验证音乐卡点，也未取得源工程。

| 区间（秒） | 观察 |
|---|---|
| 0–约3.5 | 像素角色运动、面板逐项出现，随后产生裂纹 |
| 约3.5–5.07 | 旧画面碎裂散开，露出球场和递增计分牌 |
| 5.07–约12.4 | 卧室空间总体稳定，DAY、进度与角色状态变化 |
| 约12.4–13.43 | 金光覆盖、BREAK!! 与 ×37；仍属原场内特效 |
| 13.43–17.50 | 书封缩放、正侧面交替；背景未同步整体推进 |
| 17.50–约26.6 | 场景更换，互动卡淡入、打字和箭头提示 |
| 约26.6–28.73 | 书封与发布时间叠化出现，旧卡片在过渡中仍可见，末尾变暗 |

自动场景检测曾把金光变化判为切点，因此切点需视觉确认；检测帧数不等于实际镜头数。

可迁移的是视觉锚点、图层层级、叙事动机与动静节奏，不必沿用原作者的角色、文字、书封、时长或原声。配方中的缓动和持续时间是设计建议，不能宣称为原作参数。没有证据可确定原作使用了哪款软件。
