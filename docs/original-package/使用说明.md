# 现代像素口播视频 Skill

技能名：`pixel-game-explainer`。

已经安装到当前机器并接入原来的 llm_config 总线。Codex 发现目录使用链接指向同一份源文件，后续只需要维护一处。如果当前会话的技能列表尚未刷新，打开新会话，或让 Codex 读取技能的 `SKILL.md`。

## 怎么用

可以直接说：

> 用 $pixel-game-explainer，做一条讲“为什么 AI 时代更需要验证能力”的 20 秒视频。沿用这套现代像素游戏感风格，只有音效，没有人声。

也可以只改一部分：

> 用 $pixel-game-explainer，先只做这两个镜头之间的 2 秒转场样片，不出完整视频。

> 用 $pixel-game-explainer，先给我两个人物静态方案，身体保持很小。

> 用 $pixel-game-explainer，把方案选择这段的声音做出材质区别，保留 G2 方向。

## 包里包含什么

- `SKILL.md`：入口与按任务选用的流程。
- `references/`：人物和镜头、自然嘴型和音效、生产命令、历轮反馈与决策边界。
- `scripts/`：初始化、构建、声音合成、分段/完整渲染与实际媒体核验。
- `assets/starter/`：可独立运行并编辑的完整种子工程。
- `assets/reference/`：你认可的 V7 视频、分镜预览与原成片的核验记录。

种子示例仍是《AI 时代，程序员何去何从》。新主题需要 Codex 重写语义分镜、文案、场景和时间线；它不是只输入标题就自动完成新视频的程序。默认片长、分辨率和控制台场景只是示例参数，不是所有作品的固定模板。

## 在另一台机器使用

把 ZIP 里的 `pixel-game-explainer/` 放到目标 Codex 的 skills 目录，例如 `~/.codex/skills/pixel-game-explainer/`。已有同名 skill 时先比较再替换。独立包本身不要求本机的 llm_config 路径；如果目标环境也有自己的总线，接入它的注册表即可。

预览构建需要 Python 3 和 Pillow；重做声音需要 NumPy；帧导出需要 Node.js、Playwright 和 Chrome/Chromium。视频编码目前提供并验证的是 macOS AVFoundation。完整命令与依赖说明见技能内的 `references/production.md`。

## 本次沉淀

已记录并落实：原生像素而非模糊、高清文案、小身体短手臂、自然动嘴、单主角、利落且连贯的转场、游戏机制推动讲解、少气音且材质多样的音效。

后续建议：新主题保留这套视觉语法，但换与题意有关的机制和场景；不要每次都照搬同一个控制台或同一条关卡链。
