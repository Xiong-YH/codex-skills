# 嘴型和游戏音效

## 两条独立时间线

这套视频有“口播的表演”，默认没有真实人声。嘴型根据文案节奏模拟说话，不根据音效振幅跳动，也不声称已完成真实音素对齐。

`captions.json` 是字幕时段；`mouth-phrases.json` 是相同顺序的拼音短句组。句中按音节分配时长，弱读词稍短，句末稍长；双唇音有短闭唇，逗号和句号有停顿。英文缩写、数字或外语可由作者按实际读法标注，不能丢给固定随机开合。

示例有 rest/narrow/open/round/wide 五种口型，最大张口仅为原生 4×2 像素，眼睛另有眨眼帧。这个尺寸只适用于 02 的 32×36 脸，不是新角色的固定嘴型标准。不要大黑洞、持续露齿、夸张下颌变形或整张脸缩放。不要为了避免怪嘴而让整片完全闭嘴。

改文案时必须更新拼音短句。脚本会拒绝短句组数和字幕数不一致，防止旧数据被静默截断。

## 已选声音方向

G2 赛博竞技：短电路反馈、低频触感和游戏操作感；少气音，无长风噪、持续嘶声或扫频铺底。默认无真人、无 TTS、无 BGM。若用户另有明确声音要求，以当轮要求为准。

“更多样”是材质、音头、节奏、衰减和层次的区别，不能只是同一个哔声换音高。常用分工：

| 材质 | 适合动作 | 听感 |
| --- | --- | --- |
| 机械触点 | 选择、输入 | 干脆、小回弹 |
| 离散数据颗粒 | 复制、生成 | 短而不规则 |
| 磁力滑动 | 焦点聚合、抽取 | 有方向的短低频 |
| 弹性拨片 | 面板与方案展开 | 有物体厚度 |
| 玻璃共振 | 连接、修复 | 清亮、短尾 |
| 电路故障 | 异常与边界 | 短断续，与修复区别 |
| 电音加低频层 | 确认、交付、完成 | 重要事件才叠层 |

避免每个字、每次镜头变化都打音效。优先给可见物体接触、状态确认、修复和完成配声。小动作轻，关键完成有层次；留出安静空间。

## 代码与事件

`source/palette.py` 生成不同材质；`source/game_audio.py` 提供波形与放置；`sound-score.json` 定义 `at/kind/variant/level/x`。`x` 是示例原生世界的横向位置，用于轻度声像；若改原生宽度，需要一并改声像映射。

修改事件或音色后运行：

```sh
python3 "$SKILL_DIR/scripts/project.py" sound "$PROJECT_DIR"
python3 "$SKILL_DIR/scripts/project.py" build "$PROJECT_DIR"
```

`variant` 用来表达同类动作的小变化；不同动作先选不同材质。种子带有预合成的完整音轨，所以只看已有视觉时不需要安装 NumPy 或重做声音。

## 核验

检查声音与实际可见事件，而不只是 JSON 时间表。合成后检查音轨时长、前导延迟、峰值和削波。AAC 与 WAV 波形不会完全相同，不能用文件哈希比较它们；可解码 PCM 后看相关性、包络延迟和峰值。相同 WAV 素材的复用才适合用哈希确认。

用户只看视觉时用 `--silent` 导出短样片，嘴型仍按文案表演。不要因为不做真实人声而拿生成语音当隐含步骤。
